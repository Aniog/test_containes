# SSourcing China — Design System

## Brand Identity
- Company: SSourcing China
- Tagline: China Sourcing Agent for Global Buyers
- Tone: Professional, trustworthy, international, B2B

## Color Palette
- Primary (deep navy): `#0F2A4A` — `bg-navy` / `text-navy`
- Accent (China red): `#C8102E` — `bg-red-china` / `text-red-china`
- Accent light (gold): `#D4A017` — `bg-gold` / `text-gold`
- Surface white: `#FFFFFF`
- Surface light: `#F5F7FA` — `bg-slate-50`
- Border: `#E2E8F0` — `border-slate-200`
- Text primary: `#0F2A4A`
- Text secondary: `#4A5568` — `text-slate-600`
- Text muted: `#718096` — `text-slate-500`

## Typography
- Font: Inter (Google Fonts)
- Headings: font-bold, tracking-tight
- H1: text-4xl md:text-5xl lg:text-6xl
- H2: text-3xl md:text-4xl
- H3: text-xl md:text-2xl
- Body: text-base leading-relaxed
- Small: text-sm

## Spacing
- Section padding: py-16 md:py-24
- Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8
- Gap between cards: gap-6 md:gap-8

## Components
- Primary button: bg-red-china text-white px-6 py-3 rounded-md font-semibold hover:bg-red-800 transition
- Secondary button: border-2 border-navy text-navy px-6 py-3 rounded-md font-semibold hover:bg-navy hover:text-white transition
- Card: bg-white rounded-xl shadow-sm border border-slate-200 p-6
- Badge: bg-slate-100 text-slate-600 text-xs font-medium px-3 py-1 rounded-full

## Do's
- Use navy for headings and primary text
- Use red-china for CTAs and key highlights
- Use gold sparingly for trust badges and accents
- Keep layouts clean with generous whitespace
- Use subtle shadows on cards
- Use icons from lucide-react

## Don'ts
- No neon or overly bright colors
- No exaggerated marketing claims
- No cluttered layouts
- No dark text on dark backgrounds
