# SSourcing China — Design System

## Brand Identity
Professional B2B China sourcing agency. Clean, trustworthy, international.

## Colors
- **Primary (Brand Blue):** `brand-700` (#1e3a8a) — headings, nav, primary buttons
- **Primary Mid:** `brand-600` (#1d4ed8) — links, hover states
- **Primary Light:** `brand-50` (#eff6ff) — section backgrounds
- **Accent (Gold):** `accent-500` (#d97706) — highlights, badges, CTA accents
- **Neutral Dark:** `neutral-900` (#0f172a) — body text, headings
- **Neutral Mid:** `neutral-600` (#475569) — secondary text
- **Neutral Light:** `neutral-100` (#f1f5f9) — section backgrounds
- **White:** `#ffffff` — card backgrounds, main bg

## Typography
- **Font:** Inter (Google Fonts)
- **Display/H1:** `text-4xl md:text-5xl lg:text-6xl font-bold text-neutral-900`
- **H2 Section:** `text-3xl md:text-4xl font-bold text-neutral-900`
- **H3 Card:** `text-xl font-semibold text-neutral-900`
- **Body:** `text-base text-neutral-600 leading-relaxed`
- **Small/Caption:** `text-sm text-neutral-500`
- **Label/Badge:** `text-xs font-semibold uppercase tracking-wide`

## Spacing
- Section padding: `py-16 md:py-24`
- Container: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`
- Card padding: `p-6 md:p-8`
- Gap between cards: `gap-6 md:gap-8`

## Buttons
- **Primary CTA:** `bg-brand-700 hover:bg-brand-800 text-white font-semibold px-6 py-3 rounded-lg transition-all`
- **Secondary:** `border-2 border-brand-700 text-brand-700 hover:bg-brand-50 font-semibold px-6 py-3 rounded-lg`
- **Accent CTA:** `bg-accent-500 hover:bg-accent-600 text-white font-semibold px-6 py-3 rounded-lg`

## Cards
- `bg-white rounded-xl shadow-sm border border-neutral-200 p-6 hover:shadow-md transition-shadow`

## Borders & Shadows
- Card border: `border border-neutral-200`
- Card shadow: `shadow-sm` default, `shadow-md` on hover
- Section divider: `border-t border-neutral-200`

## Do's
- Use Inter font throughout
- Keep generous whitespace between sections
- Use brand-700 for primary actions
- Use accent-500 sparingly for highlights
- Ensure all text is readable (min 4.5:1 contrast)
- Use consistent 8px grid spacing

## Don'ts
- No dark backgrounds for body text sections
- No light text on light backgrounds
- No more than 2 font weights per section
- No decorative elements that distract from content
