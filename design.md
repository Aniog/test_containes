# SSourcing China - Design System

## Visual Style
- Clean, professional B2B aesthetic
- Trustworthy, international feel
- Factory/QC/shipping imagery
- No exaggerated claims, practical tone

## Colors
- Primary: blue-700 (#1d4ed8) - trust, professionalism
- Primary dark: blue-800 (#1e40af) - hover states
- Primary light: blue-50 (#eff6ff) - backgrounds
- Accent: amber-500 (#f59e0b) - CTAs, highlights
- Text primary: slate-900 (#0f172a)
- Text secondary: slate-600 (#475569)
- Text muted: slate-500 (#64748b)
- Background: white (#ffffff)
- Background alt: slate-50 (#f8fafc)
- Border: slate-200 (#e2e8f0)

## Typography
- Font: Inter (Google Fonts)
- Headings: font-bold, tracking-tight
- Body: font-normal, leading-relaxed
- Hero: text-4xl md:text-5xl lg:text-6xl
- Section titles: text-3xl md:text-4xl
- Subsection titles: text-xl md:text-2xl
- Body text: text-base md:text-lg

## Spacing
- Section padding: py-16 md:py-24
- Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8
- Gap between items: gap-6 md:gap-8

## Components
- Buttons: rounded-lg, px-6 py-3, font-semibold
- Cards: rounded-xl, border border-slate-200, bg-white, shadow-sm
- Badges: rounded-full, px-3 py-1, text-sm

## Do's
- Use plenty of white space
- Keep layouts clean and uncluttered
- Use icons from Lucide React
- Show real-world factory/QC imagery
- Use clear, readable text colors

## Don'ts
- Don't use dark backgrounds for main content
- Don't use overly decorative fonts
- Don't use bright/neon colors
- Don't clutter with too many elements
- Don't use invisible text (always check contrast)
