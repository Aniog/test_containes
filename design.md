# SSourcing China - Design System

## Visual Style
- **Aesthetic**: Clean, professional, international B2B
- **Typography**: Inter font family (modern, highly readable)
- **Layout**: Generous whitespace, clear hierarchy, grid-based

## Color Palette
- **Primary**: #1E3A5F (Deep Navy Blue - trust, professionalism)
- **Secondary**: #2563EB (Royal Blue - action, reliability)
- **Accent**: #059669 (Emerald Green - success, growth)
- **Background Light**: #F8FAFC (Clean white-gray)
- **Background Dark**: #0F172A (Deep slate for contrast sections)
- **Text Primary**: #1E293B (Dark slate)
- **Text Secondary**: #64748B (Muted gray)
- **Border**: #E2E8F0 (Light border)

## Typography Scale
- Hero: 48-56px, Bold (700)
- H1: 36-42px, Bold (700)
- H2: 30-36px, SemiBold (600)
- H3: 24-28px, SemiBold (600)
- Body Large: 18px, Regular (400)
- Body: 16px, Regular (400)
- Small: 14px, Regular (400)

## Spacing System
- Section padding: 80-120px vertical
- Container max-width: 1280px
- Card padding: 24-32px
- Grid gap: 24-32px

## Component Styles
- **Buttons**: Rounded-lg, solid or outline variants
- **Cards**: White background, subtle shadow, rounded-xl
- **Icons**: Lucide React, consistent stroke width
- **Images**: Rounded-xl for cards, full-bleed for hero

## Key Design Principles
1. Trust signals: statistics, certifications, testimonials
2. Clear CTAs: prominent, action-oriented buttons
3. Professional imagery: factory, QC, shipping visuals
4. Clean data presentation: tables, lists, grids
5. Accessibility: proper contrast ratios, focus states
