# SSourcing China - Design System

## Visual Style
Clean, trustworthy, international B2B aesthetic. Professional color palette with deep navy, slate grays, and crisp white. Ample whitespace, clear typography hierarchy, and subtle shadows for depth.

## Color Palette
- Primary: #0F172A (Slate 900) - Deep navy for headers and CTAs
- Secondary: #1E293B (Slate 800) - Dark slate for cards and sections
- Accent: #0EA5E9 (Sky 500) - Trustworthy blue for highlights and links
- Text Primary: #0F172A - Dark text for readability
- Text Secondary: #475569 (Slate 600) - Muted text for descriptions
- Background: #FFFFFF - Clean white
- Background Alt: #F8FAFC (Slate 50) - Light gray for alternating sections
- Border: #E2E8F0 (Slate 200) - Subtle borders
- Success: #10B981 (Emerald 500) - For trust indicators

## Typography
- Font: Inter (system-ui fallback)
- Headings: 700 weight, tight tracking
- Body: 400 weight, 1.6 line-height
- Small text: 14px for captions and meta

## Spacing
- Section padding: 80px vertical (desktop), 48px (mobile)
- Card padding: 32px
- Gap between elements: 24px default

## Components
- Buttons: Rounded (6px), 48px height, clear hover states
- Cards: White background, subtle shadow, rounded corners
- Forms: Clean inputs with focus states, proper labels
- Navigation: Fixed top bar, clear active states

## Do's
- Use generous whitespace
- Maintain consistent icon sizing (24px)
- Ensure all text has proper contrast
- Use realistic B2B imagery via data-strk-img

## Don'ts
- Avoid bright or saturated colors
- No decorative flourishes or gradients
- No exaggerated claims or hype language
- No cluttered layouts or overlapping elements
