# SSourcing China Design System

## Color Palette

### Primary Colors
- **Primary Blue**: #1e40af (Deep, trustworthy blue for headers and CTAs)
- **Primary Dark**: #1e3a8a (Darker shade for hover states)
- **Primary Light**: #dbeafe (Light blue for backgrounds and accents)

### Secondary Colors
- **Secondary Gray**: #f1f5f9 (Light gray for section backgrounds)
- **Secondary Dark**: #1e293b (Dark gray for text)
- **Secondary Medium**: #64748b (Medium gray for body text)

### Accent Colors
- **Accent Orange**: #f97316 (Warm orange for highlights and CTAs)
- **Accent Dark**: #ea580c (Darker orange for hover)

### Semantic Colors
- **Success Green**: #22c55e (For positive indicators)
- **Warning Yellow**: #f59e0b (For warnings)
- **Destructive Red**: #ef4444 (For errors and alerts)

## Typography

### Font Family
- **Primary**: Inter (Clean, professional, highly readable)

### Font Sizes
- **Heading 1**: 3.75rem (60px) - Hero headlines
- **Heading 2**: 3rem (48px) - Section titles
- **Heading 3**: 2.25rem (36px) - Subsection titles
- **Heading 4**: 1.875rem (30px) - Card titles
- **Body Large**: 1.25rem (20px) - Introductions
- **Body Normal**: 1rem (16px) - Regular text
- **Body Small**: 0.875rem (14px) - Captions

### Font Weights
- **Regular**: 400
- **Medium**: 500
- **Semibold**: 600
- **Bold**: 700
- **Extrabold**: 800

## Spacing System

### Section Padding
- **Mobile**: 4rem (64px) top/bottom
- **Tablet**: 5rem (80px) top/bottom
- **Desktop**: 6rem (96px) top/bottom

### Component Spacing
- **Small Gap**: 1rem (16px)
- **Medium Gap**: 1.5rem (24px)
- **Large Gap**: 2rem (32px)
- **XL Gap**: 3rem (48px)

## Border Radius

- **Small**: 0.25rem (4px) - Buttons, inputs
- **Medium**: 0.5rem (8px) - Cards
- **Large**: 0.75rem (12px) - Large cards
- **XL**: 1rem (16px) - Feature cards
- **Full**: 9999px - Badges, avatars

## Shadows

- **Soft**: 0 2px 15px -3px rgba(0, 0, 0, 0.07), 0 10px 20px -2px rgba(0, 0, 0, 0.04)
- **Medium**: 0 4px 6px -1px rgba(0, 0, 0, 0.1), 0 2px 4px -1px rgba(0, 0, 0, 0.06)
- **Large**: 0 10px 15px -3px rgba(0, 0, 0, 0.1), 0 4px 6px -2px rgba(0, 0, 0, 0.05)

## Animations

- **Fade In**: opacity 0 to 1 over 0.5s
- **Slide Up**: translateY(20px) to 0 over 0.5s
- **Slide Down**: translateY(-10px) to 0 over 0.3s

## Component Styles

### Buttons
- **Primary**: Blue background, white text, rounded-lg
- **Secondary**: White background, blue border, blue text
- **Accent**: Orange background, white text

### Cards
- White background
- Soft shadow
- Rounded corners (xl)
- Hover: medium shadow transition

### Section Titles
- Centered alignment
- Bold font weight
- 4px margin bottom
- Max-width for subtitle text

## Layout

### Container
- Max-width: 1280px (7xl)
- Responsive padding: 1rem (mobile), 1.5rem (tablet), 2rem (desktop)

### Grid System
- 1 column on mobile
- 2 columns on tablet
- 3-4 columns on desktop

## Responsive Breakpoints

- **Mobile**: < 640px
- **Tablet**: 640px - 1023px
- **Desktop**: 1024px+

## Do's and Don'ts

### Do's
- Use consistent spacing throughout
- Maintain clear visual hierarchy
- Use primary blue for important CTAs
- Keep text readable with sufficient contrast
- Use shadows to create depth

### Don'ts
- Don't use more than 3 colors in a single section
- Don't mix too many font sizes
- Don't use low contrast text combinations
- Don't overcrowd sections with content
- Don't use inconsistent border radius
