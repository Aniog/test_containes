# SSourcing China - Design Guidelines

## Brand Identity
- **Company**: SSourcing China - China-based sourcing agent for global buyers
- **Tone**: Professional, trustworthy, clear, practical, international B2B
- **Goal**: Generate qualified sourcing inquiries

## Color Palette

### Primary Colors
- **Navy Blue** (primary): `#1e3a5f` - Trust, professionalism, authority
- **Deep Blue** (primary-dark): `#152d4a` - Headers, emphasis
- **Sky Blue** (primary-light): `#3b82f6` - CTAs, links, accents
- **Bright Blue** (accent): `#2563eb` - Hover states, active elements

### Neutral Colors
- **White**: `#ffffff` - Backgrounds, cards
- **Light Gray**: `#f8fafc` - Section backgrounds
- **Mid Gray**: `#e2e8f0` - Borders, dividers
- **Slate**: `#64748b` - Secondary text
- **Dark Slate**: `#334155` - Body text
- **Charcoal**: `#0f172a` - Headings

### Accent Colors
- **Green** (success): `#16a34a` - Trust badges, checkmarks
- **Amber** (warning): `#d97706` - Highlights
- **Red** (urgency): `#dc2626` - Limited use for important notices

## Typography
- **Font Family**: Inter (Google Fonts)
- **Headings**: font-weight 700-800, tracking tight
- **Body**: font-weight 400, line-height 1.6-1.75
- **H1**: text-4xl md:text-5xl lg:text-6xl
- **H2**: text-3xl md:text-4xl
- **H3**: text-xl md:text-2xl
- **Body**: text-base md:text-lg
- **Small**: text-sm

## Spacing & Layout
- **Section padding**: py-16 md:py-24
- **Container**: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- **Card padding**: p-6 md:p-8
- **Grid gaps**: gap-6 md:gap-8
- **Border radius**: rounded-lg for cards, rounded-xl for larger elements, rounded-full for buttons/badges

## Visual Style
- Clean, minimal design with generous whitespace
- Card-based layouts with subtle shadows (shadow-sm to shadow-md)
- Professional photography of factories, QC inspections, shipping containers
- Icons from Lucide React for service features
- Subtle hover transitions (transition-all duration-200)
- No exaggerated claims or flashy animations

## Component Patterns
- **Buttons**: 
  - Primary: bg-sky-600 text-white hover:bg-blue-700 rounded-lg px-6 py-3
  - Secondary: border border-slate-300 text-slate-700 hover:bg-slate-50
  - Ghost: text-sky-600 hover:text-blue-700
- **Cards**: bg-white rounded-lg shadow-sm border border-slate-100 p-6
- **Sections**: Alternating white and light gray backgrounds
- **Navigation**: Sticky top, white bg with shadow on scroll

## Do's
- Use professional, realistic imagery
- Keep copy clear and concise
- Use data and specifics where possible
- Ensure strong contrast for readability
- Make CTAs prominent and clear
- Use consistent spacing throughout

## Don'ts
- Don't use flashy animations or transitions
- Don't use exaggerated marketing language
- Don't use low-contrast text
- Don't use decorative elements that don't serve a purpose
- Don't use stock photos that look fake or overly posed
- Don't use more than 2-3 colors per section
