# SSourcing China - Design System

## Typography
- Primary font: Inter (Google Fonts)
- Headings: font-weight 600-800, tight letter-spacing
- Body: font-weight 400-500, normal letter-spacing
- Small text: font-weight 400, slightly muted color

## Colors
- Primary: Navy blue (#1e3a5f) - trust, professionalism
- Primary light: (#2d5a8e)
- Accent: Orange (#f97316) - CTA buttons, highlights
- Accent hover: (#ea580c)
- Background: White (#ffffff) and light gray (#f8fafc)
- Text primary: (#0f172a)
- Text secondary: (#475569)
- Text muted: (#64748b)
- Border: (#e2e8f0)
- Success: (#22c55e)

## Spacing
- Section padding: py-16 md:py-24
- Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card gap: gap-6 lg:gap-8
- Element spacing: space-y-4, space-y-6

## Layout
- Max content width: max-w-7xl
- Grid columns: 1 (mobile), 2 (tablet), 3 (desktop)
- Cards: rounded-xl, border, shadow-sm, hover:shadow-md

## Components
- Buttons: rounded-lg, px-6 py-3, font-semibold
- Primary CTA: bg-orange-500 text-white hover:bg-orange-600
- Secondary: border border-slate-300 text-slate-700 hover:bg-slate-50
- Cards: bg-white border border-slate-200 rounded-xl p-6
- Section headers: text-center mb-12

## Do's
- Use navy blue for headings and primary elements
- Use orange for CTAs and action items
- Keep plenty of white space
- Use consistent card styles
- Use proper contrast ratios

## Don'ts
- Don't use bright/neon colors
- Don't use more than 2 accent colors
- Don't overcrowd sections
- Don't use decorative fonts
- Don't use low-contrast text
