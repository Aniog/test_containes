# SSourcing China - Design System

## Overview
A professional B2B website for China-based sourcing services. The design conveys trust, reliability, and international professionalism while remaining approachable for overseas buyers.

## Color Palette

### Primary Colors
- **Primary Blue**: `#1E40AF` - Main brand color, CTAs, headers
- **Primary Light**: `#3B82F6` - Hover states, secondary elements
- **Primary Dark**: `#1E3A8A` - Text on light backgrounds

### Neutral Colors
- **Slate 900**: `#0F172A` - Headlines, primary text
- **Slate 700**: `#334155` - Body text
- **Slate 500**: `#64748B` - Secondary text, captions
- **Slate 200**: `#E2E8F0` - Borders, dividers
- **Slate 100**: `#F1F5F9` - Section backgrounds
- **White**: `#FFFFFF` - Primary background

### Accent Colors
- **Success Green**: `#059669` - Trust indicators, checkmarks
- **Warning Amber**: `#D97706` - Highlights
- **Gold Accent**: `#B8860B` - Premium elements

## Typography

### Font Family
- **Primary Font**: Inter (Google Fonts)
- **Fallback**: system-ui, -apple-system, sans-serif

### Font Sizes
- **Hero Headline**: 48px-64px, font-weight: 800
- **Section Headline**: 36px-42px, font-weight: 700
- **Sub-headline**: 24px-28px, font-weight: 600
- **Body Large**: 18px, font-weight: 400
- **Body**: 16px, font-weight: 400
- **Caption/Small**: 14px, font-weight: 400

### Line Heights
- Headlines: 1.2
- Body: 1.6
- Captions: 1.5

## Spacing System
- **XS**: 4px
- **SM**: 8px
- **MD**: 16px
- **LG**: 24px
- **XL**: 32px
- **2XL**: 48px
- **3XL**: 64px
- **4XL**: 96px

## Layout
- **Max Container Width**: 1280px
- **Section Padding**: 96px vertical (desktop), 64px (tablet), 48px (mobile)
- **Component Gap**: 24px-32px
- **Border Radius**: 8px (cards), 12px (large cards), 6px (buttons)

## Visual Elements

### Cards
- White background
- Subtle shadow: `0 4px 6px -1px rgba(0, 0, 0, 0.1)`
- Border: 1px solid slate-200
- Border-radius: 12px
- Padding: 24px-32px

### Buttons
- **Primary**: Blue background, white text, hover darken 10%
- **Secondary**: White background, blue border, blue text
- **Ghost**: Transparent, blue text
- Height: 48px (default), 44px (small)
- Padding: 12px 24px
- Border-radius: 6px

### Icons
- **Library**: Lucide React
- **Size Standard**: 24px
- **Size Large**: 32px-48px
- **Color**: slate-700 (default), primary-blue (accent)

### Images
- Border-radius: 8px-12px
- Object-fit: cover
- Use professional factory/warehouse/logistics imagery

## Sections Design

### Hero Section
- Full-width with subtle gradient overlay
- Large headline with supporting text
- Primary CTA button
- Optional secondary CTA

### Services Section
- Grid layout (3 columns desktop, 2 tablet, 1 mobile)
- Icon + Title + Description cards
- Hover lift effect

### Trust Indicators
- Horizontal layout with icons/numbers
- Key metrics: Years experience, Suppliers verified, Countries served, Orders shipped

### Process Steps
- Numbered steps with connecting line
- Icon for each step
- Clear, concise descriptions

### Case Studies
- Card grid with image, title, industry, result
- Hover effect with shadow increase

### FAQ
- Accordion style
- Plus/minus toggle icon
- Smooth expand/collapse animation

### Contact Form
- Clean, minimal design
- Floating labels or placeholder text
- Clear field validation
- Success state confirmation

## Shadows
- **Card Shadow**: `0 4px 6px -1px rgba(0, 0, 0, 0.1), 0 2px 4px -2px rgba(0, 0, 0, 0.1)`
- **Hover Shadow**: `0 20px 25px -5px rgba(0, 0, 0, 0.1), 0 8px 10px -6px rgba(0, 0, 0, 0.1)`
- **Modal Shadow**: `0 25px 50px -12px rgba(0, 0, 0, 0.25)`

## Animations
- **Hover transitions**: 200ms ease
- **Section fade-in**: 400ms ease-out
- **Button hover**: scale(1.02) + shadow increase

## Do's
- Use professional photography with real people and factories
- Maintain generous whitespace
- Use consistent spacing throughout
- Prioritize readability with proper contrast
- Use blue as trust indicator color

## Don'ts
- Use stock photos that look fake or generic
- Overcrowd sections with too many elements
- Use too many different colors
- Use decorative fonts or excessive typography
- Make claims that seem exaggerated or unbelievable
