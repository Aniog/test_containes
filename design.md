# SSourcing China - B2B Website Design System

## Visual Style

Professional, clean, trustworthy international B2B aesthetic. Use a restrained color palette with blues and grays to convey reliability and professionalism.

### Colors (Tailwind Classes)
- Primary: slate-900 (#0f172a) - Deep navy for headers and CTAs
- Secondary: slate-700 (#334155) - Body text
- Accent: blue-600 (#2563eb) - Links, buttons, highlights
- Light Background: slate-50 (#f8fafc) - Page backgrounds
- Card/Section Background: white (#ffffff)
- Border: slate-200 (#e2e8f0)
- Success/Trust: emerald-600 (#059669)

### Typography
- Font: Inter (system-ui fallback)
- Headlines: font-semibold, tracking-tight
- Body: font-normal, leading-relaxed
- Sizes: h1 (text-5xl), h2 (text-3xl), h3 (text-2xl), body (text-base)

### Spacing & Layout
- Consistent 8px grid system
- Section padding: py-16 md:py-20
- Container max-width: max-w-7xl with px-6
- Card gaps: gap-6 or gap-8
- Button padding: px-6 py-3

### Components
- Buttons: rounded-lg, font-medium, transition-colors
  - Primary: bg-slate-900 text-white hover:bg-slate-800
  - Secondary: bg-white text-slate-900 border border-slate-200 hover:bg-slate-50
- Cards: bg-white border border-slate-200 rounded-xl p-6 shadow-sm
- Forms: clean inputs with slate-200 borders, focus:ring-blue-600
- Navigation: sticky top bar, clean links, mobile hamburger

### Do's
- Use ample white space
- Keep text concise and practical
- Use realistic factory/QC/shipping imagery via data-strk-img
- Ensure all text has high contrast
- Make CTAs prominent but not aggressive

### Don'ts
- Avoid bright or saturated colors
- No exaggerated claims or hype language
- No decorative icons without purpose
- No cluttered layouts or overlapping elements
- No low-contrast text

## Page Structure

All pages share:
- Top navigation bar (logo + links + CTA button)
- Footer with contact info and links
- Mobile responsive hamburger menu

Home page sections flow logically from value proposition to conversion.
