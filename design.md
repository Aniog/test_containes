# SSourcing China - B2B Website Design System

## Visual Style

Professional, clean, trustworthy B2B aesthetic for international sourcing services.

### Color Palette
- Primary: #0F172A (slate-900) - Deep navy for headers and CTAs
- Secondary: #1E40AF (blue-800) - Trustworthy blue for accents
- Accent: #0EA5E9 (sky-500) - Light blue for highlights
- Neutral: #F8FAFC (slate-50) - Light background
- Text: #1E293B (slate-800) - Primary text
- Muted: #64748B (slate-500) - Secondary text
- Success: #059669 (emerald-600) - Trust indicators
- Border: #E2E8F0 (slate-200) - Subtle dividers

### Typography
- Font: Inter (system-ui fallback)
- Headings: 600-700 weight, tight tracking
- Body: 400-500 weight, 1.6 line-height
- Small text: 14px, muted color

### Spacing
- Section padding: 80px vertical (desktop), 48px (mobile)
- Card padding: 32px
- Gap between elements: 24px
- Container max-width: 1280px

### Components

#### Buttons
- Primary CTA: bg-[#0F172A] text-white px-8 py-3 rounded-lg font-medium hover:bg-[#1E293B]
- Secondary: border border-[#0F172A] text-[#0F172A] px-8 py-3 rounded-lg font-medium hover:bg-[#F8FAFC]
- Form submit: Full width on mobile, auto on desktop

#### Cards
- White background, subtle shadow: shadow-sm border border-[#E2E8F0]
- Rounded corners: rounded-xl
- Hover lift: transition-all hover:shadow-md

#### Forms
- Input: border border-[#E2E8F0] rounded-lg px-4 py-3 focus:border-[#1E40AF] focus:ring-1 focus:ring-[#1E40AF]
- Labels: text-sm font-medium text-[#1E293B] mb-2 block
- Error: text-red-600 text-sm mt-1

#### Navigation
- Fixed header with white background and subtle border
- Logo left, nav center, CTA right
- Mobile: hamburger menu

### Do's
- Use generous whitespace for professional feel
- Include realistic factory/QC/shipping imagery via data-strk-img
- Show trust signals: certifications, years experience, client logos
- Keep copy practical and benefit-focused
- Ensure all text has high contrast

### Don'ts
- Avoid bright or playful colors
- No exaggerated claims or hype language
- Don't overcrowd sections
- Avoid low-contrast text
- No decorative elements that distract from content

### Responsive
- Desktop: 3-4 column grids
- Tablet: 2 column grids
- Mobile: Single column, stacked elements
- Breakpoints: md (768px), lg (1024px)
