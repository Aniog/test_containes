# SSourcing China - Design System

## Brand Overview
Professional B2B China sourcing agent website. Clean, trustworthy, international.

## Color Palette
- Primary: #1e3a5f (Deep navy blue - trust, professionalism)
- Primary Light: #2a5298 (Lighter navy for hover states)
- Secondary: #0d9488 (Teal - growth, reliability)
- Accent: #f59e0b (Amber - CTAs, emphasis)
- Background: #ffffff (White)
- Surface: #f8fafc (Light gray for sections)
- Text Primary: #1e293b (Dark slate)
- Text Secondary: #64748b (Slate gray)
- Border: #e2e8f0 (Light border)
- Success: #10b981
- Error: #ef4444

## Typography
- Headings: Inter, font-weight 700-800
- Body: Inter, font-weight 400-500
- Hero heading: text-4xl md:text-5xl lg:text-6xl
- Section heading: text-3xl md:text-4xl
- Body text: text-base md:text-lg
- Small/labels: text-sm

## Spacing
- Section padding: py-16 md:py-24
- Content max-width: max-w-7xl mx-auto
- Card gap: gap-6 md:gap-8
- Component padding: p-6 md:p-8

## Components

### Buttons
- Primary: bg-amber-500 hover:bg-amber-600 text-white font-semibold px-6 py-3 rounded-md
- Secondary: bg-navy-800 hover:bg-navy-700 text-white font-semibold px-6 py-3 rounded-md
- Outline: border-2 border-navy-800 text-navy-800 hover:bg-navy-800 hover:text-white

### Cards
- bg-white rounded-xl shadow-sm border border-slate-200 p-6 md:p-8
- Hover: shadow-md transition-shadow

### Navigation
- Fixed top, bg-white/95 backdrop-blur, border-b border-slate-200
- Logo left, links center/right, CTA button prominent

## Visual Style Rules
- DO use real factory/sourcing imagery via data-strk-img
- DO keep text legible with high contrast
- DO use ample whitespace
- DON'T use flashy animations or gradients
- DON'T use emojis or casual language
- DON'T crowd elements - B2B needs clarity
