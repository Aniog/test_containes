# Velmora Fine Jewelry — Design System

## Color Palette
- **Ivyory (bg)**: `#FAF7F2` — primary page background, warm off-white
- **Cream (alt bg)**: `#F5F0E8` — section backgrounds, card surfaces
- **Gold (accent)**: `#C9A84C` — primary accent, CTAs, highlights
- **Gold Light**: `#D4B86A` — hover state for gold
- **Gold Dark**: `#A88B3D` — pressed/active gold state
- **Gold Muted**: `#E8D9A0` — subtle gold tint
- **Charcoal (text)**: `#1A1410` — headings, primary text, nav on scroll
- **Warm Gray**: `#6B5E50` — body text, descriptions
- **Warm Gray Light**: `#9A8E80` — secondary text, captions
- **Divider**: `#E8E0D4` — borders, separators
- **Deep Dark**: `#0F0C08` — footer, overlays

## Typography
- **Headings**: Cormorant Garamond (serif), weight 400–600
- **Body/UI**: Inter (sans-serif), weight 300–600
- **Product names**: Cormorant Garamond, uppercase, letter-spacing 0.12em
- **Section labels**: Inter, 10px, uppercase, tracking 0.25em

## Spacing
- Generous whitespace — sections padded 4rem–6rem vertically
- Card gaps: 1rem–1.5rem
- Max content width: 1280px (max-w-7xl)

## Components
- **Buttons**: Solid gold (`btn-accent`) or outlined gold (`btn-accent-outline`)
- **Dividers**: 1px `border-divider` (`hairline-divider`)
- **Cards**: White or cream background, subtle hover shadow
- **Inputs**: Transparent with border, gold focus ring

## Animations
- Subtle fade-in (0.6s ease-out)
- Slide-up for scroll reveals
- Hover: 0.3–0.5s transitions
- Cart drawer: slide-in-right (0.3s)
- Image crossfade on hover (0.5s)

## Do's
- Use generous whitespace
- Keep backgrounds warm and neutral
- Use gold sparingly as accent
- Maintain strong contrast (charcoal on ivory)
- Use serif for headings, sans for body

## Don'ts
- Don't use cold grays or blue-tinted backgrounds
- Don't use harsh borders (prefer hairline dividers)
- Don't use excessive animation or bounce effects
- Don't use discount-looking badges or red sale colors
- Don't break the warm, editorial mood
