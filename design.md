# SSourcing China - Design Guidelines

## Brand Identity
- **Company**: SSourcing China - China-based sourcing agent for global buyers
- **Tone**: Professional, trustworthy, clear, practical. No exaggerated claims.
- **Audience**: B2B international buyers, procurement managers, import business owners

## Typography
- **Primary font**: Inter (Google Webfont)
- **Headings**: Inter, weights 600-800, sizes responsive
- **Body text**: Inter, weight 400, size 16px base
- **Small text**: Inter, weight 400-500, size 14px

## Color Palette
- **Primary blue**: #1e56a0 (trust, professionalism, international business)
- **Primary dark**: #0f172a (headings, strong text)
- **Accent gold**: #d97706 (CTAs, highlights, warmth)
- **Background white**: #ffffff (clean, professional)
- **Background light**: #f8fafc (sections, cards)
- **Background medium**: #f1f5f9 (subtle sections)
- **Text dark**: #1e293b (body text)
- **Text medium**: #475569 (secondary text)
- **Text light**: #64748b (muted, captions)
- **Border**: #e2e8f0 (subtle borders)
- **Success green**: #16a34a (positive indicators)

## Layout Principles
- Clean, spacious layouts with generous padding
- Max content width: 1200px centered
- Section padding: 80px vertical (40px on mobile)
- Card padding: 24-32px
- Grid gaps: 24-32px
- Responsive: mobile-first, breakpoints at md (768px) and lg (1024px)

## Component Styles
- **Buttons**: 
  - Primary: bg-primary-500 text-white, hover:bg-primary-600, rounded-lg, px-6 py-3
  - Secondary: border border-primary-500 text-primary-500, hover:bg-primary-50
  - CTA: bg-accent-500 text-white, hover:bg-accent-600, larger padding
- **Cards**: bg-white, rounded-xl, shadow-sm, border border-slate-200
- **Section backgrounds**: Alternate between white and slate-50/slate-100
- **Icons**: Lucide React, 24-48px, primary-500 or slate-600 color

## Visual Style
- Professional B2B aesthetic - no playful or casual elements
- Subtle shadows and borders, not heavy or dramatic
- Consistent spacing and alignment
- Factory/QC/shipping imagery via data-strk-img system
- No decorative gradients or flashy animations
- Smooth hover transitions (0.2-0.3s)

## Do's
- Use clean white backgrounds with subtle section alternation
- Keep text readable with proper contrast
- Use professional imagery (factories, inspections, shipping, containers)
- Maintain consistent spacing throughout
- Use blue as primary trust color
- Use gold/amber for CTAs to draw attention

## Don'ts
- Don't use dark backgrounds for main content sections
- Don't use playful or cartoonish icons
- Don't use exaggerated claims or hype language
- Don't use low-contrast text on any background
- Don't use more than 2-3 colors per section
- Don't use heavy shadows or dramatic gradients
