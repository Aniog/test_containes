# Velmora Fine Jewelry - Design System

## Visual Identity

### Brand Mood
Quiet luxury, warm, editorial. Premium demi-fine jewelry aesthetic—refined, not loud.

### Color Palette
- **Background**: `#FAF9F7` (warm off-white/cream)
- **Surface**: `#FFFFFF` (pure white for cards)
- **Text Primary**: `#1A1A1A` (near-black)
- **Text Secondary**: `#6B6B6B` (warm gray)
- **Text Muted**: `#9A9A9A` (light gray)
- **Gold Accent**: `#B8976A` (warm antique gold)
- **Gold Dark**: `#9A7B56` (deeper gold for hover)
- **Divider**: `#E8E5E1` (warm light gray)
- **Overlay**: `rgba(26, 26, 26, 0.5)` (dark overlay)

### Typography
- **Headings**: Cormorant Garamond (serif), weight 400-600
  - Display: 48-72px, letter-spacing: 0.02em
  - H1: 40-48px
  - H2: 32-36px
  - H3: 24-28px
- **Body**: Inter (sans-serif), weight 300-500
  - Body: 15-16px, line-height: 1.6
  - Small: 13-14px
  - Caption: 12px
- **Product Names**: UPPERCASE, letter-spacing: 0.15em

### Spacing System
- Base unit: 4px
- Section padding: 80-120px vertical
- Container max-width: 1400px
- Grid gaps: 16-32px

### Component Styles
- **Buttons**: 
  - Primary: Gold background (#B8976A), white text, no border-radius or subtle rounded
  - Secondary: Transparent with gold border
  - Hover: Darken gold to #9A7B56
- **Cards**: White background, subtle shadow on hover
- **Dividers**: 1px hairline, warm gray (#E8E5E1)
- **Inputs**: Clean, minimal, bottom border style or subtle border

### Motion
- Transitions: 300ms ease for hover states
- Fade-in: opacity 0→1, 400ms ease
- Subtle scale on hover: 1.02
- Smooth scroll behavior

## Pages & Components

### Navigation
- Transparent on hero, solid white on scroll
- Logo: serif, centered or left-aligned
- Links: sans-serif, uppercase, letter-spacing: 0.1em
- Icons: minimal line style

### Hero
- Full-bleed imagery
- Overlaid text with warm semi-transparent backgrounds if needed
- Serif headline, sans-serif subhead

### Product Cards
- Clean white background
- Product image with hover state (second image or zoom)
- Product name in uppercase serif
- Price below
- Quick add button on hover

### Accordions
- Clean borders, minimal styling
- Chevron indicator
- Smooth expand/collapse

## Accessibility
- WCAG AA contrast ratios minimum
- Focus states visible
- Semantic HTML
- Alt text for all images
