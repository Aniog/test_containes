# SSourcing China - Design System

## Brand
- Name: SSourcing China
- Tagline: China Sourcing Agent for Global Buyers
- Positioning: Professional, trustworthy, international B2B sourcing partner.

## Color Palette
- Primary: `#0f4c81` (deep trust blue)
- Primary foreground: `#ffffff`
- Secondary: `#f4f7fb` (soft cloud blue-gray)
- Secondary foreground: `#1e293b`
- Accent: `#d97706` (warm amber for CTAs and highlights)
- Accent foreground: `#ffffff`
- Background: `#ffffff`
- Foreground: `#1e293b` (slate-900)
- Muted: `#f1f5f9`
- Muted foreground: `#64748b`
- Border: `#e2e8f0`
- Card: `#ffffff`
- Card foreground: `#1e293b`
- Destructive: `#dc2626`

## Typography
- Headings: Inter, 700/800 weight, tight letter-spacing.
- Body: Inter, 400/500 weight, line-height 1.6.
- Hero headline: `text-4xl md:text-5xl lg:text-6xl font-extrabold tracking-tight`.
- Section titles: `text-3xl md:text-4xl font-bold`.
- Body text: `text-base text-slate-600`.

## Spacing
- Section vertical padding: `py-20 md:py-28`.
- Container: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`.
- Grid gaps: `gap-6 md:gap-8`.

## Components
- Buttons:
  - Primary: `bg-[#0f4c81] text-white hover:bg-[#0d3f6b]` with rounded-md.
  - CTA accent: `bg-[#d97706] text-white hover:bg-[#b45309]`.
- Cards: white background, subtle border, rounded-xl, soft shadow `shadow-sm hover:shadow-md transition`.
- Badges: rounded-full, small text, used for trust indicators and categories.
- Forms: rounded-md borders, focus ring in primary blue.

## Visual Style
- Clean, breathable layouts with generous whitespace.
- Realistic factory, QC, shipping, and product visuals via stock image system.
- Avoid exaggerated claims; use measured, professional language.
- Responsive: single column on mobile, grids on desktop.

## Do's
- Use primary blue for headers, links, and primary actions.
- Use amber accent sparingly for CTAs and key highlights.
- Keep text contrast high and readable.
- Use Lucide icons for services and process steps.

## Don'ts
- No neon colors, no gradients overload.
- No invisible/low-contrast text.
- No mobile-style single-column stacking on large desktop screens.
