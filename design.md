# SSourcing China - Design System

## Visual Style
- **Style**: Clean, professional, trustworthy, international B2B
- **Theme**: Corporate with warm accents - conveying reliability and expertise in China sourcing

## Color Palette
- **Primary**: `#1E3A5F` (Deep navy blue - trust, professionalism)
- **Secondary**: `#2D5A7B` (Medium blue - depth, expertise)
- **Accent**: `#E67E22` (Warm orange - CTA, energy, action)
- **Background Light**: `#F8FAFC` (Off-white)
- **Background Alt**: `#EFF3F8` (Light blue-gray)
- **Text Primary**: `#1F2937` (Dark gray)
- **Text Secondary**: `#6B7280` (Medium gray)
- **Success**: `#059669` (Green for trust indicators)
- **White**: `#FFFFFF`

## Typography
- **Font Family**: Inter (Google Fonts)
- **Headings**: Bold, larger sizes, navy blue
- **Body**: Regular weight, good line height for readability
- **Font Sizes**:
  - Hero: 48px (mobile: 32px)
  - H1: 40px (mobile: 28px)
  - H2: 32px (mobile: 24px)
  - H3: 24px (mobile: 20px)
  - Body: 16px
  - Small: 14px

## Layout & Spacing
- **Container**: max-width 1280px, centered
- **Section Padding**: 80px vertical (mobile: 48px)
- **Component Gap**: 24px-32px
- **Card Padding**: 24px
- **Border Radius**: 8px for cards, 4px for buttons

## Visual Elements
- **Icons**: Lucide React icons - clean, minimal line style
- **Cards**: White background, subtle shadow, rounded corners
- **Images**: Realistic factory/QC/shipping imagery via stock system
- **Trust Indicators**: Checkmarks, badges, statistics

## Do's and Don'ts
### Do
- Use clean white space liberally
- Include realistic factory/warehouse imagery
- Show QC inspection process
- Display shipping/logistics visuals
- Use trust badges and statistics
- Include clear CTAs in accent color
- Show professional team photos

### Don't
- Use flashy animations
- Use low contrast text
- Use more than 3 colors prominently
- Use decorative fonts
- Overcrowd sections
- Use generic stock photos of offices only

## Key UI Patterns
- Hero section with strong headline and CTA
- Service cards in grid layout
- Process steps with numbered icons
- Product category cards
- Case study cards with results
- FAQ accordion
- Contact/inquiry form
- Footer with navigation and contact info
