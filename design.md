# Velmora Fine Jewelry — Visual Style Guide

## Mood
Quiet luxury, warm, editorial. Premium demi-fine jewelry — NOT loud, NOT discount-looking, NOT generic e-commerce.

## Color Palette
- **Base Dark** (deep warm charcoal): `#1C1917` — stone-900. Used for hero backgrounds, nav solid state, footer.
- **Surface Light** (warm cream): `#FAF7F2` — custom. Used for page backgrounds, card backgrounds.
- **Accent Gold** (warm metallic): `#C9A96E` — custom. Used for CTA buttons, highlights, hover states, links.
- **Accent Gold Hover**: `#B8944F` — darker gold for button hover.
- **Text Primary** (rich dark): `#1C1917` — same as base dark. Used for headings, body text on light backgrounds.
- **Text Secondary** (warm gray): `#78716C` — stone-500. Used for descriptions, captions, secondary info.
- **Text On Dark** (warm white): `#F5F0EB` — custom. Used for text on dark backgrounds.
- **Border Hairline** (warm light): `#E7E5E4` — stone-200. Used for thin dividers, card borders.
- **Border Dark** (warm dark): `#292524` — stone-800. Used for dividers on dark backgrounds.

## Typography
- **Heading Font**: Cormorant Garamond (Google Fonts) — elegant serif for headings, product names, hero text.
- **Body Font**: Inter (Google Fonts) — clean sans-serif for body text, UI elements, navigation.
- **Product Names**: UPPERCASE with wide letter-spacing (`tracking-[0.2em]`).
- **Heading Sizes**: H1 `text-4xl md:text-5xl lg:text-6xl`, H2 `text-2xl md:text-3xl`, H3 `text-xl md:text-2xl`.
- **Body Sizes**: Base `text-sm md:text-base`, Small `text-xs md:text-sm`.

## Spacing & Layout
- Generous whitespace. Sections use `py-16 md:py-24 lg:py-32`.
- Container max-width: `max-w-7xl mx-auto px-4 md:px-6 lg:px-8`.
- Grid gaps: `gap-6 md:gap-8`.
- Hairline dividers: `border-t border-stone-200` (1px, warm tone).

## Buttons
- **Primary CTA**: Solid accent gold background (`bg-[#C9A96E]`), dark text (`text-[#1C1917]`), uppercase, wide tracking, medium padding. Hover: darker gold (`bg-[#B8944F]`).
- **Secondary/Outlined**: Transparent bg, accent gold border (`border-[#C9A96E]`), accent gold text. Hover: filled gold.
- **Pill Buttons** (variant selectors): Small, rounded-full, border stone-300. Active state: bg-[#C9A96E] text-[#1C1917].

## Cards
- Product cards: Clean, minimal. Image dominant. Name + price below. Hover: second image fades in, "Add to Cart" appears.
- Soft shadow on hover: `shadow-md`.
- No heavy borders. Subtle `border border-stone-200` or none.

## Animations
- Subtle, smooth. `transition-all duration-300 ease-in-out`.
- Hover image swap: opacity transition.
- Nav: transparent to solid on scroll with smooth bg transition.
- No jarring animations. Everything feels slow and refined.

## Do's
- Use warm tones consistently
- Keep whitespace generous
- Use serif for emotional/editorial moments
- Use hairline dividers between sections
- Keep product names uppercase with wide tracking
- Ensure strong contrast (dark text on light, light text on dark)

## Don'ts
- Don't use cool/blue tones
- Don't crowd elements — give them breathing room
- Don't use heavy shadows or thick borders
- Don't use generic e-commerce patterns (badges, loud CTAs)
- Don't mix serif and sans-serif inconsistently
- Don't use low-contrast text (muted text must still be readable)
