# SSourcing China — Design System

## Brand Identity
- **Company**: SSourcing China
- **Tagline**: China Sourcing Agent for Global Buyers
- **Tone**: Professional, clear, practical, trustworthy, international B2B

## Color Palette
- **Primary Blue**: `#1A3A5C` (deep navy — trust, authority) → Tailwind: `[#1A3A5C]`
- **Accent Red**: `#C0392B` (China red — identity, energy) → Tailwind: `[#C0392B]`
- **Accent Gold**: `#D4A017` (quality, premium) → Tailwind: `[#D4A017]`
- **Light Gray BG**: `#F7F8FA` → Tailwind: `[#F7F8FA]`
- **Mid Gray**: `#6B7280` → Tailwind: `gray-500`
- **Dark Text**: `#1F2937` → Tailwind: `gray-800`
- **White**: `#FFFFFF`
- **Border**: `#E5E7EB` → Tailwind: `gray-200`

## Typography
- **Font**: Inter (Google Fonts)
- **Headings**: `font-bold`, sizes: `text-4xl` (h1), `text-3xl` (h2), `text-2xl` (h3), `text-xl` (h4)
- **Body**: `text-base`, `text-gray-600`
- **Small/Caption**: `text-sm text-gray-500`
- **Line height**: `leading-relaxed` for body, `leading-tight` for headings

## Spacing
- Section padding: `py-16 md:py-24`
- Container: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`
- Card padding: `p-6` or `p-8`
- Gap between cards: `gap-6` or `gap-8`

## Components

### Buttons
- **Primary CTA**: `bg-[#C0392B] hover:bg-[#a93226] text-white font-semibold px-6 py-3 rounded-lg transition-colors`
- **Secondary**: `border-2 border-[#1A3A5C] text-[#1A3A5C] hover:bg-[#1A3A5C] hover:text-white font-semibold px-6 py-3 rounded-lg transition-colors`
- **Ghost/Link**: `text-[#1A3A5C] hover:text-[#C0392B] font-medium underline-offset-4 hover:underline`

### Cards
- `bg-white rounded-xl shadow-sm border border-gray-200 p-6 hover:shadow-md transition-shadow`

### Section Headers
- Centered label: `text-sm font-semibold text-[#C0392B] uppercase tracking-widest mb-2`
- Main heading: `text-3xl md:text-4xl font-bold text-[#1A3A5C] mb-4`
- Subheading: `text-lg text-gray-600 max-w-2xl mx-auto`

### Navbar
- `bg-white border-b border-gray-200 sticky top-0 z-50`
- Logo: `text-[#1A3A5C] font-bold text-xl`
- Nav links: `text-gray-600 hover:text-[#1A3A5C] font-medium`

### Hero Section
- Background: dark navy `bg-[#1A3A5C]` with subtle overlay
- Headline: `text-4xl md:text-6xl font-bold text-white`
- Subheadline: `text-xl text-blue-100`

## Do's
- Use navy (#1A3A5C) for headings and primary UI elements
- Use red (#C0392B) for CTAs and accent highlights
- Use generous whitespace between sections
- Use card grids for services, products, features
- Keep forms clean with clear labels
- Use trust badges and numbers prominently

## Don'ts
- Don't use light text on light backgrounds
- Don't use more than 3 colors in one section
- Don't use decorative fonts — keep Inter throughout
- Don't use exaggerated marketing language
- Don't crowd sections — breathe
