# SSourcing China — Design System

## Brand Identity
- Company: SSourcing China
- Tagline: China Sourcing Agent for Global Buyers
- Tone: Professional, trustworthy, international, B2B, practical

## Color Palette
- Primary Blue: `#1A3C6E` (deep navy — trust, authority) → Tailwind: `blue-900` or custom `brand-blue`
- Accent Red: `#C0392B` (China red — identity, energy) → Tailwind: custom `brand-red`
- Light Blue: `#2E86C1` (action, links) → Tailwind: custom `brand-light`
- Background Light: `#F4F7FB` → Tailwind: custom `brand-bg`
- Surface White: `#FFFFFF`
- Text Dark: `#1A1A2E` → Tailwind: `gray-900`
- Text Muted: `#6B7280` → Tailwind: `gray-500`
- Border: `#E5E7EB` → Tailwind: `gray-200`
- Success Green: `#27AE60`

## Typography
- Font: Inter (Google Fonts)
- Headings: font-bold, tracking-tight
- Body: font-normal, leading-relaxed
- H1: text-4xl md:text-5xl lg:text-6xl
- H2: text-3xl md:text-4xl
- H3: text-xl md:text-2xl
- Body: text-base md:text-lg
- Small/Caption: text-sm

## Spacing
- Section padding: py-16 md:py-24
- Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8
- Gap between cards: gap-6 md:gap-8

## Components
- Primary Button: bg-brand-red text-white px-6 py-3 rounded-lg font-semibold hover:bg-red-700 transition
- Secondary Button: border-2 border-brand-blue text-brand-blue px-6 py-3 rounded-lg font-semibold hover:bg-brand-blue hover:text-white transition
- Card: bg-white rounded-xl shadow-sm border border-gray-200 p-6
- Section Header: centered, H2 with colored underline accent
- Badge: bg-blue-100 text-brand-blue text-sm px-3 py-1 rounded-full

## Do's
- Use generous whitespace
- Keep CTAs prominent and red
- Use trust signals (numbers, certifications, flags)
- Use clean grid layouts for services/products
- Maintain consistent section rhythm

## Don'ts
- No dark backgrounds for body text
- No cluttered layouts
- No exaggerated superlatives
- No small unreadable text on colored backgrounds
