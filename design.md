# SSourcing China - Design System

## Brand Identity
- Professional B2B sourcing agent website
- Clean, trustworthy, international feel
- Target: overseas buyers looking for China sourcing support

## Colors
- Primary: `brand-navy` (#1B2A4A) - trust, authority
- Primary accent: `brand-blue` (#2563EB) - action, links
- Secondary: `brand-orange` (#F97316) - CTAs, highlights
- Background: `brand-light` (#F8FAFC) - clean white-ish
- Surface: `brand-white` (#FFFFFF) - cards
- Text primary: `brand-dark` (#1E293B)
- Text secondary: `brand-muted` (#64748B)
- Border: `brand-border` (#E2E8F0)
- Success: `brand-green` (#16A34A)

## Typography
- Font: Inter (Google Fonts)
- Headings: font-bold, tracking-tight
- H1: text-4xl md:text-5xl lg:text-6xl
- H2: text-3xl md:text-4xl
- H3: text-xl md:text-2xl
- Body: text-base (16px), text-brand-dark
- Small/muted: text-sm, text-brand-muted

## Spacing
- Section padding: py-16 md:py-24
- Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8
- Gap between cards: gap-6 md:gap-8

## Components
- Buttons primary: bg-brand-orange text-white font-semibold px-6 py-3 rounded-lg hover:bg-orange-600 transition
- Buttons secondary: border-2 border-brand-navy text-brand-navy font-semibold px-6 py-3 rounded-lg hover:bg-brand-navy hover:text-white transition
- Cards: bg-white rounded-xl shadow-sm border border-brand-border p-6
- Badges: inline-flex px-3 py-1 rounded-full text-sm font-medium bg-blue-50 text-brand-blue

## Do's
- Use generous whitespace
- Keep text readable with high contrast
- Use icons (Lucide) to support text
- Use stock images for factory, QC, shipping contexts
- Maintain consistent section structure

## Don'ts
- No dark backgrounds with light text for main content (except hero/navy sections)
- No exaggerated marketing claims
- No cluttered layouts
- No magic hex values outside the defined palette
