# SSourcing China Design Guide

## Brand personality
SSourcing China should feel clean, trustworthy, international, and practical. The visual style should support qualified B2B sourcing inquiries from overseas buyers without exaggerated claims.

## Color system
- Primary navy: use Tailwind `slate-950`, `slate-900`, and `slate-800` for headers, navigation, and high-trust content.
- Action blue: use `blue-700`, `blue-600`, and `blue-50` for CTAs, links, process indicators, and focus states.
- Industrial neutrals: use `slate-100`, `slate-200`, `slate-500`, and `white` for page backgrounds, dividers, cards, and secondary text.
- Trust accents: use `emerald-600` and `emerald-50` sparingly for verification, QC, and successful outcomes.
- Warning/attention accents: use `amber-500` and `amber-50` lightly for risk reduction and problem-solving sections.

## Typography
- Use Inter as the default font.
- Headings should be strong, direct, and businesslike with `font-semibold` or `font-bold`.
- Body text should be practical and readable using `text-slate-600` or `text-slate-700` on light backgrounds.
- Avoid overly decorative typography.

## Layout and spacing
- Use wide, centered containers: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`.
- Use generous vertical spacing: `py-16`, `py-20`, or `py-24` for major sections.
- Cards should use `rounded-2xl`, `border border-slate-200`, `bg-white`, and subtle shadows such as `shadow-sm`.
- Desktop layouts should use multi-column grids where appropriate. Mobile layouts should stack clearly using responsive Tailwind breakpoints.

## Imagery
- Use realistic factory, quality inspection, warehouse, shipping, and international trade visuals.
- Use the Strikingly stock image attributes with contextual text references rather than hardcoded image URLs.
- Do not overuse images; place them where they support trust and clarity.

## UI components
- Buttons: primary CTAs should use `bg-blue-700 text-white hover:bg-blue-800`. Secondary buttons should use white backgrounds with slate borders.
- Forms: use clear labels, visible borders, white backgrounds, and readable text. Required fields should be obvious.
- Badges: use subtle backgrounds like `bg-blue-50 text-blue-700` or `bg-emerald-50 text-emerald-700`.

## Do's
- Keep claims specific and practical.
- Make every CTA easy to find.
- Use explicit foreground colors for every important content area.
- Emphasize supplier verification, factory audits, QC inspection, production follow-up, and shipping coordination.

## Don'ts
- Do not use neon colors or consumer-style gradients.
- Do not make exaggerated promises such as guaranteed lowest price or zero risk.
- Do not use low-contrast text.
- Do not crowd mobile screens with dense columns.
