# SSourcing China - Design Guidelines

## Project Overview
- **Project Name**: SSourcing China Website
- **Type**: B2B Corporate Website
- **Purpose**: Generate qualified sourcing inquiries for China sourcing agent services
- **Target Audience**: Overseas buyers, procurement managers, business owners looking for reliable Chinese suppliers

## Visual Style

### Overall Aesthetic
- Clean, professional, trustworthy, international B2B
- No exaggerated claims - practical and results-oriented
- Realistic factory/QC/shipping visuals
- Modern corporate design with subtle warmth

### Color Palette
- **Primary**: `#1E3A5F` (Deep Navy Blue - trust, professionalism)
- **Secondary**: `#2D5A87` (Medium Blue - approachable)
- **Accent**: `#E67E22` (Warm Orange - CTAs, energy)
- **Success**: `#27AE60` (Green - trust indicators)
- **Background Light**: `#F8FAFC` (Off-white)
- **Background Dark**: `#0F172A` (Dark navy for footer)
- **Text Primary**: `#1E293B` (Dark slate)
- **Text Secondary**: `#64748B` (Muted slate)
- **Border**: `#E2E8F0` (Light gray)

### Typography
- **Headings**: "Plus Jakarta Sans" - modern, geometric, professional
- **Body**: "Inter" - clean, readable, international
- **Font Sizes**:
  - H1: 48px (hero), 36px (page titles)
  - H2: 32px (section titles)
  - H3: 24px (card titles)
  - Body: 16px
  - Small: 14px

### Spacing System
- Section padding: 80px vertical (desktop), 48px (mobile)
- Container max-width: 1200px
- Card padding: 24px
- Grid gap: 32px

### Visual Effects
- Subtle box shadows: `0 4px 6px -1px rgba(0,0,0,0.1)`
- Card hover: slight lift with shadow increase
- Smooth transitions: 300ms ease
- Border radius: 8px (cards), 4px (buttons)

## Layout Structure

### Header
- Logo (left): "SSourcing China" with subtle icon
- Navigation (center): Home, Services, How It Works, Products, Case Studies, Blog, Contact
- CTA Button (right): "Get a Free Quote"
- Sticky on scroll with subtle shadow
- Mobile: hamburger menu

### Footer
- 4-column layout: Company, Services, Resources, Contact
- Social links
- Copyright
- Dark background

## Components

### Buttons
- Primary: Orange background, white text
- Secondary: Navy outline, navy text
- Hover: Slight darken/lighten

### Cards
- White background
- Subtle shadow
- Hover: lift effect
- Icon + title + description format

### Form Inputs
- Clean borders
- Focus: blue border
- Error: red border with message

### Icons
- Lucide React icons
- Consistent sizing (24px standard)

## Responsive Breakpoints
- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px

## Do's and Don'ts
- DO: Use professional imagery, clear CTAs, concise copy
- DON'T: Use overly salesy language, stock photos that look fake, cluttered layouts
- DO: Maintain consistent spacing and alignment
- DON'T: Mix too many font weights or colors
