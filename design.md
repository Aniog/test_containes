# SSourcing China - Design System

## Brand Identity
- Brand: SSourcing China - China-based sourcing agent for global buyers
- Tone: Professional, trustworthy, international, B2B, practical, confident but not exaggerated
- Goal: Generate qualified sourcing inquiries

## Typography
- Font Family: Inter (sans-serif), loaded from Google Fonts
- Headings: font-semibold or font-bold, tracking-tight
- Body: font-normal, leading-relaxed
- Sizes: xs (12px), sm (14px), base (16px), lg (18px), xl (20px), 2xl (24px), 3xl (30px), 4xl (36px), 5xl (48px)

## Colors
- Primary (navy blue): #1e3a5f - main brand color, headers, buttons
- Primary-light: #2d5a87 - hover states
- Primary-dark: #142b47 - darker variant
- Secondary (amber): #d97706 - CTA buttons, highlights
- Secondary-light: #f59e0b - CTA hover
- Accent (teal): #0d9488 - quality/trust accents
- Background: #ffffff - page backgrounds
- Background-alt: #f8fafc - alternate section backgrounds
- Background-warm: #fffbeb - warm highlight backgrounds
- Text: #1e293b - body text
- Text-muted: #64748b - secondary text
- Text-light: #94a3b8 - placeholder text
- Border: #e2e8f0 - card borders, dividers
- Success: #16a34a - verification badges
- White: #ffffff

## Spacing
- Section padding: py-16 md:py-24
- Container max-width: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8
- Gap between sections: space-y-4 or gap-8

## Borders & Shadows
- Card borders: border border-gray-200 rounded-xl
- Card shadows: shadow-sm hover:shadow-md transition-shadow
- Buttons: rounded-lg
- Inputs: rounded-lg border border-gray-300

## Component Styles

### Buttons
- Primary CTA: bg-amber-600 hover:bg-amber-700 text-white font-semibold rounded-lg px-6 py-3
- Secondary: bg-primary hover:bg-primary-light text-white font-semibold rounded-lg px-6 py-3
- Outline: border-2 border-primary text-primary hover:bg-primary hover:text-white font-semibold rounded-lg px-6 py-3

### Cards
- bg-white rounded-xl border border-gray-200 shadow-sm p-6 md:p-8
- Hover: shadow-md transition-all duration-200

### Navigation
- Fixed top, white background, subtle bottom border
- Links: text-gray-600 hover:text-primary font-medium
- Mobile: hamburger menu

### Form Elements
- Inputs: w-full rounded-lg border border-gray-300 px-4 py-3 focus:ring-2 focus:ring-primary focus:border-primary
- Labels: block text-sm font-medium text-gray-700 mb-1
- Textarea: same as input with min-h-[120px]

### Section Headers
- text-3xl md:text-4xl font-bold text-gray-900 text-center
- Subtitle: text-lg text-gray-600 text-center max-w-2xl mx-auto mt-4

## Do's
- Use ample white space
- Keep clean, minimal layouts
- Use professional, high-quality imagery
- Emphasize trust signals (badges, certifications, numbers)
- Use clear CTAs
- Responsive design on all breakpoints

## Don'ts
- Don't use exaggerated claims or hype language
- Don't use low-quality or generic stock photos
- Don't overcrowd sections
- Don't use bright, flashy colors that reduce professionalism
- Don't use Comic Sans or informal fonts
- Don't use dark backgrounds for main content areas
