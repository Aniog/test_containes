# SSourcing China Visual Design Guide

## Brand direction
SSourcing China should feel clean, trustworthy, international, and practical for B2B buyers. The interface should communicate operational competence rather than hype.

## Color system
Use a restrained professional palette:
- Deep navy for headings and primary surfaces: `brand-950`, `brand-900`, `brand-800`.
- Operational blue for primary actions and links: `brand-700`, `brand-600`.
- Warm amber as a measured accent for highlights: `accent-500`, `accent-100`.
- Soft industrial neutrals for backgrounds and borders: `sand-50`, `sand-100`, `slate` defaults.

Do use high-contrast foreground/background pairs such as navy text on white or sand backgrounds, and white text on navy/blue surfaces. Do not use pale gray text for important business information.

## Typography
Use Inter from Google Fonts. Headings should be firm and clear with tight tracking, e.g. `font-semibold tracking-tight`. Body text should use comfortable line height, e.g. `leading-7`.

## Layout and spacing
Use generous B2B spacing with clear sections: `py-16 md:py-24`, max width `max-w-7xl`, and consistent `px-4 sm:px-6 lg:px-8`. Desktop layouts should use multi-column grids where helpful; mobile should stack cleanly.

## Components
Cards should use white surfaces, subtle borders, and soft shadows: `rounded-2xl border border-slate-200 bg-white shadow-sm`. Primary buttons use `bg-brand-700 text-white hover:bg-brand-800`. Secondary buttons use a white background with navy text and a slate border.

## Imagery
Use realistic factory, quality inspection, supplier meeting, production, warehouse, and shipping visuals via the Strikingly image tagging system. Images should feel documentary and business-oriented, not overly polished or exaggerated.
