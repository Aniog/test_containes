# SSourcing China - Design Guidelines

## Brand Overview
SSourcing China is a professional China-based sourcing agent helping overseas B2B buyers find reliable suppliers, verify factories, inspect quality, follow production, and coordinate shipping.

**Tone:** Professional, clear, practical, trustworthy. No exaggerated claims.

## Color Palette

### Primary Colors
- **Primary Navy:** `#0A2540` - Deep, trustworthy navy for headers and primary text
- **Primary Blue:** `#1E40AF` - Professional blue for CTAs and links
- **Accent Blue:** `#2563EB` - Brighter blue for hover states

### Neutral Colors
- **Dark Gray:** `#1F2937` - Body text
- **Medium Gray:** `#4B5563` - Secondary text
- **Light Gray:** `#6B7280` - Muted text, borders
- **Border Gray:** `#E5E7EB` - Dividers, card borders
- **Background Light:** `#F9FAFB` - Section backgrounds
- **White:** `#FFFFFF` - Cards, modals, overlays

### Accent Colors
- **Success Green:** `#059669` - Trust indicators, completed steps
- **Warm Gold:** `#B45309` - Subtle accent for highlights (sparingly)

## Typography

### Font Stack
Primary: Inter, system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif

### Type Scale
- **H1 (Hero):** 48px / 56px, font-weight: 700, color: #0A2540
- **H2 (Section):** 32px / 40px, font-weight: 600, color: #0A2540
- **H3 (Card):** 20px / 28px, font-weight: 600, color: #1F2937
- **Body:** 16px / 24px, font-weight: 400, color: #1F2937
- **Small:** 14px / 20px, font-weight: 400, color: #4B5563
- **Caption:** 12px / 16px, font-weight: 400, color: #6B7280

- Error text: 13px, #DC2626

## Trust Indicators
- Use subtle checkmarks (lucide Check icon)
- Client logos in grayscale, 50% opacity
- Statistics in large numbers with small labels
- Certifications as clean badges

## Image Usage
- Factory, QC, shipping visuals should be realistic and professional
- Use data-strk-img for stock images with appropriate B2B queries
- Maintain consistent aspect ratios across similar elements
- Avoid overly staged or stock-photo-looking images

## Responsive Breakpoints
- Mobile: < 768px
- Tablet: 768px - 1024px
- Desktop: > 1024px

## Do's
- Use ample white space for clean, professional feel
- Keep copy concise and benefit-focused
- Use data and specifics (numbers, timelines, processes)
- Maintain consistent icon style (lucide-react, stroke width 2)
- Ensure all text has sufficient contrast

## Don'ts
- No bright gradients or flashy effects
- No exaggerated claims ("#1", "best", "guaranteed")
- No cluttered layouts or excessive icons
- No decorative elements that don't serve purpose
- No low-contrast text or subtle grays for body copy
