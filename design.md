# SSourcing China Design System

## Brand personality
Professional, trustworthy, practical, and international. The website should feel like a reliable B2B partner for overseas buyers sourcing from China.

## Color palette
Use named Tailwind theme colors rather than arbitrary hex values in JSX.
- `brand-navy` for headers, primary text, and strong trust cues.
- `brand-blue` for primary buttons, active navigation, links, and key accents.
- `brand-sky` for soft highlights and section backgrounds.
- `brand-slate` for secondary text.
- `brand-mist` for page backgrounds and muted panels.
- `brand-line` for borders and dividers.
- `brand-green` for positive operational indicators.
- `brand-orange` for selective warm CTA accents.

## Typography
Use Inter from Google Fonts. Headings should be clear, compact, and confident with `font-semibold` or `font-bold`. Body copy should use practical, plain English with readable line lengths.

## Layout and spacing
Use generous white space, structured cards, and consistent section spacing. Desktop layouts should use balanced multi-column grids. Mobile layouts should stack cleanly with comfortable spacing.

## Components
- Buttons: rounded, high-contrast, with clear hover states.
- Cards: white or soft blue surfaces, subtle borders, and light shadows.
- Forms: large fields, visible labels, clear helper text, and strong error/success contrast.
- Navigation: sticky top bar with clear active anchors and a visible quote CTA.
- Images: realistic factory, inspection, quality control, logistics, supplier, and shipping visuals via the Strikingly stock image tagging system.

## Do
- Use practical B2B language.
- Make all text high contrast and easy to read.
- Pair custom backgrounds with explicit foreground colors.
- Keep visual rhythm consistent across all pages.

## Don't
- Do not use exaggerated claims such as guaranteed savings or risk-free sourcing.
- Do not use low-contrast text.
- Do not use hardcoded image URLs or arbitrary hex colors in JSX.
