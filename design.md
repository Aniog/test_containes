# SSourcing China - Design Guidelines

## Brand Identity
- Professional B2B sourcing agent website
- Trustworthy, clean, international feel
- Target audience: overseas buyers, import managers, procurement teams

## Typography
- Primary font: Inter (Google Fonts)
- Headings: font-weight 700-800, tracking tight
- Body: font-weight 400, line-height 1.6
- Small text: font-weight 500, tracking normal

## Colors
- Primary: Deep navy blue (#1e40af) - trust, professionalism
- Primary dark: (#1e3a8a) - hover states, emphasis
- Accent: Amber (#d97706) - CTAs, highlights, warmth
- Text primary: Slate 800 (#1e293b)
- Text secondary: Slate 500 (#64748b)
- Background: White (#ffffff)
- Section alt: Slate 50 (#f8fafc)
- Border: Slate 200 (#e2e8f0)

## Spacing
- Section padding: py-16 md:py-24
- Container max-width: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8
- Element gaps: gap-6 md:gap-8

## Components
- Buttons: rounded-lg, font-semibold, px-6 py-3
- Primary button: bg-brand-500 text-white hover:bg-brand-600
- Secondary button: border-2 border-brand-500 text-brand-500 hover:bg-brand-50
- Cards: bg-white rounded-xl shadow-sm border border-neutral-200
- Section headings: text-3xl md:text-4xl font-bold text-neutral-800

## Visual Style
- Clean white backgrounds with subtle section alternation
- Professional stock imagery of factories, QC, shipping
- Icons from Lucide React for service features
- Subtle shadows and borders, no heavy gradients
- Generous whitespace for readability

## Do's
- Use consistent spacing and alignment
- Keep text concise and scannable
- Use data and specifics over vague claims
- Ensure high contrast for readability
- Use amber/gold for CTAs to stand out against blue

## Don'ts
- Don't use exaggerated marketing language
- Don't use dark backgrounds with dark text
- Don't overcrowd sections with too much content
- Don't use decorative elements that don't serve information
- Don't use low-contrast text combinations
