# SSourcing China - Design Guidelines

## Project Overview
- **Project Name**: SSourcing China Website
- **Type**: B2B Corporate Website
- **Purpose**: Generate qualified sourcing inquiries for China sourcing agent services
- **Target Audience**: Overseas buyers, procurement managers, business owners looking for reliable Chinese suppliers

## Visual Style
- **Tone**: Professional, trustworthy, clean, international B2B
- **Aesthetic**: Modern corporate with subtle industrial/manufacturing undertones

## Color Palette
- **Primary**: `#1a365d` (Deep Navy Blue - trust, professionalism)
- **Primary Light**: `#2c5282` (Medium Blue)
- **Secondary**: `#c53030` (Professional Red - action, China connection)
- **Accent**: `#d69e2e` (Gold - quality, premium)
- **Background**: `#f7fafc` (Light Gray)
- **Surface**: `#ffffff` (White)
- **Text Primary**: `#1a202c` (Near Black)
- **Text Secondary**: `#4a5568` (Gray)
- **Text Muted**: `#718096` (Light Gray)
- **Border**: `#e2e8f0` (Light Border)
- **Success**: `#38a169` (Green)

## Typography
- **Font Family**: "Inter", system-ui, sans-serif
- **Headings**: 
  - H1: 48px/56px, font-weight 800
  - H2: 36px/44px, font-weight 700
  - H3: 24px/32px, font-weight 600
  - H4: 20px/28px, font-weight 600
- **Body**: 16px/24px, font-weight 400
- **Small**: 14px/20px, font-weight 400

## Spacing System
- **Base unit**: 4px
- **Section padding**: 80px vertical (desktop), 48px (mobile)
- **Container max-width**: 1200px
- **Grid gap**: 24px (desktop), 16px (mobile)

## Visual Elements
- **Border radius**: 8px (cards), 4px (buttons), 2px (inputs)
- **Shadows**: 
  - Card: `0 4px 6px -1px rgba(0, 0, 0, 0.1)`
  - Elevated: `0 10px 15px -3px rgba(0, 0, 0, 0.1)`
- **Transitions**: 200ms ease-in-out

## Layout Principles
- Clean, generous whitespace
- Clear visual hierarchy
- Card-based content sections
- Consistent alignment
- Mobile-responsive (breakpoints: 640px, 768px, 1024px, 1280px)

## Component Guidelines

### Buttons
- **Primary**: Navy background, white text, red hover accent
- **Secondary**: White background, navy border, navy text
- **CTA**: Red background, white text (prominent)

### Cards
- White background
- Subtle shadow
- 8px border radius
- 24px padding

### Icons
- Lucide React icons
- Consistent sizing (24px standard, 20px small, 32px large)
- Muted colors for secondary icons

### Images
- Realistic factory/QC/shipping visuals
- Professional photography style
- Consistent aspect ratios (16:9 for hero, 4:3 for cards)

## Do's and Don'ts
- DO: Use professional, measured language
- DO: Include trust signals (certifications, stats, testimonials)
- DO: Use clear CTAs
- DON'T: Use exaggerated claims or hyperbolic language
- DON'T: Use overly flashy animations
- DON'T: Use low-quality or stock-photo-looking images
- DON'T: Clutter the design with too many elements

## Page Structure

### Homepage Sections
1. **Header**: Logo, navigation, CTA button
2. **Hero**: Headline, subheadline, CTA, background image
3. **Services Overview**: 4-6 service cards
4. **Sourcing Process**: Step-by-step visual flow
5. **Products We Source**: Category grid
6. **Problems We Solve**: Pain points and solutions
7. **Trust Points**: Stats, certifications, guarantees
8. **Case Studies**: Success story cards
9. **FAQ**: Expandable questions
10. **Inquiry Form**: Lead capture form
11. **Footer**: Links, contact info, copyright

### All Pages
- Consistent header and footer
- Breadcrumb navigation where appropriate
- Mobile hamburger menu
