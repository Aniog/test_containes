# SSourcing China - Design System

## Brand Identity
- **Tone**: Professional, trustworthy, international B2B
- **Feel**: Clean, confident, no-nonsense — like a reliable business partner

## Color Palette

### Primary Colors
- **Navy Blue** (primary): `#1B3A5C` — Trust, authority, professionalism
- **Sky Blue** (primary-light): `#2E6BAD` — Approachable, modern
- **Accent Orange**: `#E87722` — CTA buttons, highlights, energy
- **Accent Orange Hover**: `#D06818` — CTA hover state

### Neutral Colors
- **White**: `#FFFFFF` — Backgrounds, cards
- **Light Gray**: `#F7F8FA` — Section backgrounds
- **Mid Gray**: `#E5E7EB` — Borders, dividers
- **Dark Gray**: `#4B5563` — Body text
- **Charcoal**: `#1F2937` — Headings
- **Near Black**: `#111827` — Footer background

### Semantic Colors
- **Success Green**: `#059669` — Trust badges, checkmarks
- **Warning Amber**: `#D97706` — Caution indicators

## Typography
- **Font Family**: Inter (Google Fonts)
- **Headings**: font-weight 700 (bold), color charcoal `#1F2937`
- **Body**: font-weight 400, color dark gray `#4B5563`
- **Lead/Intro**: font-weight 400, size 18px, color `#4B5563`

### Scale
- H1: 48px / 3rem (desktop), 32px / 2rem (mobile)
- H2: 36px / 2.25rem (desktop), 28px / 1.75rem (mobile)
- H3: 24px / 1.5rem
- H4: 20px / 1.25rem
- Body: 16px / 1rem
- Small: 14px / 0.875rem

## Spacing
- Section padding: 80px vertical (desktop), 48px (mobile)
- Container max-width: 1200px, centered
- Card padding: 24px–32px
- Grid gap: 24px–32px

## Components

### Buttons
- **Primary CTA**: bg `#E87722`, text white, rounded-lg, px-6 py-3, font-semibold, hover:bg `#D06818`
- **Secondary**: border navy `#1B3A5C`, text navy, bg transparent, rounded-lg, px-6 py-3, hover:bg navy hover:text-white
- **Ghost**: text navy, underline, no bg

### Cards
- White background, rounded-xl, shadow-sm, border `#E5E7EB`
- Hover: shadow-md, slight translateY(-2px)

### Sections
- Alternating white and `#F7F8FA` backgrounds
- Each section has a heading + optional subtitle centered

### Navigation
- Sticky top, white bg, shadow-sm on scroll
- Logo left, nav links center/right, CTA button right
- Mobile: hamburger menu

### Footer
- Dark background `#111827`, white/light text
- 4-column layout: About, Services, Resources, Contact
- Copyright bar at bottom

## Visual Style
- Use stock images of: factories, quality inspection, shipping containers, warehouses, business meetings
- Icons: Lucide React, stroke style, navy or orange
- Subtle rounded corners on cards and images
- Clean whitespace — no clutter
- No gradients on backgrounds (solid colors only)
- No exaggerated claims or hype language

## Do's
- Use generous whitespace
- Keep text concise and scannable
- Use real business language
- Show trust signals (certifications, years, client count)
- Use orange CTAs sparingly for maximum impact

## Don'ts
- Don't use dark text on dark backgrounds
- Don't use more than 2 colors for text (charcoal for headings, dark gray for body)
- Don't use decorative gradients or glassmorphism
- Don't use cartoon illustrations — use photos or clean icons
- Don't use superlatives like "best", "#1", "world-class"
