# SSourcing China - Design Specification

## Project Overview
- **Project Name**: SSourcing China Website
- **Type**: B2B Corporate Website
- **Core Functionality**: China sourcing agent website to generate qualified sourcing inquiries
- **Target Users**: Overseas buyers seeking reliable Chinese suppliers

## Visual Style

### Overall Aesthetic
- Clean, professional, trustworthy, international B2B
- Realistic factory/QC/shipping visuals
- No exaggerated claims - practical and clear messaging

### Color Palette
- **Primary**: #1E3A5F (Deep Navy Blue - trust, professionalism)
- **Secondary**: #2D5A87 (Medium Blue - reliability)
- **Accent**: #E67E22 (Warm Orange - CTA buttons, energy)
- **Success**: #27AE60 (Green - trust indicators)
- **Background Light**: #F8FAFC (Off-white)
- **Background Dark**: #0F172A (Dark navy for footer)
- **Text Primary**: #1E293B (Dark slate)
- **Text Secondary**: #64748B (Muted slate)
- **Border**: #E2E8F0 (Light gray)

### Typography
- **Headings**: "Plus Jakarta Sans" - modern, professional, geometric
- **Body**: "Inter" - clean, readable, international
- **Font Sizes**:
  - H1: 48px (hero), 36px (page titles)
  - H2: 32px (section titles)
  - H3: 24px (card titles)
  - Body: 16px
  - Small: 14px

### Layout & Spacing
- Max content width: 1200px
- Section padding: 80px vertical (desktop), 48px (mobile)
- Card padding: 24px
- Grid gap: 32px
- Border radius: 8px (cards), 4px (buttons)

### Visual Effects
- Subtle box shadows on cards: 0 4px 6px -1px rgba(0,0,0,0.1)
- Hover transitions: 0.3s ease
- Clean dividers between sections

## Page Structure

### 1. Homepage
- **Header**: Logo, navigation, CTA button
- **Hero Section**: Headline, subheadline, primary CTA, trust indicators
- **Services Section**: 6 service cards (Supplier Verification, Quality Inspection, Production Follow-up, Shipping Coordination, Sourcing, Custom Solutions)
- **Sourcing Process**: 5-step process visualization
- **Products We Source**: Grid of product categories
- **Problems We Solve**: Pain points and solutions
- **Trust Points**: Stats, certifications, guarantees
- **Case Studies**: 3 featured success stories
- **FAQ Section**: Expandable accordion
- **Inquiry Form**: Lead capture form
- **Footer**: Links, contact info, copyright

### 2. Services Page
- Detailed service descriptions
- Process explanations
- Pricing transparency (indicative)

### 3. How It Works Page
- Step-by-step visual guide
- Timeline visualization

### 4. Products We Source Page
- Category grid with descriptions
- Sourcing capabilities

### 5. Case Studies Page
- Success stories with results
- Client testimonials

### 6. Blog Page
- Article grid
- Category filters

### 7. Contact Page
- Contact form
- Company information
- Map placeholder

## Components

### Navigation
- Sticky header
- Mobile hamburger menu
- Active state indicator

### Buttons
- Primary: Orange background, white text
- Secondary: Navy outline
- Hover: Darken by 10%

### Cards
- White background
- Subtle shadow
- Icon + title + description
- Optional CTA link

### Form Elements
- Clean input fields
- Clear labels
- Validation states

### Trust Indicators
- Statistics with icons
- Client logos
- Certification badges

## Responsive Breakpoints
- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px

## Do's and Don'ts
- DO: Use professional imagery, clear typography, consistent spacing
- DON'T: Use overly flashy animations, exaggerated claims, cluttered layouts
- DO: Include real statistics and practical benefits
- DON'T: Use generic stock photos that look fake
