# SSourcing China - Design System

## Brand Colors
- Primary Navy: #1E3A5F (headings, primary buttons, nav background)
- Primary Dark: #0F2440 (footer, dark sections)
- Primary Light: #2D6B9E (hover states, secondary elements)
- Accent Orange: #E67E22 (CTAs, highlights, accent elements)
- Accent Hover: #D35400 (CTA hover state)
- Success Green: #27AE60 (trust badges, positive indicators)

## Neutral Colors
- White: #FFFFFF (page backgrounds, cards)
- Light Gray: #F7F8FA (section backgrounds, subtle highlights)
- Border Gray: #E2E8F0 (borders, dividers)
- Medium Gray: #718096 (body text, secondary text)
- Dark Text: #1A202C (primary text color)
- Near Black: #0F172A (hero text, heavy emphasis)

## Typography
- Headings: Inter, font-weight 600-800
- Body: Inter, font-weight 400-500
- Font sizes: text-sm (14px), text-base (16px), text-lg (18px), text-xl (20px), text-2xl (24px), text-3xl (30px), text-4xl (36px), text-5xl (48px)

## Spacing
- Section padding: py-16 lg:py-24
- Container max-width: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 lg:p-8
- Gap between sections: space-y-4 lg:space-y-6

## Borders & Shadows
- Cards: rounded-lg border border-gray-200 shadow-sm
- Elevated cards: rounded-xl shadow-md
- Buttons: rounded-lg font-semibold
- Inputs: rounded-lg border border-gray-300

## Visual Style
- Clean, professional, minimal
- Lots of white space
- Card-based layouts for service listings
- Grid layouts for product categories
- Left-aligned text for body content, centered for hero sections
- Use icons from Lucide React for service/feature illustrations
- Background images for hero sections use data-strk-bg attributes
- Product/case study images use data-strk-img attributes

## Do's
- Use consistent navy + orange color scheme
- Keep plenty of whitespace between sections
- Use professional, clear language
- Include trust indicators (badges, certifications, numbers)
- Make CTAs prominent with the accent orange
- Use divider lines between sections

## Don'ts
- Don't use overly bright or saturated colors
- Don't use exaggerated claims or hype language
- Don't overcrowd sections with too much text
- Don't use unprofessional fonts
- Don't use generic stock photos without context
