# Velmora Fine Jewelry — Design System

## Visual Identity
**Mood:** Quiet luxury, warm, editorial. Premium demi-fine jewelry — NOT loud, NOT discount-looking, NOT generic e-commerce.

## Color Palette

| Token | Hex | Usage |
|-------|-----|-------|
| `cream` | #F5F0EB | Light backgrounds, body bg |
| `warm-dark` | #2D2926 | Primary text on light |
| `charcoal` | #1C1917 | Dark section backgrounds, nav solid |
| `gold` | #C9A96E | Accent color, buttons, highlights |
| `gold-light` | #D4B87A | Hover states, lighter gold |
| `muted` | #9C8E80 | Secondary text, captions |
| `warm-border` | #D4C5B5 | Hairline dividers, borders |
| `warm-white` | #FAFAF7 | Card backgrounds, inputs |
| `rose` | #E8D5C4 | Soft accent for UGC overlays |

## Typography

- **Headings & Product Names:** Cormorant Garamond (serif), weight 400–600
- **Body & UI:** Inter (sans-serif), weight 300–500
- **Product names:** UPPERCASE, letter-spacing 0.15em
- **Section headings:** UPPERCASE, letter-spacing 0.2em, smaller size
- **Body text:** 16px base, line-height 1.6

## Spacing & Layout
- Generous whitespace: sections 80–120px vertical padding
- Grid gaps: 24–32px
- Hairline dividers: 1px `warm-border`
- Max content width: 1280px

## Buttons
- Primary: solid `gold` bg, `cream` text, rounded-none or slight rounded, uppercase, letter-spacing 0.1em
- Secondary: outlined `gold` border, `gold` text, same typography
- Hover: subtle darken, smooth 200ms transition
- Padding: 12px 32px minimum

## Cards
- Product cards: minimal, `warm-white` bg, no heavy shadows
- Hover: second image swap, subtle scale or shadow
- Soft shadow on hover: `shadow-md` with warm tone

## Images
- Editorial, warm-lit, gold jewelry on dark/neutral backgrounds
- Hero: full-bleed, 16:9 or wider
- Product: 4:3 or 3x4
- UGC: 9:16 vertical

## Animations
- Subtle, smooth: 200–300ms transitions
- No jarring animations
- Hover: opacity changes, soft shadows
- Scroll: no aggressive parallax

## Do's
- Use generous whitespace
- Keep product names in UPPERCASE serif with wide spacing
- Use hairline dividers between sections
- Ensure strong contrast (warm-dark on cream, cream on charcoal)
- Keep accent gold restrained — buttons, highlights, not everywhere

## Don'ts
- Don't use bright/saturated colors
- Don't use heavy shadows or thick borders
- Don't use generic e-commerce layouts (no busy grids, no discount badges)
- Don't use lowercase product names
- Don't over-animate
- Don't use light text on light backgrounds
