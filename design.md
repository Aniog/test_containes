# Velmora Fine Jewelry — Design System

## Direction
Quiet luxury, warm editorial. Premium demi-fine jewelry. No loud discount cues. No generic e-commerce feel.

## Palette
- Background: #F9F6F2 (warm cream)
- Surface: #FFFFFF (white)
- Primary text: #1A1A1A (near-black)
- Secondary text: #6B6B6B (warm gray)
- Muted text: #9E9E9E
- Accent: #B89B72 (warm antique gold)
- Accent hover: #A68A60
- Divider: #E6E0D8 (warm hairline)
- Dark section: #1A1A1A (near-black for newsletter/footer accents)
- Inverse text on dark: #F9F6F2

## Typography
- Headings / product names: Cormorant Garamond, serif. Weight 400–600.
  - H1: 48–64px, line-height 1.1, letter-spacing 0.02em
  - H2: 36–48px, line-height 1.15, letter-spacing 0.02em
  - Product names: 14–16px, uppercase, letter-spacing 0.18em, weight 500
- Body / UI: Inter, sans-serif. Weight 400–500.
  - Body: 15–16px, line-height 1.65
  - UI / captions: 12–13px, letter-spacing 0.04em

## Spacing
- Section padding: 80–120px vertical on desktop, 48–64px on mobile
- Content max-width: 1280px, centered
- Grid gap: 24–32px
- Card border-radius: 0 (sharp editorial edges) or 2px for subtle softness

## Elevation
- No heavy shadows. Only:
  - `shadow-sm`: 0 1px 2px rgba(0,0,0,0.04)
  - `shadow-md`: 0 4px 12px rgba(0,0,0,0.06)

## Components
- Buttons:
  - Primary: accent background (#B89B72), white text, no border-radius, padding 14px 32px, uppercase 12px tracking-widest
  - Outline: transparent bg, 1px #1A1A1A border, no border-radius
  - Ghost: no border, underline on hover
- Dividers: 1px solid #E6E0D8
- Inputs: 1px #E6E0D8 border, no radius, 14px padding, focus: accent border
- Cards: no border, subtle shadow on hover only
