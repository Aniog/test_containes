# SSourcing China Design System

## Brand Identity
- **Company**: SSourcing China - Professional B2B sourcing agent
- **Audience**: Global buyers, importers, e-commerce sellers
- **Tone**: Professional, trustworthy, practical, international

## Color Palette

### Primary Colors
- **Primary Blue**: #1e40af (Professional, trustworthy)
- **Primary Dark**: #1e3a8a (Hover states)
- **Primary Light**: #3b82f6 (Accents)

### Neutral Colors
- **Gray 900**: #111827 (Headings)
- **Gray 700**: #374151 (Body text)
- **Gray 500**: #6b7280 (Secondary text)
- **Gray 300**: #d1d5db (Borders)
- **Gray 100**: #f3f4f6 (Backgrounds)
- **White**: #ffffff (Cards, surfaces)

### Accent Colors
- **Success Green**: #059669 (Trust indicators)
- **Warning Amber**: #d97706 (Highlights)
- **Error Red**: #dc2626 (Form validation)

## Typography

### Font Family
- **Primary**: Inter, system-ui, sans-serif
- **Headings**: Inter, system-ui, sans-serif (600-700 weight)
- **Body**: Inter, system-ui, sans-serif (400-500 weight)

### Font Sizes
- **Hero H1**: text-4xl md:text-5xl lg:text-6xl (36px - 60px)
- **Section H2**: text-3xl md:text-4xl (30px - 36px)
- **Card H3**: text-xl md:text-2xl (20px - 24px)
- **Body Large**: text-lg (18px)
- **Body**: text-base (16px)
- **Small**: text-sm (14px)
- **Caption**: text-xs (12px)

## Spacing

### Section Padding
- **Section**: py-16 md:py-20 lg:py-24
- **Container**: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8

### Component Spacing
- **Card Padding**: p-6 md:p-8
- **Button Padding**: px-6 py-3
- **Gap**: gap-6 md:gap-8

## Components

### Buttons
- **Primary**: bg-blue-700 hover:bg-blue-800 text-white rounded-lg font-semibold
- **Secondary**: border-2 border-blue-700 text-blue-700 hover:bg-blue-50 rounded-lg
- **Large**: px-8 py-4 text-lg

### Cards
- **Standard**: bg-white rounded-xl shadow-sm border border-gray-100
- **Hover**: hover:shadow-md transition-shadow duration-200
- **Featured**: ring-2 ring-blue-100

### Forms
- **Input**: border border-gray-300 rounded-lg px-4 py-3 focus:ring-2 focus:ring-blue-500 focus:border-blue-500
- **Label**: text-sm font-medium text-gray-700

## Layout Patterns

### Hero Section
- Full-width background with gradient
- Centered content with max-width
- Large headline + subtitle + CTA button
- Background image or gradient

### Service Cards Grid
- 2x2 grid on mobile, 3-column on desktop
- Icon + title + description
- Subtle hover effects

### Process Steps
- Horizontal timeline on desktop
- Vertical timeline on mobile
- Numbered steps with connecting lines

### Trust Indicators
- Stats bar with numbers
- Certification badges
- Client logos carousel

## Responsive Breakpoints
- **Mobile**: < 640px (sm)
- **Tablet**: 640px - 1024px (md)
- **Desktop**: > 1024px (lg)

## Images
- Use stock images for factory, quality control, shipping visuals
- Professional B2B imagery
- Consistent aspect ratios: 16:9 for heroes, 4:3 for cards

## Do's
- Use white space generously
- Keep content scannable
- Use professional language
- Include clear CTAs
- Maintain consistent spacing
- Use professional imagery

## Don'ts
- Don't use excessive animations
- Don't use flashy colors
- Don't use informal language
- Don't overcrowd sections
- Don't use low-quality images
- Don't use inconsistent spacing
