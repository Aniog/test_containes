# SSourcing China - B2B Website Design System

## Visual Style

**Overall Aesthetic**: Clean, trustworthy, international B2B. Professional corporate design with emphasis on reliability and expertise.

**Color Palette**:
- Primary: #0F172A (Slate 900) - Deep navy for headers and CTAs
- Secondary: #1E40AF (Blue 800) - Trust blue for accents and links
- Accent: #0EA5E9 (Sky 500) - Light blue for highlights
- Neutral: #F8FAFC (Slate 50) - Light background
- Text: #1E293B (Slate 800) - Primary text color
- Muted: #64748B (Slate 500) - Secondary text
- Success: #059669 (Emerald 600) - For trust indicators
- Border: #E2E8F0 (Slate 200) - Subtle dividers

**Typography**:
- Font: Inter (system-ui fallback)
- Headings: 700 weight, tight tracking
- Body: 400 weight, 1.6 line-height
- Small text: 500 weight for labels

**Spacing**:
- Section padding: 80px vertical (desktop), 48px (mobile)
- Container max-width: 1280px
- Card gap: 24px
- Form field spacing: 16px

**Components**:
- Buttons: Rounded corners (6px), 48px height, 600 weight
- Cards: White background, subtle shadow, 12px border radius
- Forms: Clean inputs with 1px border, focus ring in accent blue
- Navigation: Sticky, white background, subtle bottom border

**Do's**:
- Use generous whitespace between sections
- Maintain consistent 8px grid alignment
- Use icons from Lucide React (professional line style)
- Ensure all text has sufficient contrast (WCAG AA)
- Use realistic factory/QC/shipping imagery via data-strk-img

**Don'ts**:
- Avoid bright or saturated colors
- No exaggerated claims or hype language
- No decorative elements that distract from content
- No low-contrast text on any background
- Avoid overly complex animations

**Responsive**:
- Desktop: 3-column grids for cards
- Tablet: 2-column grids
- Mobile: Single column, stacked elements
- Navigation collapses to hamburger on mobile

**Trust Elements**:
- Subtle checkmarks for credentials
- Clean testimonial cards
- Professional case study cards with metrics
- FAQ accordion with clear questions

**Form Styling**:
- White background cards
- Clear labels above inputs
- Helpful placeholder text
- Submit button in primary color with loading state
- Success message with checkmark icon

**SEO & Accessibility**:
- Semantic HTML structure
- Proper heading hierarchy
- Alt text on all images
- ARIA labels on interactive elements
- Keyboard navigation support
