# SSourcing China - Design System

## Brand Identity
Professional, trustworthy, international B2B sourcing agent based in China.

## Color Palette
- **Primary (Navy)**: `#0f2540` - Headers, footer, primary buttons, trust
- **Accent (Orange)**: `#e85d04` - CTAs, highlights, hover states, important badges
- **Secondary Blue**: `#1b4965` - Links, secondary buttons, icons
- **Background Light**: `#f8f9fa` - Page backgrounds, cards
- **Background White**: `#ffffff` - Cards, sections
- **Text Dark**: `#1a1a2e` - Body text, headings
- **Text Muted**: `#6c757d` - Secondary text, captions
- **Border**: `#dee2e6` - Dividers, card borders
- **Success**: `#2d6a4f` - Success states, trust badges
- **Light Gray**: `#e9ecef` - Alternate section backgrounds

## Typography
- **Font Family**: Inter (Google Fonts), sans-serif fallback
- **H1**: 48px / 700 weight / line-height 1.2
- **H2**: 36px / 600 weight / line-height 1.3
- **H3**: 24px / 600 weight / line-height 1.4
- **Body**: 16px / 400 weight / line-height 1.6
- **Small/Caption**: 14px / 400 weight
- **Nav Links**: 15px / 500 weight

## Spacing
- Section padding: 80px vertical (desktop), 48px (mobile)
- Container max-width: 1200px
- Card padding: 24px-32px
- Grid gap: 24px-32px
- Component margin: 16px-24px

## Buttons
- **Primary**: bg-orange-500, text-white, rounded-md, px-6 py-3, hover:bg-orange-600
- **Secondary**: bg-navy, text-white, rounded-md, px-6 py-3, hover:bg-navy/90
- **Outline**: border-2 border-navy, text-navy, rounded-md, hover:bg-navy hover:text-white

## Cards
- White background, rounded-lg, shadow-sm
- Border: 1px solid #dee2e6
- Hover: shadow-md transition

## Visual Elements
- Use stock images for: factory interiors, QC inspection, shipping containers, product categories
- Icons: Lucide React, consistent 24px size
- Trust badges: shields, checkmarks, verified icons
- Clean lines, minimal decoration

## DO's
- Use plenty of whitespace
- Maintain high contrast for readability
- Use orange sparingly for CTAs only
- Keep text left-aligned for body content
- Use navy for headers and footers

## DON'Ts
- Don't use multiple accent colors
- Don't use decorative gradients on backgrounds
- Don't crowd elements - B2B needs breathing room
- Don't use playful or casual fonts
- Don't use low-contrast text on any background
