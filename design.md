# SSourcing China - Design System

## Brand Identity
- **Company**: SSourcing China - China-based sourcing agent for global buyers
- **Tone**: Professional, trustworthy, practical, international B2B
- **Visual Style**: Clean, modern, corporate with a hint of industrial/warehouse feel

## Color Palette
- **Primary Blue**: `#0A2647` (deep navy blue) - headers, nav, trust signals
- **Secondary Blue**: `#144272` - buttons, accents
- **Accent Blue**: `#205295` - hover states, links
- **Highlight Blue**: `#2C74B3` - CTA buttons, active states
- **Light Blue**: `#E8F1FD` - section backgrounds, card highlights
- **White**: `#FFFFFF` - main background, cards
- **Light Gray**: `#F8FAFC` - alternate section backgrounds
- **Medium Gray**: `#64748B` - body text, secondary text
- **Dark Gray**: `#1E293B` - headings text
- **Success Green**: `#16A34A` - trust badges, success states
- **Warning Orange**: `#EA580C` - emphasis, problem callouts

## Typography
- **Primary Font**: Inter (Google Fonts) - clean, professional, great readability
- **Heading Font**: Inter (bold weights 600-800)
- **Body Font**: Inter (weights 300-500)
- **Heading sizes**: 
  - H1: 3.5rem (56px) / line-height 1.1
  - H2: 2.5rem (40px) / line-height 1.2
  - H3: 1.5rem (24px) / line-height 1.3
  - H4: 1.25rem (20px) / line-height 1.4
- **Body text**: 1rem (16px) / line-height 1.6
- **Small text**: 0.875rem (14px)

## Spacing
- Section padding: py-20 md:py-28 (80px-112px vertical)
- Container max-width: max-w-7xl mx-auto (1280px)
- Card padding: p-6 md:p-8 (24px-32px)
- Element gap: gap-6 to gap-8 (24px-32px)

## Border Radius
- Cards: rounded-xl (12px)
- Buttons: rounded-lg (8px)
- Badges/Pills: rounded-full
- Images: rounded-lg (8px)

## Shadows
- Card shadow: shadow-lg (hover: shadow-xl transition)
- Button shadow: shadow-sm (hover: shadow-md)
- Navbar: shadow-sm

## Components Style
- **Buttons**: 
  - Primary: bg-[#2C74B3] hover:bg-[#205295] text-white px-6 py-3 rounded-lg font-semibold
  - Secondary: bg-white border-2 border-[#2C74B3] text-[#2C74B3] hover:bg-[#E8F1FD]
  - Large CTA: px-8 py-4 text-lg
- **Cards**: bg-white rounded-xl shadow-lg p-6 hover:shadow-xl transition-shadow
- **Section Headers**: text-[#0A2647] font-bold, subtitle in text-[#64748B]
- **Badges/Pills**: bg-[#E8F1FD] text-[#205295] px-3 py-1 rounded-full text-sm font-medium

## Stock Image Usage
- Factory/warehouse images for hero and services
- QC/inspection images for quality sections
- Shipping/container images for logistics
- Team/professional images for trust sections
- Product category images for sourcing sections

## Layout Guidelines
- Full-width hero sections with overlay text
- Alternating white/gray section backgrounds
- Grid layouts: 3-col desktop, 2-col tablet, 1-col mobile
- Consistent container widths for content alignment
- Mobile-responsive hamburger menu

## Do's
- Use professional, clean layouts with lots of whitespace
- Include real metrics and numbers for credibility
- Use trust badges and certifications
- Keep content scannable with clear headings
- Include clear CTAs on every section

## Don'ts
- Don't use overly flashy animations
- Don't use informal language
- Don't use excessive colors
- Don't clutter sections with too much text
- Don't use generic stock photos without context
