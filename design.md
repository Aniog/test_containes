# SSourcing China — Design System

## Brand Identity
- Company: SSourcing China
- Tagline: China Sourcing Agent for Global Buyers
- Tone: Professional, trustworthy, practical, international B2B

## Color Palette
- Primary Blue: `#1A4B8C` (deep navy-blue — trust, reliability)
- Primary Blue Light: `#2563EB` (interactive elements, links)
- Accent Red: `#C0392B` (China accent, CTAs, highlights)
- Accent Red Light: `#E74C3C`
- Neutral Dark: `#1E293B` (headings, body text)
- Neutral Mid: `#475569` (secondary text)
- Neutral Light: `#94A3B8` (muted text, borders)
- Surface White: `#FFFFFF`
- Surface Gray: `#F8FAFC` (section backgrounds)
- Surface Blue Tint: `#EFF6FF` (light blue section backgrounds)
- Border: `#E2E8F0`

## Typography
- Font Family: Inter (Google Fonts)
- Heading XL: `text-4xl md:text-5xl font-bold text-[#1E293B]`
- Heading LG: `text-3xl md:text-4xl font-bold text-[#1E293B]`
- Heading MD: `text-2xl font-semibold text-[#1E293B]`
- Heading SM: `text-xl font-semibold text-[#1E293B]`
- Body: `text-base text-[#475569]`
- Small: `text-sm text-[#94A3B8]`
- Label/Tag: `text-xs font-semibold uppercase tracking-wider`

## Spacing
- Section padding: `py-16 md:py-24`
- Container: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`
- Card padding: `p-6 md:p-8`
- Gap between cards: `gap-6 md:gap-8`

## Components

- Secondary: `bg-[#1A4B8C] hover:bg-[#2563EB] text-white font-semibold px-6 py-3 rounded-lg transition-colors`
- Outline: `border-2 border-[#1A4B8C] text-[#1A4B8C] hover:bg-[#1A4B8C] hover:text-white font-semibold px-6 py-3 rounded-lg transition-colors`

### Cards
- Standard: `bg-white rounded-xl shadow-sm border border-[#E2E8F0] p-6 hover:shadow-md transition-shadow`
- Feature: `bg-white rounded-xl shadow-sm border border-[#E2E8F0] p-8`

### Navbar
- Background: `bg-white border-b border-[#E2E8F0]`
- Logo text: `text-[#1A4B8C] font-bold`
- Nav links: `text-[#475569] hover:text-[#1A4B8C] font-medium`
- Active: `text-[#1A4B8C] font-semibold`

### Hero Section
- Background: dark navy gradient `from-[#0F2A5C] to-[#1A4B8C]`
- Headline: `text-white font-bold`
- Subtext: `text-blue-200`

### Section Backgrounds
- White: `bg-white`
- Light Gray: `bg-[#F8FAFC]`
- Light Blue: `bg-[#EFF6FF]`
- Dark Navy: `bg-[#0F2A5C]`

### Badges / Tags
- Blue: `bg-[#EFF6FF] text-[#1A4B8C] text-xs font-semibold px-3 py-1 rounded-full`
- Red: `bg-red-50 text-[#C0392B] text-xs font-semibold px-3 py-1 rounded-full`

### Dividers
- `border-t border-[#E2E8F0]`

## Do's
- Use Inter font throughout
- Keep layouts clean with generous whitespace
- Use icons (Lucide) alongside text for scannability
- Use numbered steps for process sections
- Use trust signals (years, clients, countries) prominently
- Use real-sounding case study data

## Don'ts
- No dark mode (light professional theme only)
- No exaggerated claims ("best in the world", "guaranteed")
- No cluttered layouts
- No low-contrast text
- No decorative fonts
