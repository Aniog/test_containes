# SSourcing China - Design System

## Overview
Professional B2B website for a China-based sourcing agent. Clean, trustworthy, international style.

## Colors
- Primary: #1A3A5C (dark navy blue) - trust, professionalism
- Primary Light: #2C5F8A (medium blue)
- Accent: #D4A843 (warm gold) - highlights, CTAs, accents
- Background: #FFFFFF (white) - main page bg
- Light Gray: #F5F7FA - section backgrounds
- Border: #E2E8F0 - subtle borders
- Text Primary: #1E293B (dark slate)
- Text Secondary: #64748B (medium slate)
- Text Light: #94A3B8 (light slate)

## Typography
- Font: Inter (Google Font) - weights 300, 400, 500, 600, 700, 800
- H1: 3.5rem / 1.1, font-bold, text-primary
- H2: 2.25rem / 1.2, font-bold, text-primary
- H3: 1.5rem / 1.3, font-semibold, text-primary
- Body: 1rem / 1.6, text-gray-700
- Small: 0.875rem, text-gray-500

## Spacing
- Section padding: py-16 md:py-24
- Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8
- Gap grids: gap-6 md:gap-8

## Borders / Shadows
- Card shadow: shadow-sm hover:shadow-md transition-shadow
- Card border: border border-gray-100
- Button radius: rounded-md
- Card radius: rounded-lg

## Components

### Buttons
- Primary CTA: bg-primary text-white hover:bg-primary-light font-semibold px-6 py-3 rounded-md transition-colors
- Gold CTA: bg-accent text-white hover:bg-amber-600 font-semibold px-6 py-3 rounded-md
- Outline: border-2 border-primary text-primary hover:bg-primary hover:text-white font-semibold px-6 py-3 rounded-md

### Navigation
- Sticky, white bg, shadow-sm
- Logo: bold, text-primary
- Links: text-gray-600 hover:text-primary font-medium
- Mobile: hamburger menu with slide-out

### Cards
- Service cards: bg-white rounded-lg shadow-sm border border-gray-100 p-6 hover:shadow-md transition
- Icon: w-12 h-12 text-primary mb-4

### Section Headers
- Center-aligned, max-w-3xl mx-auto
- Badge: inline-block bg-primary/10 text-primary text-sm font-semibold px-4 py-1 rounded-full mb-4

## Do's
- Use generous whitespace
- Keep layouts clean and uncluttered
- Use consistent heading hierarchy
- Use the gold accent sparingly for CTAs and highlights
- Keep images professional and realistic

## Don'ts
- Don't use flashy animations
- Don't use casual/colloquial language
- Don't overcrowd sections
- Don't use bright neon colors
- Don't use unprofessional stock photos
