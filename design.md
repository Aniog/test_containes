# MicroCosmos Design System

## Visual Style
Dark, immersive, scientific aesthetic inspired by microscopy and the hidden world of microorganisms.

## Colors
- Background (deep dark): `bg-gray-950` (#030712)
- Surface cards: `bg-gray-900` (#111827)
- Surface elevated: `bg-gray-800` (#1f2937)
- Primary accent (teal/cyan): `text-teal-400`, `bg-teal-500` (#14b8a6 / #06b6d4)
- Secondary accent (purple): `text-purple-400`, `bg-purple-500`
- Text primary: `text-white`
- Text secondary: `text-gray-300`
- Text muted: `text-gray-500`
- Border: `border-gray-700`

## Typography
- Font: Inter (sans-serif), loaded via Google Fonts
- Hero heading: `text-6xl md:text-8xl font-black tracking-tight`
- Section heading: `text-4xl md:text-5xl font-bold`
- Subheading: `text-xl md:text-2xl font-semibold`
- Body: `text-base text-gray-300 leading-relaxed`
- Caption/label: `text-sm text-gray-500 uppercase tracking-widest`

## Spacing
- Section padding: `py-20 md:py-28 px-6`
- Card padding: `p-6`
- Gap between grid items: `gap-6`

## Borders & Shadows
- Card border: `border border-gray-700/50`
- Card radius: `rounded-2xl`
- Glow effect: `shadow-lg shadow-teal-500/10`
- Image radius: `rounded-xl`

## Do's
- Use dark backgrounds with bright accent colors for contrast
- Use teal/cyan as the primary highlight color
- Use large, full-bleed images in hero and feature sections
- Use grid layouts for image galleries (3-4 columns on desktop, 2 on tablet, 1 on mobile)
- Add subtle gradient overlays on images for text legibility
- Use uppercase tracking-widest for section labels/eyebrows

## Don'ts
- Don't use white or light backgrounds
- Don't use low-contrast text on dark surfaces
- Don't use more than 2 accent colors
- Don't use serif fonts
