# SSourcing China - Design System

## Brand Identity
Professional B2B sourcing agent connecting global buyers with Chinese manufacturers. Clean, trustworthy, international.

## Colors
- Primary: Navy Blue #1a365d (deep, trustworthy, professional)
- Primary Light: #2c5282
- Accent: Warm Red #c53030 (CTAs, highlights)
- Accent Light: #e53e3e
- Neutral BG: #f7f8fa (light gray, clean)
- White: #ffffff
- Text Primary: #1a202c
- Text Secondary: #4a5568
- Text Muted: #718096
- Border: #e2e8f0

## Typography
- Font: Inter (Google Fonts, already loaded)
- Headings: font-bold, tracking-tight
- Body: font-normal, text-gray-700
- Hero headline: text-4xl md:text-5xl lg:text-6xl font-bold
- Section titles: text-3xl md:text-4xl font-bold
- Card titles: text-xl font-semibold

## Spacing
- Section padding: py-16 md:py-24
- Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8

## Components
- Buttons: rounded-md, font-semibold, transition-colors
  - Primary: bg-blue-900 hover:bg-blue-800 text-white
  - Accent: bg-red-600 hover:bg-red-700 text-white
  - Outline: border-2 border-blue-900 text-blue-900 hover:bg-blue-900 hover:text-white
- Cards: bg-white rounded-lg shadow-sm border border-gray-100
- Input fields: rounded-md border-gray-300 focus:border-blue-900 focus:ring-blue-900

## Visual Style
- Clean, lots of white space
- Professional photography style (factory, QC, logistics)
- Subtle shadows, not heavy
- Icons: Lucide React, consistent sizing
- Numbers/stats: large, bold, with subtle labels

## Do's
- Use ample white space between sections
- Keep text concise and scannable
- Use icons to support key points
- Display trust indicators prominently
- Mobile-first responsive design

## Don'ts
- No exaggerated or flashy language
- No bright neon colors
- No crowded layouts
- No generic stock photos (use factory/sourcing relevant)
- No excessive animations
