# SSourcing China - Design System

## Brand Colors
- Primary (Brand): Deep blue `brand-500` (#1e40af) for headers, buttons, key accents
- Secondary: `brand-600` (#1e3a8a) for hover states
- Accent: Orange `accent-500` (#ea580c) for CTAs, highlights, badges
- Background: White `#ffffff` for main content, `surface-50` (#f8fafc) for alternate sections
- Text: `surface-800` (#1e293b) for body, `surface-500` (#64748b) for secondary text
- Borders: `surface-200` (#e2e8f0)

## Typography
- Font: Inter (Google Fonts)
- H1: 3.5rem/4rem, font-bold, tracking-tight
- H2: 2.25rem/2.5rem, font-bold
- H3: 1.5rem/2rem, font-semibold
- Body: 1rem/1.75rem, text-surface-800
- Small: 0.875rem, text-surface-500

## Spacing
- Section padding: py-16 md:py-24
- Container max-width: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8
- Gap between cards: gap-6 md:gap-8

## Visual Style
- Cards: white bg, rounded-xl, shadow-sm border border-surface-200, hover:shadow-md transition
- Buttons: rounded-lg, font-medium, px-6 py-3
- Primary CTA: bg-brand-500 text-white hover:bg-brand-600
- Accent CTA: bg-accent-500 text-white hover:bg-accent-600
- Section headings: centered, H2 with text-surface-800, subtitle below in text-surface-500
- Icons: 8-10px stroke-width, text-brand-500 or text-accent-500
- Dividers: border-surface-200
- Grid: 3-column for desktop, 2 for tablet, 1 for mobile

## Do's
- Use consistent brand colors for all interactive elements
- Keep generous whitespace around sections
- Use professional, realistic imagery (factory, QC, shipping visuals)
- Use clear hierarchy with consistent heading sizes
- Use subtle shadows and borders for depth

## Don'ts
- Don't use exaggerated claims or superlatives
- Don't use dark backgrounds for main content
- Don't overcrowd sections with too much text
- Don't use emojis in professional content
- Don't use bright, flashy colors
