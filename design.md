# Velmora Fine Jewelry — Design System

## Direction
Quiet luxury, warm editorial. Premium demi-fine jewelry. No loud discounts, no generic e-commerce clutter.

## Color Palette
| Token | Hex | Usage |
|-------|-----|-------|
| background | #F8F5F1 | Page background, warm ivory |
| foreground | #2C1A12 | Primary text, deep espresso |
| card | #FFFFFF | Cards, modals, drawer |
| muted | #EAE3DA | Subtle sections, dividers |
| muted-foreground | #7A6B5F | Secondary text |
| accent | #B8926A | CTAs, links, stars, antique gold |
| accent-foreground | #FFFFFF | Text on accent |
| border | #DCD3C9 | Hairline borders |

## Typography
- Headings / product names: Playfair Display, serif. Uppercase product names with wide tracking.
- Body / UI: Inter, sans-serif.

## Spacing & Layout
- Generous whitespace. Section padding: py-20 to py-28.
- Container max-width: max-w-7xl centered.
- Hairline dividers: border-border / 1px.

## Components
- Buttons: solid accent (bg-accent text-white) or outlined (border-foreground text-foreground).
- Cards: minimal, white background, soft hover lift.
- Inputs: clean, subtle border, focus ring accent.

## Imagery
Warm gold jewelry on dark/neutral backgrounds. Use data-strk-img tags with jewelry-related queries.
