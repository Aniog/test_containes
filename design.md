# SSourcing China — Design System

## Brand
- Name: SSourcing China
- Tagline: China Sourcing Agent for Global Buyers
- Purpose: Generate qualified sourcing inquiries from overseas buyers.

## Tone
Professional, clear, practical, no exaggerated claims. International B2B trust.

## Colors
- Primary: `#0055b8` (trust blue)
- Primary dark: `#003d85`
- Primary light: `#e6f0fa`
- Accent: `#0ea5e9` (sky blue for highlights)
- Success: `#16a34a`
- Warning: `#d97706`
- Text primary: `#0f172a` (slate 900)
- Text secondary: `#475569` (slate 600)
- Text muted: `#64748b` (slate 500)
- Background: `#ffffff`
- Surface: `#f8fafc` (slate 50)
- Border: `#e2e8f0` (slate 200)

## Typography
- Headings: Inter, 700–800, tight line-height (`leading-tight`)
- Body: Inter, 400–500, `leading-relaxed`
- Hero headline: `text-4xl md:text-5xl lg:text-6xl`
- Section title: `text-3xl md:text-4xl`
- Section subtitle: `text-lg md:text-xl text-slate-600`

## Spacing
- Sections: `py-16 md:py-24`
- Container: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`
- Card gap: `gap-6 md:gap-8`

## Components
- Buttons:
  - Primary: `bg-[#0055b8] hover:bg-[#003d85] text-white font-semibold rounded-lg px-6 py-3`
  - Secondary: `bg-white border border-slate-300 text-slate-800 hover:bg-slate-50 font-semibold rounded-lg px-6 py-3`
- Cards: `bg-white rounded-xl border border-slate-200 shadow-sm hover:shadow-md transition`
- Badges: `inline-flex items-center rounded-full bg-blue-50 text-[#0055b8] px-3 py-1 text-sm font-medium`
- Section header: centered badge label + h2 + p subtitle, max-w-3xl mx-auto

## Imagery
- Use realistic factory, QC, shipping, and product-sourcing visuals via data-strk-img tags.
- Prefer 16x9 for hero backgrounds and 4x3 for cards.

## Do
- Keep layouts generous with whitespace.
- Use clear hierarchy and readable contrast.
- Use Lucide icons for services and trust points.
- Include explicit CTA sections on every page.

## Don't
- Use stock-photo clichés as the only content.
- Use neon or playful colors.
- Crowd mobile layouts.
