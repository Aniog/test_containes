# SSourcing China - Design System

## Brand Identity
- Brand: SSourcing China - China Sourcing Agent
- Tone: Professional, clear, practical, trustworthy, international B2B
- No exaggerated claims. No superlatives like "best", "top", "leading".

## Typography
- Font Family: Inter (Google Font)
- Headings: font-bold, tracking-tight
- Body: font-normal, leading-relaxed
- Sizes: h1 ~ text-4xl/sm:text-5xl, h2 ~ text-3xl, h3 ~ text-xl, body ~ text-base

## Colors
- Primary: #1e40af (blue-800) - trust, professionalism
- Primary Light: #3b82f6 (blue-500) - CTAs, links
- Accent: #dc2626 (red-600) - urgency, CTA buttons
- Background: #ffffff (white) main, #f8fafc (slate-50) alternate sections
- Text: #0f172a (slate-900) headings, #475569 (slate-600) body
- Muted: #94a3b8 (slate-400) secondary text
- Borders: #e2e8f0 (slate-200)

## Spacing
- Section padding: py-16 md:py-24
- Container max-width: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Component gap: gap-6 md:gap-8
- Card padding: p-6 md:p-8

## Visual Style
- Cards: white bg, rounded-lg, subtle shadow-sm, border border-slate-200
- Buttons: rounded-md, px-6 py-3, font-semibold
- Primary CTA: bg-blue-600 text-white hover:bg-blue-700
- Accent CTA: bg-red-600 text-white hover:bg-red-700
- Images: rounded-lg, object-cover
- Grid layouts: 1 col mobile, 2-3 cols desktop
- Icons: lucide-react, size 5-6, text-blue-600

## Do's
- Use clean, white backgrounds with subtle contrast sections
- Keep plenty of whitespace
- Use consistent heading hierarchy
- Show practical, realistic imagery
- Use clear CTAs

## Don'ts
- Don't use exaggerated marketing language
- Don't use dark backgrounds for main content
- Don't clutter with too many elements
- Don't use gradients or heavy visual effects
- Don't use comic or casual fonts
