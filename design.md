# SSourcing China - Design System

## Brand Identity
- Professional, trustworthy, international B2B aesthetic
- Clean and minimal with strong visual hierarchy
- Blue primary color conveys trust and reliability
- Warm accent colors for CTAs and highlights

## Colors
- Primary Blue: #1a56db (trust, reliability)
- Primary Dark: #1e3a5f (deep navy for headers/footers)
- Accent Orange: #ea580c (CTAs, highlights)
- Neutral Gray: #f8fafc (light backgrounds)
- Text Dark: #1e293b (body text)
- Text Muted: #64748b (secondary text)
- Border: #e2e8f0 (cards, dividers)
- Success Green: #16a34a (checkmarks, trust points)

## Typography
- Font: Inter (Google Font)
- H1: text-4xl md:text-5xl lg:text-6xl font-bold tracking-tight
- H2: text-3xl md:text-4xl font-bold
- H3: text-xl md:text-2xl font-semibold
- Body: text-base md:text-lg text-slate-700 leading-relaxed
- Small: text-sm text-slate-500

## Spacing
- Section padding: py-16 md:py-24
- Container max-width: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Section gap: space-y-12 md:space-y-16
- Card padding: p-6 md:p-8
- Grid gap: gap-6 md:gap-8

## Components
### Cards
- White background with rounded-xl shadow-sm border border-slate-100
- Hover: shadow-md transition-shadow

### Buttons
- Primary CTA: bg-orange-600 hover:bg-orange-700 text-white font-semibold rounded-lg px-6 py-3
- Secondary: bg-white border border-slate-200 hover:bg-slate-50 text-slate-700 rounded-lg px-6 py-3
- Outline: border-primary-600 text-primary-600 hover:bg-primary-50

### Navigation
- Sticky header with white background, shadow-sm on scroll
- Desktop: horizontal links with hover underline effect
- Mobile: hamburger menu with slide-out panel

### Service/Feature Icons
- Use Lucide icons with blue-600 color, size w-10 h-10 or w-12 h-12
- Icon containers: bg-blue-50 rounded-xl p-3

## Visual Style
- Clean white backgrounds with subtle gray sections alternating
- Card-based layouts for services, products, case studies
- Generous whitespace between sections
- Consistent border-radius: rounded-xl for cards, rounded-lg for buttons
- Subtle shadows: shadow-sm for cards, shadow-md on hover
- All images use stock image system with realistic factory/QC/shipping visuals

## Do's
- Use the blue primary color for headings, links, icons
- Use orange only for primary CTAs
- Keep lots of whitespace
- Use consistent card styles
- Show real-looking process steps with numbers
- Use trust signals (badges, numbers, certifications)

## Don'ts
- Don't use exaggerated claims or hype language
- Don't use dark backgrounds for content sections
- Don't overcrowd sections
- Don't use multiple accent colors
- Don't use Comic Sans or decorative fonts
