# SSourcing China — Design System

## Brand Identity
- Company: SSourcing China
- Tagline: China Sourcing Agent for Global Buyers
- Tone: Professional, trustworthy, international, B2B

## Color Palette
- Primary Blue: `#1A3C6E` (deep navy — trust, authority)
- Accent Red: `#C0392B` (China red — identity, energy)
- Accent Gold: `#D4A017` (premium, quality)
- Light Blue: `#EBF2FA` (backgrounds, cards)
- White: `#FFFFFF`
- Text Dark: `#1A1A2E`
- Text Muted: `#6B7280`
- Border: `#E5E7EB`
- Success Green: `#16A34A`

## Typography
- Font: Inter (Google Fonts)
- Headings: font-bold, tracking-tight
- Body: font-normal, leading-relaxed
- H1: text-4xl md:text-5xl lg:text-6xl
- H2: text-3xl md:text-4xl
- H3: text-xl md:text-2xl
- Body: text-base md:text-lg

## Spacing
- Section padding: py-16 md:py-24
- Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8
- Gap between cards: gap-6 md:gap-8

## Components
- Primary Button: bg-[#C0392B] text-white px-6 py-3 rounded-lg font-semibold hover:bg-[#A93226] transition
- Secondary Button: border-2 border-[#1A3C6E] text-[#1A3C6E] px-6 py-3 rounded-lg font-semibold hover:bg-[#1A3C6E] hover:text-white transition
- Card: bg-white rounded-xl shadow-sm border border-[#E5E7EB] p-6
- Section bg alternating: white / #EBF2FA

## Do's
- Use navy for headings and primary text
- Use red only for CTAs and key highlights
- Use gold sparingly for trust badges and highlights
- Keep layouts clean with generous whitespace
- Use icons from lucide-react consistently

## Don'ts
- No dark backgrounds except hero
- No neon or overly bright colors
- No exaggerated claims in copy
- No cluttered layouts
