# SSourcing China - B2B Website Design Specification

## Overview
Professional B2B website for a China-based sourcing agent helping overseas buyers find suppliers, verify factories, inspect quality, and coordinate shipping.

## Visual Style

### Color Palette
- **Primary**: `#1B4D3E` (Deep forest green - trust, reliability)
- **Secondary**: `#2D5A4A` (Medium green - professional)
- **Accent**: `#D4A853` (Warm gold - premium, professional)
- **Background Light**: `#F8FAF9` (Off-white with green tint)
- **Background Dark**: `#0F2D24` (Dark green for contrast sections)
- **Text Primary**: `#1A1A1A` (Near black)
- **Text Secondary**: `#5A6B62` (Muted green-gray)
- **Text Light**: `#FFFFFF` (White)
- **Border**: `#E2E8E5` (Light gray-green)

### Typography
- **Headings**: Inter (600-800 weight) - clean, professional
- **Body**: Inter (400-500 weight) - highly readable
- **Font Sizes**:
  - Hero: 48-64px
  - H1: 40-48px
  - H2: 32-36px
  - H3: 24-28px
  - Body: 16-18px
  - Small: 14px

### Spacing System
- Base unit: 4px
- Section padding: 80-120px vertical
- Container max-width: 1280px
- Card padding: 24-32px
- Component gap: 16-24px

### Visual Elements
- Rounded corners: 8px for cards, 6px for buttons
- Subtle shadows for elevation
- Professional stock imagery (factories, QC inspections, shipping containers)
- Icon style: Lucide React (line icons, 24px standard)
- Subtle background patterns for visual interest

## Component Guidelines

### Navigation
- Sticky header with logo and menu
- Primary CTA button in header
- Mobile hamburger menu

### Hero Section
- Full-width background with factory/logistics imagery
- Clear headline and subheadline
- Primary CTA button
- Trust badges below CTA

### Service Cards
- Icon, title, brief description
- Hover effect with subtle shadow lift
- Clean white background with border

### Process Steps
- Numbered timeline/step indicator
- Icon + title + description for each step
- Visual connection between steps

### Case Study Cards
- Industry tag
- Company description
- Results/metrics
- Link to full case study

### FAQ Accordion
- Clean expandable questions
- Plus/minus toggle icon
- Smooth expand animation

### Forms
- Clean input fields with labels
- Validation states
- Clear submit button
- Success confirmation

## Layout Structure

### Pages
1. **Home** - Hero, Services Overview, Process, Products, Trust Points, Case Studies, FAQ, CTA
2. **Services** - Detailed service offerings
3. **How It Works** - Step-by-step process
4. **Products We Source** - Categories of products
5. **Case Studies** - Client success stories
6. **Blog** - Industry insights and guides
7. **Contact** - Inquiry form and contact info

### Responsive Breakpoints
- Mobile: < 640px (single column, stacked layouts)
- Tablet: 640-1024px (2 columns where appropriate)
- Desktop: > 1024px (full layout)

## Design Do's
- Use generous white space
- Keep copy concise and practical
- Show real B2B scenarios
- Include concrete metrics/numbers
- Use professional imagery

## Design Don'ts
- Avoid exaggerated claims
- Don't use stock photos that look fake
- Avoid cluttered layouts
- Don't use too many colors
- Don't use informal language
