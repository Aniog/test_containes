# Soccer Website Design System

## Brand Identity
A bold, energetic soccer website with a dark, premium feel. Inspired by top football leagues and sports media brands.

## Color Palette
- **Primary Green**: `#16a34a` (grass green, `text-green-600`, `bg-green-600`)
- **Dark Background**: `#0a0f1e` (deep navy-black, `bg-[#0a0f1e]`)
- **Card Background**: `#111827` (dark gray, `bg-gray-900`)
- **Surface**: `#1f2937` (medium dark, `bg-gray-800`)
- **Accent Yellow**: `#facc15` (highlight, `text-yellow-400`)
- **Text Primary**: `#f9fafb` (near white, `text-gray-50`)
- **Text Secondary**: `#9ca3af` (muted gray, `text-gray-400`)
- **Border**: `#374151` (subtle border, `border-gray-700`)

## Typography
- **Font**: Inter (Google Fonts)
- **Hero Heading**: `text-5xl md:text-7xl font-black tracking-tight text-white`
- **Section Heading**: `text-3xl font-bold text-white`
- **Card Title**: `text-lg font-semibold text-white`
- **Body**: `text-base text-gray-300`
- **Label/Badge**: `text-xs font-bold uppercase tracking-widest`

## Spacing & Layout
- **Page max-width**: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`
- **Section padding**: `py-16 md:py-24`
- **Card padding**: `p-6`
- **Gap between cards**: `gap-6`

## Components

### Navbar
- Dark background `bg-gray-900/95 backdrop-blur`
- Logo with green accent
- Links in `text-gray-300 hover:text-white`
- Active link with green underline

### Hero
- Full-viewport height with dark overlay on background image
- Large bold headline, subtitle, CTA button in green
- Gradient overlay: `from-[#0a0f1e] via-[#0a0f1e]/70 to-transparent`

### Cards
- `bg-gray-900 border border-gray-800 rounded-2xl`
- Hover: `hover:border-green-600/50 transition-all`
- Image on top, content below

### Badges / Tags
- Live badge: `bg-red-600 text-white text-xs font-bold px-2 py-0.5 rounded`
- Category badge: `bg-green-600/20 text-green-400 text-xs font-bold px-2 py-0.5 rounded`

### Buttons
- Primary: `bg-green-600 hover:bg-green-500 text-white font-bold px-6 py-3 rounded-xl`
- Secondary: `border border-gray-700 hover:border-green-600 text-white px-6 py-3 rounded-xl`

## Do's
- Use dark backgrounds throughout for a premium sports feel
- Use green as the primary accent color consistently
- Use bold, uppercase labels for categories and stats
- Use large numbers/stats with yellow accent for emphasis
- Keep cards clean with clear hierarchy

## Don'ts
- Don't use light backgrounds (no white pages)
- Don't use low-contrast text on dark backgrounds
- Don't mix too many accent colors — stick to green + yellow
- Don't use small font sizes for key stats or scores
