- **Font Family**: Inter (Google Fonts)
- **H1**: 48px / 800 weight / -0.02em tracking
- **H2**: 36px / 700 weight / -0.01em tracking
- **H3**: 24px / 600 weight
- **Body**: 16px / 400 weight / 1.6 line-height
- **Small**: 14px / 400 weight

## Spacing
- Section padding: py-20 (80px) desktop, py-12 (48px) mobile
- Container max-width: max-w-7xl (1280px)
- Container padding: px-4 sm:px-6 lg:px-8
- Card padding: p-6 to p-8
- Gap between cards: gap-6 to gap-8

## Layout Rules
- Single column on mobile, grid on desktop
- Hero: full-width with subtle gradient background
- Sections alternate between white and slate-50 backgrounds
- Navigation: fixed top, white bg with subtle shadow
- Footer: dark slate-900 bg with white text

## Do's
- Use plenty of whitespace
- Maintain consistent alignment
- Use amber accent sparingly for CTAs and highlights
- Ensure all text has strong contrast
- Use realistic factory/QC/shipping imagery

## Don'ts
- No exaggerated claims or flashy animations
- No dark mode (light only)
- No cluttered layouts
- No low-contrast text
