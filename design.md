# SSourcing China - Design System

## Overview
Professional B2B website for a China-based sourcing agent. Clean, trustworthy, international aesthetic with realistic factory/QC/shipping visuals.

## Typography
- **Primary Font**: Inter (Google Fonts)
- **Weights**: 300, 400, 500, 600, 700, 800
- **Base Size**: 16px
- **Line Height**: 1.5

## Color Palette
- **Primary**: Slate-900 (#0f172a) - Headers, CTAs, key elements
- **Secondary**: Slate-600 (#475569) - Body text, secondary elements
- **Accent**: Slate-100 (#f1f5f9) - Light backgrounds, hover states
- **Background**: White (#ffffff) - Main background
- **Text Primary**: Slate-900 (#0f172a) - Primary text
- **Text Secondary**: Slate-600 (#475569) - Secondary text
- **Success**: Green-600 (#16a34a) - Success indicators
- **Border**: Slate-200 (#e2e8f0) - Borders, dividers

## Spacing
- **Section Padding**: py-20 (5rem)
- **Container Max Width**: max-w-7xl
- **Grid Gap**: gap-8 (2rem)
- **Card Padding**: p-6 to p-8

## Components

### Buttons
- **Primary**: bg-slate-900 text-white hover:bg-slate-800
- **Secondary**: bg-slate-100 text-slate-900 hover:bg-slate-200
- **Outline**: border border-slate-200 bg-white hover:bg-slate-50
- **Sizes**: default (h-9 px-4), lg (h-10 px-8)

### Cards
- **Background**: White or slate-50
- **Border Radius**: rounded-xl
- **Shadow**: hover:shadow-lg transition
- **Padding**: p-6 to p-8

### Navigation
- **Background**: White with border-b border-slate-200
- **Height**: h-16
- **Mobile**: Hamburger menu with slide-down

### Forms
- **Input Border**: border-slate-300
- **Focus Ring**: focus:ring-2 focus:ring-slate-900
- **Labels**: text-sm font-medium text-slate-700

## Layout
- **Container**: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- **Grid**: Responsive grid with 1/2/3/4 columns
- **Hero**: Full-width with overlay, py-20 to py-32

## Visual Style
- **Clean**: Minimal clutter, ample whitespace
- **Professional**: Slate color scheme, no bright colors
- **Trustworthy**: Consistent spacing, clear hierarchy
- **International**: English-first, neutral design

## Do's
- Use slate color palette consistently
- Maintain consistent spacing and alignment
- Use Inter font family
- Include hover states for interactive elements
- Use rounded corners (rounded-lg, rounded-xl)
- Include proper padding and margins

## Don'ts
- Don't use bright or neon colors
- Don't use multiple font families
- Don't create crowded layouts
- Don't use low-contrast text
- Don't skip hover states
- Don't use magic values for spacing

## Responsive Breakpoints
- **Mobile**: Default styles
- **Tablet**: md: (768px)
- **Desktop**: lg: (1024px)
- **Large Desktop**: xl: (1280px)

## Images
- Use data-strk-img for stock images
- Use data-strk-bg for background images
- Maintain consistent aspect ratios
- Use SVG placeholders before images load
