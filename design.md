# SSourcing China - Design System

## Brand Identity
- **Company**: SSourcing China - Professional B2B sourcing agent
- **Tone**: Professional, clear, practical, trustworthy, international
- **Target**: Global buyers looking for Chinese suppliers

## Color Palette
- **Primary Blue**: `#0052CC` (Trust, professionalism) - Used for CTAs, links, key elements
- **Dark Navy**: `#1A1F36` (Headings, important text)
- **Slate Gray**: `#4A5568` (Body text)
- **Light Gray**: `#F7FAFC` (Backgrounds, cards)
- **White**: `#FFFFFF` (Clean backgrounds)
- **Accent Green**: `#38A169` (Success, trust points)
- **Accent Orange**: `#DD6B20` (Warnings, highlights)

## Typography
- **Font Family**: Inter (Google Fonts)
- **Headings**: 700-800 weight, dark navy color
- **Body**: 400-500 weight, slate gray color
- **Sizes**: 
  - H1: text-4xl md:text-5xl lg:text-6xl
  - H2: text-3xl md:text-4xl
  - H3: text-xl md:text-2xl
  - Body: text-base md:text-lg

## Layout
- **Max Width**: max-w-7xl (1280px)
- **Container**: mx-auto px-4 sm:px-6 lg:px-8
- **Spacing**: 
  - Section padding: py-16 md:py-24
  - Card padding: p-6 md:p-8
  - Grid gaps: gap-6 md:gap-8

## Components
- **Buttons**: 
  - Primary: bg-blue-600 hover:bg-blue-700 text-white rounded-lg px-6 py-3
  - Secondary: border-2 border-blue-600 text-blue-600 hover:bg-blue-50
- **Cards**: bg-white rounded-xl shadow-sm border border-gray-100 hover:shadow-md transition-shadow
- **Forms**: bg-white rounded-lg border border-gray-200 p-6

## Visual Style
- Clean, professional B2B aesthetic
- Ample white space
- Subtle shadows and borders
- Realistic factory/QC/shipping imagery via stock image system
- Trust badges and certifications displayed prominently

## Do's
- Use clear, professional language
- Display trust signals (years in business, clients served, etc.)
- Use high-quality stock images of factories, warehouses, shipping
- Include clear CTAs on every section
- Maintain consistent spacing and alignment

## Don'ts
- Use flashy animations or excessive gradients
- Use exaggerated claims or hype language
- Clutter sections with too much text
- Use low-quality or generic stock images
- Mix too many colors or fonts
