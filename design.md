# Archery Sport Website Design System

## Brand Identity
- **Theme**: Precision, Focus, Power — the essence of archery
- **Tone**: Professional, athletic, inspiring

## Color Palette
- **Primary**: Deep Forest Green `#1a4731` — strength and nature
- **Primary Light**: `#2d6a4f` — hover states
- **Accent Gold**: `#c9a84c` — medals, highlights, CTAs
- **Accent Gold Light**: `#e8c96a` — hover on gold
- **Dark BG**: `#0d1f17` — hero sections, dark panels
- **Surface**: `#f5f7f2` — light page background
- **Card BG**: `#ffffff`
- **Text Primary**: `#1a2e1e` — main body text
- **Text Secondary**: `#4a6741` — muted text
- **Text Light**: `#f0f4ee` — text on dark backgrounds
- **Border**: `#d4e0cc`

## Typography
- **Font**: "Noto Serif SC" for headings (Chinese serif), "Inter" for body
- **H1**: `text-5xl md:text-7xl font-bold tracking-tight`
- **H2**: `text-3xl md:text-4xl font-bold`
- **H3**: `text-xl md:text-2xl font-semibold`
- **Body**: `text-base leading-relaxed`
- **Caption**: `text-sm text-[#4a6741]`

## Spacing
- Section padding: `py-20 px-4 md:px-8`
- Card padding: `p-6 md:p-8`
- Gap between cards: `gap-6 md:gap-8`

## Borders & Shadows
- Card: `rounded-2xl shadow-md border border-[#d4e0cc]`
- Button: `rounded-full`
- Divider: `border-[#d4e0cc]`

## Components

### Buttons
- Primary: `bg-[#c9a84c] hover:bg-[#e8c96a] text-[#0d1f17] font-semibold px-8 py-3 rounded-full transition-all`
- Secondary: `border-2 border-[#c9a84c] text-[#c9a84c] hover:bg-[#c9a84c] hover:text-[#0d1f17] px-8 py-3 rounded-full transition-all`
- Ghost: `text-[#f0f4ee] hover:text-[#c9a84c] transition-colors`

### Navigation
- Dark background: `bg-[#0d1f17]`
- Logo: gold accent color
- Links: light text, gold on hover

### Cards
- White background with green border
- Hover: slight shadow lift `hover:shadow-xl hover:-translate-y-1 transition-all`

### Hero Section
- Full-screen dark overlay on background image
- Large centered text with gold accent
- Subtle animated elements

## Do's
- Use green/gold color pairing consistently
- Use serif font for section headings to convey tradition
- Add subtle hover animations on interactive elements
- Use high-contrast text on dark backgrounds

## Don'ts
- Don't use pure black backgrounds (use `#0d1f17` instead)
- Don't use blue or red as primary colors
- Don't use small font sizes for important content
- Don't use light text on light backgrounds
