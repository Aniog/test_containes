# Velmora Fine Jewelry — Design System

## Mood
Quiet luxury, warm, editorial. Premium demi-fine jewelry. NOT loud, NOT discount-looking.

## Color Palette
- **Background (cream):** `#FAF8F5` — warm off-white page base
- **Foreground (charcoal):** `#1A1A1A` — primary text
- **Muted text:** `#6B6560` — secondary/body copy
- **Accent (gold):** `#B8860B` — CTAs, highlights, hover states
- **Accent hover:** `#9A7209` — darker gold for hover
- **Surface (warm gray):** `#F3EDE7` — card backgrounds, sections
- **Border:** `#E8E0D8` — hairline dividers
- **Dark surface:** `#2C2420` — dark sections (hero overlay, footer)

## Typography
- **Headings / Product names:** `Cormorant Garamond`, serif — elegant, editorial
- **Body / UI:** `Inter`, sans-serif — clean, modern
- **Product names:** UPPERCASE, `tracking-[0.2em]`
- **Section headings:** `text-3xl md:text-5xl font-light`
- **Body text:** `text-base font-normal leading-relaxed`

## Spacing & Layout
- Generous whitespace: sections use `py-16 md:py-24`
- Container max-width: `max-w-7xl mx-auto px-4 md:px-8`
- Card padding: `p-4 md:p-6`
- Grid gaps: `gap-4 md:gap-6`

## Components
- **Buttons (primary):** `bg-accent text-white px-8 py-3 text-sm tracking-widest uppercase hover:bg-accent-hover transition-colors`
- **Buttons (outline):** `border border-accent text-accent px-8 py-3 text-sm tracking-widest uppercase hover:bg-accent hover:text-white transition-colors`
- **Cards:** `bg-white rounded-none` — no border-radius for editorial feel
- **Dividers:** `border-t border-border` — thin hairline
- **Shadows:** `shadow-sm` — very subtle, only on hover

## Do's
- Use generous whitespace between sections
- Keep imagery large and editorial
- Use serif for emotional/brand text, sans-serif for functional UI
- Thin hairline dividers between sections
- Subtle hover transitions (opacity, translateY)
- Gold accent sparingly — CTAs and key highlights only

## Don'ts
- No rounded corners on cards or product images
- No heavy drop shadows
- No bright/saturated colors
- No cluttered layouts
- No discount-style badges or loud sale graphics
- No generic e-commerce feel
