# Velmora Fine Jewelry - Design Identity

## Visual Style: Quiet Luxury / Editorial
The brand embodies "Quiet Luxury" — sophisticated, warm, and high-end but accessible. It avoids loud branding and discount-focused UI, favoring a clean, editorial layout with generous whitespace and elegant typography.

## Color Palette
- **Base (Cream):** `#FCFAF7` (Tailwind: `bg-[#FCFAF7]`) - Main background, warm and inviting.
- **Accents (Deep Charcoal):** `#1A1A1A` (Tailwind: `text-[#1A1A1A]`, `bg-[#1A1A1A]`) - Headers, buttons, primary text.
- **Metallic (Antique Gold):** `#C5A059` (Tailwind: `text-[#C5A059]`, `border-[#C5A059]`) - Subtle accents, dividers, call-to-actions.
- **Muted (Soft Sand):** `#EFE9E1` (Tailwind: `bg-[#EFE9E1]`) - Hover states, secondary backgrounds.

## Typography
- **Headings (Serif):** `Cormorant Garamond`, serif. Used for brand name, page titles, and product names (Uppercase).
  - Example: `font-serif tracking-widest uppercase`
- **Body & UI (Sans):** `Inter`, sans-serif. Used for product descriptions, navigation links, and functional UI elements.
  - Example: `font-sans text-sm tracking-tight`

## UI Elements
- **Buttons:** Solid deep charcoal or elegant outline charcoal. Minimal rounding (sm or none).
- **Dividers:** Thin, 1px hairlines in `#EFE9E1` or `#C5A059`.
- **Transitions:** Soft, smooth opacity and scale transitions for a premium feel.
- **Shadows:** Very subtle, soft shadows for depth on cards and modals.

## Photography Direction
- Warm, natural lighting.
- Focus on skin textures and the shimmer of gold.
- Editorial-style lifestyle shots mixed with clean product photography on neutral backgrounds.
