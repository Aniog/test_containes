# SSourcing China - Design Guidelines

## Brand Identity
- Professional B2B sourcing agent website
- Clean, trustworthy, international feel
- No exaggerated claims - practical and clear

## Color Palette
- Primary: Deep Navy Blue (#1e3a5f) - trust, professionalism
- Primary Light: #2d5a8e - hover states, accents
- Accent: Warm Orange (#e87722) - CTAs, highlights
- Accent Hover: #d06a1b
- Background: White (#ffffff) and Light Gray (#f8f9fa)
- Text Primary: #1a1a2e - near-black for body text
- Text Secondary: #4a5568 - gray for secondary text
- Text Muted: #718096 - lighter gray for captions
- Border: #e2e8f0 - subtle borders
- Card Background: #ffffff
- Section Alt Background: #f1f5f9 - alternating sections

## Typography
- Font: Inter (Google Fonts)
- Headings: font-weight 700 (bold), tracking tight
- Body: font-weight 400, line-height 1.7
- H1: text-4xl md:text-5xl lg:text-6xl
- H2: text-3xl md:text-4xl
- H3: text-xl md:text-2xl
- Body: text-base (16px)
- Small: text-sm (14px)

## Spacing
- Section padding: py-16 md:py-24
- Container max-width: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8
- Element gaps: gap-6 md:gap-8

## Visual Style
- Cards: rounded-xl, shadow-sm, border border-gray-100
- Buttons: rounded-lg, font-semibold, transition-all
- Primary CTA: bg-accent text-white hover:bg-accent-hover
- Secondary CTA: border-2 border-primary text-primary hover:bg-primary hover:text-white
- Images: rounded-lg, object-cover
- Icons: lucide-react, stroke-width 1.5

## Do's
- Use ample white space
- Use consistent section spacing
- Use professional, realistic imagery via data-strk-img
- Keep forms simple and clear
- Use trust indicators (certifications, stats)
- Mobile-first responsive design

## Don'ts
- Don't use garish colors or gradients
- Don't use cartoon icons or clip art
- Don't use exaggerated marketing language
- Don't use dark backgrounds with dark text
- Don't crowd sections with too much content
