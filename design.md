# SSourcing China - Design Guidelines

## Project Overview
- **Project Name**: SSourcing China Website
- **Type**: B2B Corporate Website
- **Purpose**: Generate qualified sourcing inquiries for China sourcing agent services
- **Target Audience**: Overseas buyers, procurement managers, business owners looking to source products from China

## Visual Style

### Color Palette
- **Primary**: `#1E3A5F` (Deep Navy Blue - trust, professionalism)
- **Primary Light**: `#2D5A87` (Medium Blue)
- **Secondary**: `#F5A623` (Warm Orange - CTA buttons, highlights)
- **Secondary Hover**: `#E09000` (Darker Orange)
- **Accent**: `#4CAF50` (Green - success, trust indicators)
- **Background Primary**: `#FFFFFF` (White)
- **Background Secondary**: `#F8FAFC` (Light Gray-Blue)
- **Background Dark**: `#1A1A2E` (Dark Navy for footer)
- **Text Primary**: `#1F2937` (Dark Gray)
- **Text Secondary**: `#6B7280` (Medium Gray)
- **Text Light**: `#FFFFFF` (White)
- **Border**: `#E5E7EB` (Light Gray)

### Typography
- **Font Family**: "Inter", system-ui, sans-serif
- **Headings**: 
  - H1: 48px/56px, font-weight 700
  - H2: 36px/44px, font-weight 600
  - H3: 24px/32px, font-weight 600
  - H4: 20px/28px, font-weight 500
- **Body**: 16px/24px, font-weight 400
- **Small**: 14px/20px, font-weight 400

### Spacing System
- Base unit: 4px
- Section padding: 80px vertical (desktop), 48px (mobile)
- Container max-width: 1200px
- Grid gap: 24px (desktop), 16px (mobile)

### Visual Effects
- Card shadows: `0 4px 6px -1px rgba(0, 0, 0, 0.1), 0 2px 4px -1px rgba(0, 0, 0, 0.06)`
- Hover shadows: `0 10px 15px -3px rgba(0, 0, 0, 0.1), 0 4px 6px -2px rgba(0, 0, 0, 0.05)`
- Border radius: 8px (cards), 4px (buttons), 50% (avatars)
- Transitions: 200ms ease-in-out

## Layout Structure

### Header/Navigation
- Fixed top navigation bar
- Logo on left (SSourcing China text logo)
- Navigation links: Home, Services, How It Works, Products, Case Studies, Blog, Contact
- CTA button on right: "Get a Free Sourcing Quote"
- Mobile: Hamburger menu

### Footer
- Dark background (#1A1A2E)
- 4 columns: Company info, Services, Resources, Contact
- Social links
- Copyright

### Responsive Breakpoints
- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px

## Components

### Buttons
- Primary: Orange background (#F5A623), white text
- Secondary: Navy outline, navy text
- Hover: Darker shade, slight lift

### Cards
- White background
- Light shadow
- 8px border radius
- Hover: Elevated shadow

### Form Inputs
- Light border
- Focus: Navy border
- Placeholder: Gray text

### Icons
- Lucide React icons
- Consistent sizing (24px default)

## Image Guidelines
- Use professional B2B imagery
- Factory, warehouse, QC inspection, shipping containers
- Realistic, not stock-photo generic
- People in professional settings

## Do's and Don'ts
- DO: Clean, professional, trustworthy appearance
- DO: Clear value propositions
- DO: Easy navigation
- DO: Prominent CTAs
- DON'T: Exaggerated claims or unrealistic promises
- DON'T: Cluttered layouts
- DON'T: Too many colors
- DON'T: Informal tone
