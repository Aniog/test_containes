# Velmora Fine Jewelry Design System

## Brand direction
Velmora should feel like quiet luxury: editorial, warm, refined, and premium without feeling flashy or discount-driven.

## Color system
Use a single confident direction built from Tailwind's stone and amber palette.

- Primary canvas: `bg-stone-50`
- Elevated cards: `bg-white`
- Deep editorial surfaces: `bg-stone-950`, `bg-stone-900`
- Main text on light: `text-stone-900`
- Main text on dark: `text-stone-100`
- Secondary text: `text-stone-600`, `text-stone-300`
- Dividers: `border-stone-200`, `border-stone-800`
- Premium accent: `bg-amber-200`, `text-amber-200`, `border-amber-200`
- Accent hover: `bg-amber-300`

## Typography
- Headings and product names use Cormorant Garamond via Tailwind class `font-serif`
- Body and UI use Inter via Tailwind class `font-sans`
- Product names should be uppercase with `tracking-widest`

## Layout and spacing
- Favor generous whitespace: `py-16`, `py-20`, `py-24`
- Keep content widths elegant: `max-w-7xl`, `max-w-6xl`, `max-w-3xl`
- Use thin dividers and subtle shadows: `border`, `shadow-sm`, `shadow-xl/10`
- Rounded corners should be refined, not playful: `rounded-2xl`, `rounded-3xl`

## Component styling
- Buttons should feel premium: either `bg-amber-200 text-stone-950` or `border border-stone-300 bg-transparent`
- Inputs should feel clean and understated: `border-stone-300 bg-white text-stone-900`
- Large media blocks should use soft overlays instead of loud gradients
- Hover transitions should be subtle: `transition duration-300 ease-out`

## Do
- Keep contrast strong and readable on every surface
- Use editorial image crops and warm jewelry imagery
- Let whitespace create the premium feel
- Keep accents restrained and purposeful

## Don't
- Do not use bright sales colors, discount badges, or loud promotional patterns
- Do not mix multiple accent colors
- Do not use dense layouts or cramped cards
- Do not use heavy borders, thick shadows, or novelty styling
