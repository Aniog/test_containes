# Velmora Fine Jewelry — Design System

## Brand Direction
Quiet luxury, warm, editorial. Premium demi-fine jewelry. NOT loud, NOT discount-looking, NOT generic e-commerce.

## Color Palette

| Token | Hex | Usage |
|-------|-----|-------|
| --bg-cream | #F8F5F0 | Primary page background |
| --bg-deep | #1A1714 | Hero, dark sections, footer |
| --text-primary | #1A1714 | Body text, headings on light |
| --text-secondary | #6B6560 | Muted text, captions |
| --text-on-dark | #F8F5F0 | Text on dark backgrounds |
| --accent-gold | #C9A96E | CTA buttons, accents, stars |
| --accent-gold-hover | #B89860 | Button hover |
| --border-light | #E8E3DC | Dividers, borders on light |
| --border-dark | #3A3530 | Borders on dark |
| --card-bg | #FFFFFF | Product cards |

## Spacing
- Section vertical padding: 80px desktop, 56px mobile
- Content max-width: 1280px
- Grid gap: 24px desktop, 16px mobile
- Card border-radius: 0 (sharp editorial edges) or 2px

## Elevation & Shadows
- Card hover: 0 8px 32px rgba(26,23,20,0.08)
- Subtle transition: all 0.3s ease
- Image hover scale: 1.03 over 0.5s ease

## Buttons
- Primary: solid accent-gold, text #1A1714, uppercase, letter-spacing 0.1em, padding 14px 32px
- Secondary / Outline: 1px border accent-gold, text accent-gold, transparent bg
- Ghost: transparent, text-primary, hover underline

## Do's and Don'ts
- DO use generous whitespace
- DO use large editorial imagery
- DO use thin hairline dividers
- DO keep hover transitions subtle (0.3s)
- DON'T use loud discount-style colors (red, bright orange)
- DON'T use heavy drop shadows
- DON'T use rounded corners on product images
- DON'T use generic stock-photo styling
