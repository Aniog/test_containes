# SSourcing China — Design System

## Brand Identity
- Company: SSourcing China
- Tagline: China Sourcing Agent for Global Buyers
- Tone: Professional, trustworthy, clear, practical, international B2B

## Color Palette

### Primary Colors
- `brand-navy`: #0F2A4A — deep navy, primary brand color (trust, authority)
- `brand-blue`: #1A5FA8 — medium blue, interactive elements
- `brand-sky`: #2E8BC0 — lighter blue, accents and highlights
- `brand-red`: #C0392B — China red, accent for CTAs and highlights

### Neutral Colors
- `neutral-50`: #F8FAFC — page background
- `neutral-100`: #F1F5F9 — section alternating background
- `neutral-200`: #E2E8F0 — borders, dividers
- `neutral-400`: #94A3B8 — muted text, placeholders
- `neutral-600`: #475569 — secondary body text
- `neutral-800`: #1E293B — primary body text
- `neutral-900`: #0F172A — headings

### Semantic Colors
- Success: #16A34A
- Warning: #D97706
- Error: #DC2626

## Typography

### Font Family
- Primary: Inter (Google Fonts)
- Fallback: system-ui, sans-serif

### Scale
- Display: `text-5xl font-bold` (48px) — hero headlines
- H1: `text-4xl font-bold` (36px) — page titles
- H2: `text-3xl font-semibold` (30px) — section headings
- H3: `text-xl font-semibold` (20px) — card titles, subsections
- Body Large: `text-lg` (18px) — lead paragraphs
- Body: `text-base` (16px) — standard body text
- Small: `text-sm` (14px) — captions, labels, meta

## Spacing
- Section vertical padding: `py-16 md:py-24`
- Container max-width: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`
- Card padding: `p-6 md:p-8`
- Gap between cards: `gap-6 md:gap-8`

## Components

### Buttons
- Primary CTA: `bg-brand-red text-white px-6 py-3 rounded-lg font-semibold hover:bg-red-700 transition-colors`
- Secondary: `bg-brand-navy text-white px-6 py-3 rounded-lg font-semibold hover:bg-blue-900 transition-colors`
- Outline: `border-2 border-brand-navy text-brand-navy px-6 py-3 rounded-lg font-semibold hover:bg-brand-navy hover:text-white transition-colors`

### Cards
- Standard: `bg-white rounded-xl shadow-sm border border-neutral-200 p-6`
- Hover: `hover:shadow-md transition-shadow`

### Sections
- Light: `bg-neutral-50`
- Alternate: `bg-neutral-100`
- Dark: `bg-brand-navy text-white`

## Do's
- Use navy + red as the primary brand combination
- Keep layouts clean with generous whitespace
- Use icons alongside text for scannability
- Show trust signals prominently (years, clients, countries)
- Use numbered steps for process sections

## Don'ts
- No dark mode (light-only B2B site)
- No exaggerated claims or superlatives
- No cluttered layouts
- No low-contrast text combinations
- No decorative fonts
