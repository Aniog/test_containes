# SSourcing China — Design System

## Brand Overview
Professional B2B sourcing agent based in China. Target: overseas buyers, procurement managers, e-commerce sellers. Goal: generate qualified sourcing inquiries.

## Tone
Professional, clear, practical, no exaggerated claims. Trustworthy and international.

## Colors
- Primary: `#0f4c81` (deep trust blue)
- Primary Dark: `#0a3560`
- Accent: `#e67e22` (warm action orange)
- Accent Dark: `#c45d0e`
- Background: `#ffffff`
- Surface: `#f6f8fb`
- Text Primary: `#1a1a2e`
- Text Secondary: `#5a6270`
- Text Muted: `#8b93a3`
- Border: `#e2e8f0`
- Success: `#27ae60`
- Danger: `#c0392b`

## Typography
- Font: Inter (Google Fonts)
- H1: 48px / 1.1 / font-weight 700
- H2: 36px / 1.2 / font-weight 700
- H3: 24px / 1.3 / font-weight 600
- Body: 16px / 1.6 / font-weight 400
- Small: 14px / 1.5 / font-weight 400
- Label: 12px / 1.4 / font-weight 600 / uppercase / letter-spacing 0.05em

## Spacing
- Section padding: 80px vertical (desktop), 48px (mobile)
- Container max-width: 1200px, centered
- Card padding: 24px
- Grid gap: 24px–32px

## Components
- Buttons: rounded-md (6px), primary = blue bg + white text, secondary = white bg + blue border
- Cards: rounded-lg (10px), white bg, subtle border (#e2e8f0), light shadow
- Inputs: rounded-md, border #d1d5db, focus ring blue
- Badges: rounded-full, small padding, uppercase text

## Layout
- Fixed top navigation, white background, subtle bottom border
- Hero: full-width, light gradient or image background, left-aligned text + CTA
- Sections alternate: white / light gray (#f6f8fb)
- Footer: dark navy (#0a192f) with white text

## Do's
- Use realistic factory/QC/shipping imagery
- Keep text readable with strong contrast
- Use icons from Lucide React
- Maintain consistent spacing
- Use responsive breakpoints (md:, lg:)

## Don'ts
- No flashy animations
- No exaggerated claims or superlatives
- No low-contrast text
- No clutter — keep whitespace generous
