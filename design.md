# SSourcing China - B2B Website Design Guidelines

## Project Overview
- **Project Name**: SSourcing China Website
- **Type**: B2B corporate website for China sourcing agent
- **Goal**: Generate qualified sourcing inquiries from overseas buyers
- **Tone**: Professional, clear, practical, trustworthy, no exaggerated claims

## Visual Style

### Color Palette
- **Primary**: `#1E3A5F` (Deep Navy Blue - trust, professionalism)
- **Primary Light**: `#2D5A87` (Medium Blue)
- **Secondary**: `#F5A623` (Warm Amber - CTA buttons, highlights)
- **Secondary Hover**: `#E09000` (Darker Amber)
- **Accent**: `#00A651` (Success Green - trust indicators)
- **Background Primary**: `#FFFFFF` (White)
- **Background Secondary**: `#F8FAFC` (Light Gray-Blue)
- **Background Dark**: `#1A1A2E` (Dark Navy for footer)
- **Text Primary**: `#1F2937` (Dark Gray)
- **Text Secondary**: `#6B7280` (Medium Gray)
- **Text Light**: `#9CA3AF` (Light Gray)
- **Border**: `#E5E7EB` (Light Border)
- **Error**: `#DC2626` (Red)

### Typography
- **Font Family**: "Inter", system-ui, sans-serif
- **Headings**: 
  - H1: 48px/56px, font-weight 700
  - H2: 36px/44px, font-weight 600
  - H3: 24px/32px, font-weight 600
  - H4: 20px/28px, font-weight 500
- **Body**: 16px/24px, font-weight 400
- **Small**: 14px/20px, font-weight 400
- **Caption**: 12px/16px, font-weight 400

### Spacing System
- Base unit: 4px
- Section padding: 80px vertical (desktop), 48px (mobile)
- Container max-width: 1200px
- Grid gap: 24px (desktop), 16px (mobile)
- Card padding: 24px

### Visual Effects
- **Shadows**: 
  - Card: `0 4px 6px -1px rgba(0, 0, 0, 0.1), 0 2px 4px -1px rgba(0, 0, 0, 0.06)`
  - Elevated: `0 10px 15px -3px rgba(0, 0, 0, 0.1), 0 4px 6px -2px rgba(0, 0, 0, 0.05)`
  - Button hover: `0 4px 12px rgba(245, 166, 35, 0.4)`
- **Border Radius**: 
  - Buttons: 6px
  - Cards: 8px
  - Images: 4px
- **Transitions**: 200ms ease-in-out

### Layout
- **Header**: Fixed, white background, logo left, nav center, CTA right
- **Hero**: Full-width, split layout (text left, image right) or centered
- **Sections**: Alternating background colors (white/light gray)
- **Footer**: Dark background, multi-column layout

## Components

### Navigation
- Logo (left)
- Menu items: Home, Services, How It Works, Products, Case Studies, Blog, Contact
- CTA button: "Get a Free Quote" (right)
- Mobile: Hamburger menu with slide-out drawer

### Buttons
- **Primary**: Amber background (#F5A623), white text, 6px radius
- **Primary Hover**: Darker amber, slight shadow
- **Secondary**: Navy outline, navy text
- **Ghost**: No background, navy text

### Cards
- White background
- Light border
- 8px border radius
- Subtle shadow on hover

### Form Elements
- Input fields: Full width, 48px height, light border, 6px radius
- Focus state: Navy border
- Labels: Above input, medium weight

### Icons
- Lucide React icons
- Size: 24px default, 20px for inline
- Color: Match text color or primary

## Responsive Breakpoints
- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px

## Image Guidelines
- Use realistic factory/QC/shipping visuals
- Aspect ratios: 16:9 for hero, 4:3 for cards, 1:1 for team
- Placeholder: Light gray with subtle pattern

## Do's and Don'ts
- DO: Use professional, clean layouts with ample white space
- DO: Include trust signals (certifications, stats, testimonials)
- DO: Use clear, benefit-oriented copy
- DO: Make CTA buttons prominent and consistent
- DON'T: Use exaggerated claims or unrealistic promises
- DON'T: Use cluttered layouts or too many colors
- DON'T: Use low-quality or stock-photo-looking images
- DON'T: Use jargon without explanation
