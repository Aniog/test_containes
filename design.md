# SSourcing China - Design Guidelines

## Brand Identity

### Company Profile
- **Company**: SSourcing China
- **Industry**: B2B Sourcing Agent Services
- **Target Audience**: Overseas buyers seeking reliable Chinese suppliers
- **Value Proposition**: Professional sourcing, factory verification, quality control, and logistics coordination

### Color Palette
| Role | Color | Hex | Usage |
|------|-------|-----|-------|
| Primary | Deep Navy | #1E3A5F | Headers, CTAs, key elements |
| Secondary | Trust Blue | #2C5282 | Secondary buttons, accents |
| Accent | Professional Gold | #C9A227 | Highlights, badges, emphasis |
| Background Light | Off-White | #F8FAFC | Main background |
| Background Alt | Light Gray | #F1F5F9 | Alternate sections |
| Text Primary | Dark Slate | #1E293B | Body text |
| Text Secondary | Gray | #64748B | Supporting text |
| Success | Green | #059669 | Trust indicators |
| Border | Light Border | #E2E8F0 | Dividers, borders |

### Typography
- **Primary Font**: Inter (Google Fonts)
- **Headings**: Inter, Bold/Semibold, tracking tight
- **Body**: Inter, Regular, 16px base
- **Scale**: 14px, 16px, 18px, 20px, 24px, 32px, 40px, 48px

### Visual Style
- Clean, professional B2B aesthetic
- Photography: Realistic factory/warehouse/QC inspection imagery
- Icons: Lucide React - consistent stroke weight
- Layout: Spacious, 8px grid system
- Shadows: Subtle, professional (shadow-sm, shadow-md)

## Page Structure

### Navigation
- Fixed top navigation with logo
- Desktop: Horizontal menu items
- Mobile: Hamburger menu with slide-out drawer
- CTA button always visible: "Get a Free Sourcing Quote"

### Footer
- Company info and contact details
- Quick links to all pages
- Trust badges and certifications
- Copyright and legal links

## Components

### Buttons
- Primary: Navy background (#1E3A5F), white text, rounded-md
- Secondary: Outlined, navy border, navy text
- CTA: Gold accent (#C9A227) background for conversion-focused actions
- Hover: Slight darkening, subtle scale transform

### Cards
- White background, rounded-lg
- Subtle shadow (shadow-sm to shadow-md)
- Consistent padding (p-6 to p-8)
- Optional gold accent border for featured items

### Section Patterns
- Alternating background colors for visual rhythm
- Consistent vertical padding (py-16 to py-24)
- Max-width container for content alignment

### Trust Indicators
- Checkmark icons in green (#059669)
- Statistics with large numbers
- Client logos or testimonials
- Certification badges

### Form Elements
- Clean input fields with clear labels
- Proper spacing and validation states
- Clear submit button placement

## Imagery Guidelines
- Hero images: Professional warehouse/factory settings
- Service icons: Clean, simple line icons
- Process illustrations: Step-based visual guides
- Case study images: Before/after or product showcase

## Responsive Breakpoints
- Mobile: < 640px (sm)
- Tablet: 640px - 1024px (md, lg)
- Desktop: > 1024px (xl, 2xl)

## Animations
- Subtle fade-in on scroll
- Hover transitions (150-200ms)
- No excessive or distracting animations
- Professional, not playful
