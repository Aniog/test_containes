# SSourcing China — Design System

## Brand Identity
- Company: SSourcing China
- Tagline: China Sourcing Agent for Global Buyers
- Tone: Professional, clear, practical, trustworthy, international B2B

## Color Palette
- Primary Blue: `#1A4F8A` (navy/trust blue) → Tailwind: `blue-900` or custom `brand-blue`
- Accent Blue: `#2563EB` → Tailwind: `blue-600`
- Light Blue: `#EFF6FF` → Tailwind: `blue-50`
- Dark Navy: `#0F2A4A` → Tailwind: custom `brand-navy`
- Neutral Gray: `#64748B` → Tailwind: `slate-500`
- Light Gray: `#F8FAFC` → Tailwind: `slate-50`
- Border Gray: `#E2E8F0` → Tailwind: `slate-200`
- Text Dark: `#0F172A` → Tailwind: `slate-900`
- Text Body: `#334155` → Tailwind: `slate-700`
- White: `#FFFFFF`
- Success Green: `#16A34A` → Tailwind: `green-600`
- Warning Amber: `#D97706` → Tailwind: `amber-600`

## Typography
- Font Family: Inter (Google Fonts)
- H1: `text-4xl md:text-5xl lg:text-6xl font-bold text-slate-900 leading-tight`
- H2: `text-3xl md:text-4xl font-bold text-slate-900`
- H3: `text-xl md:text-2xl font-semibold text-slate-800`
- H4: `text-lg font-semibold text-slate-800`
- Body Large: `text-lg text-slate-700 leading-relaxed`
- Body: `text-base text-slate-600 leading-relaxed`
- Small: `text-sm text-slate-500`
- Caption: `text-xs text-slate-400 uppercase tracking-wide`

## Spacing
- Section padding: `py-16 md:py-24`
- Container: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`
- Card padding: `p-6 md:p-8`
- Gap between cards: `gap-6 md:gap-8`

## Components

### Buttons
- Primary: `bg-blue-600 hover:bg-blue-700 text-white font-semibold px-6 py-3 rounded-lg transition-colors`
- Secondary: `border-2 border-blue-600 text-blue-600 hover:bg-blue-50 font-semibold px-6 py-3 rounded-lg transition-colors`
- Ghost: `text-blue-600 hover:text-blue-700 font-medium`

### Cards
- Default: `bg-white rounded-xl shadow-sm border border-slate-200 p-6 hover:shadow-md transition-shadow`
- Feature: `bg-white rounded-xl shadow-sm border border-slate-200 p-8`
- Highlight: `bg-blue-600 text-white rounded-xl p-6`

### Navbar
- Background: `bg-white border-b border-slate-200 shadow-sm`
- Logo: brand-blue, bold
- Links: `text-slate-700 hover:text-blue-600 font-medium`
- CTA button: primary style

### Hero Section
- Background: dark navy gradient with subtle pattern
- Text: white on dark
- CTA: primary button + secondary outline

### Section Backgrounds
- White: default
- Light gray: `bg-slate-50`
- Light blue: `bg-blue-50`
- Dark navy: `bg-slate-900` (for trust/stats sections)

## Do's
- Use consistent 8px spacing grid
- Use Inter font throughout
- Keep CTAs prominent and action-oriented
- Use icons from lucide-react consistently
- Maintain high contrast for all text
- Use subtle shadows and borders for depth

## Don'ts
- No bright/neon colors
- No decorative fonts
- No low-contrast text combinations
- No cluttered layouts
- No exaggerated marketing claims
