# SSourcing China - B2B Website Design Guidelines

## Project Overview
- **Project Name**: SSourcing China Website
- **Type**: B2B corporate website for China sourcing agent
- **Goal**: Generate qualified sourcing inquiries from overseas buyers
- **Target Audience**: International B2B buyers looking for reliable Chinese suppliers

## Visual Style
- Clean, professional, trustworthy, international B2B aesthetic
- Realistic factory/QC/shipping visuals
- No exaggerated claims - practical and clear messaging

## Color Palette
- **Primary**: `#1E3A5F` (Deep Navy Blue - trust, professionalism)
- **Secondary**: `#2D5A87` (Medium Blue - reliability)
- **Accent**: `#E67E22` (Warm Orange - CTA buttons, energy)
- **Success**: `#27AE60` (Green - trust indicators)
- **Background Light**: `#F8FAFC` (Off-white)
- **Background Dark**: `#0F172A` (Dark navy for footer)
- **Text Primary**: `#1E293B` (Dark slate)
- **Text Secondary**: `#64748B` (Muted slate)
- **Border**: `#E2E8F0` (Light gray)

## Typography
- **Headings**: "Plus Jakarta Sans" - modern, professional, geometric
- **Body**: "Inter" - clean, readable, international
- **Font Sizes**:
  - H1: 48px (hero), 36px (page titles)
  - H2: 32px (section titles)
  - H3: 24px (card titles)
  - Body: 16px
  - Small: 14px

## Spacing System
- Section padding: 80px vertical (desktop), 48px (mobile)
- Container max-width: 1200px
- Card padding: 24px
- Grid gap: 32px (desktop), 24px (mobile)

## Layout Principles
- Clean white backgrounds for content sections
- Subtle gray backgrounds for alternating sections
- Full-width hero sections with overlay
- Card-based layouts for services and features
- Clear visual hierarchy with consistent spacing

## Component Styles

### Navigation
- Fixed header with white background
- Logo on left, navigation links center, CTA button right
- Subtle shadow on scroll
- Mobile: hamburger menu

### Buttons
- Primary: Orange background (#E67E22), white text, rounded corners
- Secondary: Navy outline, navy text
- Hover: Slight darken/shadow effect
- Padding: 12px 24px

### Cards
- White background
- Subtle shadow (0 4px 6px rgba(0,0,0,0.07))
- Rounded corners (8px)
- Hover: Lift effect with increased shadow

### Icons
- Lucide React icons
- Consistent sizing (24px for features, 48px for hero sections)
- Navy blue or accent color

## Backgrounds
- Hero: Dark overlay on industrial/sourcing image
- Alternating sections: Light gray (#F8FAFC)
- Footer: Dark navy (#0F172A)

## Visual Effects
- Subtle fade-in animations on scroll
- Smooth hover transitions (0.3s ease)
- Card hover lift effect
- Button hover scale/shadow

## Do's and Don'ts
- DO: Use professional photography, clean layouts, clear CTAs
- DON'T: Use cheesy stock photos, exaggerated claims, cluttered designs
- DO: Maintain consistent spacing and alignment
- DON'T: Use too many colors or decorative elements
- DO: Use clear, benefit-focused copy
- DON'T: Use jargon or vague statements
