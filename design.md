# SSourcing China - Design Guidelines

## Project Overview
- **Project Name**: SSourcing China Website
- **Type**: B2B Corporate Website
- **Purpose**: Generate qualified sourcing inquiries for China sourcing agent services
- **Target Audience**: Overseas buyers seeking reliable Chinese suppliers

## Visual Style
- Clean, professional, trustworthy, international B2B aesthetic
- Realistic factory/QC/shipping visuals
- No exaggerated claims - practical and clear messaging

## Typography
- **Primary Font**: Inter (Google Fonts)
- **Headings**: 
  - H1: 48px/56px, font-weight 700
  - H2: 36px/44px, font-weight 600
  - H3: 24px/32px, font-weight 600
  - H4: 20px/28px, font-weight 500
- **Body**: 16px/24px, font-weight 400
- **Small**: 14px/20px, font-weight 400

## Color Palette
- **Primary**: #1E3A5F (Deep Navy Blue - trust, professionalism)
- **Primary Light**: #2D5A87
- **Secondary**: #F97316 (Orange - CTA buttons, energy)
- **Secondary Hover**: #EA580C
- **Accent**: #0EA5E9 (Sky Blue - highlights)
- **Background Primary**: #FFFFFF
- **Background Secondary**: #F8FAFC
- **Background Tertiary**: #F1F5F9
- **Text Primary**: #1E293B
- **Text Secondary**: #475569
- **Text Muted**: #64748B
- **Border**: #E2E8F0
- **Success**: #10B981
- **Warning**: #F59E0B

## Spacing System
- **Section Padding**: 80px vertical (desktop), 48px (mobile)
- **Container Max Width**: 1200px
- **Grid Gap**: 24px (desktop), 16px (mobile)
- **Component Padding**: 24px

## Layout Principles
- Clean white backgrounds with subtle gray sections
- Generous whitespace for readability
- Card-based layouts for services and case studies
- Clear visual hierarchy with consistent spacing

## Components

### Navigation
- Fixed header with white background
- Logo on left, nav links center, CTA button right
- Mobile: hamburger menu with slide-out drawer

### Hero Section
- Full-width with subtle background
- Headline, subheadline, dual CTAs
- Trust badges below CTA

### Service Cards
- White background with subtle shadow
- Icon, title, description
- Hover: slight lift effect

### Process Steps
- Numbered steps with connecting line
- Icon, title, description per step

### Product Categories
- Grid of category cards
- Image, title, item count

### Case Study Cards
- Image, client name, challenge, result
- Statistics with icons

### FAQ Accordion
- Expandable questions
- Clean borders, smooth transitions

### Contact Form
- Clean input fields with labels
- Required field indicators
- Submit button with loading state

### Footer
- Multi-column layout
- Company info, quick links, services, contact
- Social links, copyright

## Responsive Breakpoints
- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px

## Do's and Don'ts
- DO: Use professional imagery, clear typography, consistent spacing
- DON'T: Use flashy animations, overly saturated colors, exaggerated claims
- DO: Maintain white space, use card layouts, show trust elements
- DON'T: Clutter pages, use too many colors, make text hard to read
