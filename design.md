# SSourcing China - Design Guidelines

## Project Overview
- **Project Name**: SSourcing China Website
- **Type**: B2B Corporate Website
- **Purpose**: Generate qualified sourcing inquiries for a China-based sourcing agent
- **Target Audience**: Overseas buyers, procurement managers, business owners looking to source products from China

## Visual Style
- Clean, professional, trustworthy, international B2B aesthetic
- Realistic factory/QC/shipping visuals
- No exaggerated claims - practical and clear messaging

## Color Palette
- **Primary**: #1E3A5F (Deep Navy Blue - trust, professionalism)
- **Secondary**: #2D5A87 (Medium Blue - reliability)
- **Accent**: #E67E22 (Warm Orange - CTA buttons, energy)
- **Success Green**: #27AE60 (trust indicators)
- **Light Background**: #F8FAFC (off-white)
- **Dark Text**: #1A1A2E (near-black)
- **Muted Text**: #64748B (slate gray)
- **Border**: #E2E8F0 (light gray)

## Typography
- **Headings**: Inter, bold weights (600, 700)
- **Body**: Inter, regular weight (400)
- **Font Sizes**:
  - H1: 48px (hero), 36px (page titles)
  - H2: 32px (section titles)
  - H3: 24px (subsection titles)
  - Body: 16px
  - Small: 14px

## Spacing System
- Section padding: 80px vertical (desktop), 48px (mobile)
- Container max-width: 1200px
- Grid gap: 32px
- Card padding: 24px

## Layout Principles
- Full-width sections with contained content
- Clear visual hierarchy
- Generous white space
- Card-based layouts for services and features
- Grid layouts for product categories and case studies

## Components

### Navigation
- Fixed header with logo, nav links, CTA button
- Mobile hamburger menu
- Active state indicator

### Hero Section
- Large headline with subheadline
- Primary CTA button
- Background image with overlay

### Service Cards
- Icon, title, description
- Hover effect with subtle shadow
- Link to services page

### Process Steps
- Numbered steps with icons
- Connecting line between steps
- Clear descriptions

### Trust Indicators
- Statistics (years, clients, factories)
- Client logos
- Certifications

### Case Study Cards
- Image, title, description, results
- Link to full case study

### FAQ Accordion
- Expandable questions
- Clean answer display

### Contact Form
- Name, email, company, message fields
- Validation states
- Submit button with loading state

## Do's and Don'ts
- DO: Use professional imagery of factories, QC inspections, shipping containers
- DO: Keep text concise and scannable
- DO: Use clear CTAs throughout
- DO: Include trust signals (certifications, stats)
- DON'T: Use overly flashy animations
- DON'T: Make exaggerated claims
- DON'T: Use low-quality or stock-photo-looking images
- DON'T: Clutter the design with too many elements

## Responsive Breakpoints
- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px
