# SSourcing China - Design System

## Brand Identity
- Professional B2B sourcing agent website
- Clean, trustworthy, international feel
- Target: overseas buyers looking for China sourcing support

## Colors
- Primary: `brand-blue` (#1e40af) - trust, professionalism
- Primary Dark: `brand-navy` (#1e3a5f) - headers, depth
- Accent: `brand-orange` (#f97316) - CTAs, highlights
- Background: `brand-light` (#f8fafc) - page backgrounds
- Surface: `brand-white` (#ffffff) - cards, sections
- Text Primary: `brand-text` (#1e293b) - headings, body
- Text Secondary: `brand-muted` (#64748b) - descriptions
- Border: `brand-border` (#e2e8f0) - dividers, card borders

## Typography
- Font: Inter (Google Fonts)
- Headings: font-bold, tracking-tight
  - H1: text-4xl md:text-5xl lg:text-6xl
  - H2: text-3xl md:text-4xl
  - H3: text-xl md:text-2xl
  - H4: text-lg md:text-xl
- Body: text-base (16px), text-brand-muted
- Small: text-sm

## Spacing
- Section padding: py-16 md:py-24
- Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8
- Gap between cards: gap-6 md:gap-8

## Components
- Buttons: rounded-lg, font-semibold, px-6 py-3
  - Primary: bg-brand-orange text-white hover:bg-orange-600
  - Secondary: bg-brand-blue text-white hover:bg-blue-800
  - Outline: border-2 border-brand-blue text-brand-blue hover:bg-brand-blue hover:text-white
- Cards: bg-white rounded-xl shadow-sm border border-brand-border p-6
- Badges: inline-flex px-3 py-1 rounded-full text-sm font-medium

## Layout
- Desktop: multi-column grids (2-4 cols)
- Mobile: single column stacking
- Navigation: sticky top, white bg, shadow-sm
- Footer: dark bg (brand-navy), white text

## Do's
- Use plenty of whitespace
- Keep text concise and scannable
- Use icons to support text
- Maintain consistent spacing
- Use stock images for factory/QC/shipping contexts

## Don'ts
- No exaggerated claims or hype language
- No cluttered layouts
- No invisible or low-contrast text
- No magic hex values outside the defined palette
- No single-column layouts on desktop
