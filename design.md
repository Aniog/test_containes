# Design System - SSourcing China

## Typography
- Primary Font: Inter (Sans-serif)
- Headings: Bold, primary color (#003b71)
- Body: slate-700 for readability

## Colors
- Primary: #003b71 (Trust, Professionalism, B2B)
- Accent: #ff6b00 (Action, Attention, Sourcing Energy)
- Background: #ffffff
- Muted: #f8fafc (slate-50)
- Border: #e2e8f0 (slate-200)

## Spacing
- Section Padding: py-16 to py-24
- Container: max-w-7xl mx-auto px-4

## UI Components (Tailwind)
- Buttons: .btn-primary, .btn-accent
- Cards: bg-white shadow-sm border border-slate-200 rounded-lg p-6
- Navigation: Sticky, glassmorphism or solid white with shadow

## Visual Style
- Clean, grid-based layouts
- High-quality professional imagery (Factory, Quality Control, Shipping containers)
- Clear hierarchy with bold typography
