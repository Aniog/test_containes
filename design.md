# SSourcing China - Design System

## Brand Identity
A professional B2B China sourcing agent website. Clean, trustworthy, international look.

## Typography
- Font: Inter (Google Fonts, loaded via index.html)
- Headings: font-bold, text-neutral-900
- Body: text-neutral-600, text-base
- Section titles: text-3xl md:text-4xl font-bold text-center
- Section subtitles: text-lg text-neutral-500 text-center max-w-2xl mx-auto

## Colors
- Primary Blue: brand-500 (#1e40af) - CTAs, links, key accents
- Dark Blue: brand-900 (#172554) - footer, deep backgrounds
- Accent Red: accent-500 (#dc2626) - urgency, important badges
- White: #ffffff - backgrounds, cards
- Light Gray: neutral-50 (#f8fafc) - alternating section backgrounds
- Medium Gray: neutral-200 (#e2e8f0) - borders, dividers
- Text Dark: neutral-900 (#0f172a) - headings
- Text Body: neutral-600 (#475569) - paragraphs
- Text Muted: neutral-400 (#94a3b8) - captions

## Spacing
- Section padding: py-16 md:py-24
- Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8
- Gap between grid items: gap-6 md:gap-8

## Components
- Cards: bg-white rounded-xl shadow-sm border border-neutral-100
- Primary buttons: bg-brand-500 hover:bg-brand-600 text-white font-semibold rounded-lg px-6 py-3
- Secondary buttons: bg-white border border-brand-500 text-brand-500 font-semibold rounded-lg px-6 py-3
- Input fields: border border-neutral-300 rounded-lg px-4 py-3 focus:ring-2 focus:ring-brand-500 focus:border-brand-500

## Do's
- Use white and light gray alternating sections
- Keep text left-aligned within centered containers
- Use blue for CTAs and trust elements
- Maintain generous whitespace
- Use stock images of real factories, QC inspections, shipping

## Don'ts
- No gradient backgrounds on sections
- No dark mode
- No exaggerated claims or flashy animations
- No purple, pink, or neon colors
- No overly dense text blocks
