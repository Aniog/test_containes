# SSourcing China Design System

## Brand Colors
- Primary: `#0f172a` (slate-900) - deep navy for headings, navbar
- Primary Accent: `#1e40af` (blue-800) - links, buttons, CTAs
- Primary Hover: `#1e3a8a` (blue-900)
- Secondary: `#64748b` (slate-500) - body text, descriptions
- Muted: `#94a3b8` (slate-400) - placeholders, borders
- Background: `#ffffff` (white) - main backgrounds
- Surface: `#f8fafc` (slate-50) - alternating sections
- Border: `#e2e8f0` (slate-200) - dividers, card borders
- Success: `#16a34a` (green-600)
- Alert: `#dc2626` (red-600)

## Typography
- Font family: Inter, system-ui, sans-serif
- Headings: font-weight 700-800, tight line-height (1.1-1.2)
- Body: font-weight 400-500, line-height 1.6
- Small/captions: font-weight 400, slate-500

## Spacing
- Section padding: py-20 (80px) on desktop, py-12 on mobile
- Container max-width: max-w-7xl
- Component gaps: gap-6 to gap-12

## Components
- Buttons: rounded-lg, px-6 py-3, font-semibold
  - Primary: bg-blue-800 text-white hover:bg-blue-900
  - Secondary: border border-slate-300 bg-white text-slate-900 hover:bg-slate-50
- Cards: bg-white rounded-xl border border-slate-200 shadow-sm p-6
- Inputs: rounded-lg border-slate-300 focus:ring-blue-800 focus:border-blue-800

## Visual Style
- Clean, minimal, trustworthy B2B aesthetic
- Plenty of whitespace
- Subtle shadows, not heavy
- Professional photography of factories, QC, shipping
- No gradients on buttons - solid colors
