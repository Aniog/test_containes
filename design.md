# SSourcing China - B2B Website Design Guidelines

## Project Overview
- **Project Name**: SSourcing China Website
- **Type**: B2B Corporate Website
- **Purpose**: Generate qualified sourcing inquiries for China-based sourcing agent services
- **Target Audience**: Overseas buyers seeking reliable Chinese suppliers

## Visual Style

### Overall Aesthetic
- Clean, professional, trustworthy
- International B2B feel
- No exaggerated claims - practical and clear
- Realistic factory/QC/shipping visuals

### Color Palette
- **Primary**: #1E3A5F (Deep Navy Blue) - Trust, professionalism
- **Secondary**: #2D5A87 (Medium Blue) - Supporting blue
- **Accent**: #E67E22 (Warm Orange) - CTA buttons, highlights
- **Success**: #27AE60 (Green) - Trust indicators
- **Background Light**: #F8FAFC (Off-white)
- **Background Dark**: #0F172A (Dark navy for footer)
- **Text Primary**: #1E293B (Dark slate)
- **Text Secondary**: #64748B (Muted slate)
- **Border**: #E2E8F0 (Light gray)

### Typography
- **Headings**: "DM Sans", sans-serif (Bold, professional)
- **Body**: "DM Sans", sans-serif (Regular, readable)
- **Font Sizes**:
  - H1: 48px (hero), 36px (page titles)
  - H2: 32px (section titles)
  - H3: 24px (subsection titles)
  - Body: 16px
  - Small: 14px

### Spacing System
- Section padding: 80px vertical, responsive
- Container max-width: 1200px
- Grid gap: 32px
- Card padding: 24px

### Visual Effects
- Subtle box shadows on cards: 0 4px 20px rgba(0,0,0,0.08)
- Hover transitions: 0.3s ease
- Border radius: 8px (cards), 4px (buttons)
- No excessive animations - professional restraint

## Layout Structure

### Header
- Logo (left)
- Navigation (center): Home, Services, How It Works, Products, Case Studies, Blog, Contact
- CTA Button (right): "Get a Free Quote"
- Sticky on scroll with subtle shadow

### Footer
- Company info and logo
- Quick links
- Services links
- Contact information
- Copyright

### Responsive Breakpoints
- Mobile: < 768px (single column, hamburger menu)
- Tablet: 768px - 1024px (2 columns)
- Desktop: > 1024px (full layout)

## Components

### Buttons
- Primary: Orange background (#E67E22), white text, rounded
- Secondary: Navy outline, navy text
- Hover: Slight darken, subtle lift

### Cards
- White background
- Subtle shadow
- 8px border radius
- Hover: Slight elevation increase

### Icons
- Lucide React icons
- Consistent sizing (24px standard)
- Navy or accent color

### Forms
- Clean input fields with border
- Clear labels
- Validation states
- Submit button prominent

## Do's and Don'ts

### Do
- Use professional, realistic imagery
- Keep text concise and scannable
- Use clear CTAs
- Maintain consistent spacing
- Ensure mobile responsiveness

### Don't
- Use exaggerated claims ("#1", "best", "guaranteed")
- Use stock photos that look fake
- Overcrowd sections
- Use too many colors
- Make text too small to read
