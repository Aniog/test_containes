# SSourcing China — Design System

## Brand Identity
- Company: SSourcing China
- Tagline: China Sourcing Agent for Global Buyers
- Tone: Professional, trustworthy, international, practical, B2B

## Color Palette
- Primary Blue: `#1A3C6E` (deep navy — trust, authority)
- Accent Red: `#C0392B` (China red — identity, energy)
- Accent Gold: `#D4A017` (quality, premium)
- Light Blue: `#EBF2FA` (backgrounds, cards)
- Neutral Gray: `#6B7280`
- Dark Text: `#1F2937`
- Light Text: `#F9FAFB`
- Border: `#E5E7EB`
- White: `#FFFFFF`

## Typography
- Font: Inter (Google Fonts)
- Headings: font-bold, tracking-tight
- Body: font-normal, leading-relaxed
- H1: text-4xl md:text-5xl lg:text-6xl
- H2: text-3xl md:text-4xl
- H3: text-xl md:text-2xl
- Body: text-base md:text-lg

## Tailwind Config Extensions
- `primary`: `#1A3C6E`
- `accent`: `#C0392B`
- `gold`: `#D4A017`
- `lightblue`: `#EBF2FA`

## Spacing
- Section padding: `py-16 md:py-24`
- Container: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`
- Card padding: `p-6 md:p-8`
- Gap between cards: `gap-6 md:gap-8`

## Components
- Buttons: rounded-md, px-6 py-3, font-semibold
- Primary CTA: bg-accent text-white hover:bg-red-700
- Secondary CTA: border-2 border-primary text-primary hover:bg-primary hover:text-white
- Cards: bg-white rounded-xl shadow-md border border-gray-100
- Section headers: centered, with colored underline accent
- Nav: sticky top-0, bg-white shadow-sm, z-50

## Do's
- Use navy (#1A3C6E) for headings and nav
- Use red (#C0392B) for primary CTAs and highlights
- Use gold (#D4A017) sparingly for trust badges and stars
- Use lightblue (#EBF2FA) for alternating section backgrounds
- Keep layouts clean with generous whitespace
- Use icons from lucide-react for service/feature items

## Don'ts
- No dark text on dark backgrounds
- No overly bright or saturated colors
- No exaggerated marketing claims
- No cluttered layouts
