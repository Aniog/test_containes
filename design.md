# SSourcing China Design System

## Brand Overview
SSourcing China is a professional B2B sourcing agent website targeting global buyers. The design conveys trust, reliability, and international professionalism.

## Color Palette

### Primary Colors
- **Navy (Primary)**: `#0F2B5B` - Used for headers, primary text, nav background
- **Royal Blue (Secondary)**: `#1E6FD9` - Used for links, secondary accents, hover states
- **Orange (CTA Accent)**: `#E87C3E` - Used for call-to-action buttons, highlights
- **White**: `#FFFFFF` - Cards, backgrounds, text on dark surfaces

### Background Colors
- **Light Background**: `#F7F9FC` - Main page background
- **Lighter Background**: `#EDF2F7` - Alternate section backgrounds
- **Card Background**: `#FFFFFF` - Cards and elevated surfaces
- **Dark Background**: `#0F2B5B` - Footer, dark sections

### Text Colors
- **Primary Text**: `#1A202C` - Headings, primary content
- **Secondary Text**: `#4A5568` - Body text, descriptions
- **Muted Text**: `#718096` - Captions, supplementary text
- **Light Text**: `#FFFFFF` - Text on dark backgrounds
- **Muted Light**: `#CBD5E0` - Muted text on dark backgrounds

### Status Colors
- **Success/Green**: `#22A06B` - Trust indicators, checkmarks, success states
- **Warning/Amber**: `#D97706` - Warning states
- **Error/Red**: `#E53E3E` - Error states

## Typography

### Font Family
- **Primary**: Inter, system-ui, sans-serif
- **Weights**: 300 (light), 400 (regular), 500 (medium), 600 (semibold), 700 (bold), 800 (extrabold)

### Font Sizes
- **Hero Title**: 3.5rem (56px) / line-height 1.1, font-weight 800
- **Section Title**: 2.25rem (36px) / line-height 1.2, font-weight 700
- **Card Title**: 1.25rem (20px) / line-height 1.4, font-weight 600
- **Body Large**: 1.125rem (18px) / line-height 1.7
- **Body**: 1rem (16px) / line-height 1.6
- **Small**: 0.875rem (14px) / line-height 1.5
- **Caption**: 0.75rem (12px) / line-height 1.4, uppercase, letter-spacing 0.05em

## Spacing

### Section Spacing
- **Section Padding**: py-16 (64px) on desktop, py-10 (40px) on mobile
- **Container Max Width**: max-w-7xl (1280px)
- **Container Padding**: px-6 (24px) on mobile, px-8 (32px) on desktop

### Component Spacing
- **Card Padding**: p-6 (24px) or p-8 (32px)
- **Grid Gap**: gap-6 (24px) or gap-8 (32px)
- **Element Spacing**: space-y-4 (16px) or space-y-6 (24px)

## Border & Shadows

### Border Radius
- **Small**: rounded-md (6px)
- **Medium**: rounded-lg (8px)
- **Large**: rounded-xl (12px)
- **Full**: rounded-full (for avatars, badges)

### Shadows
- **Small Shadow**: shadow-sm - subtle elevation
- **Medium Shadow**: shadow-md - cards, elevated elements
- **Large Shadow**: shadow-xl - modals, popups

- **Secondary**: bg-blue-600 hover:bg-blue-700 text-white rounded-lg px-6 py-3 font-semibold
- **Outline**: border-2 border-navy-900 text-navy-900 hover:bg-navy-900 hover:text-white rounded-lg px-6 py-3 font-semibold
- **Ghost**: text-navy-900 hover:bg-gray-100 rounded-lg px-4 py-2

### Cards
- **Standard**: bg-white rounded-xl shadow-md p-6 border border-gray-100
- **Feature Card**: bg-white rounded-xl shadow-md p-8 border border-gray-100 with icon
- **Testimonial Card**: bg-white rounded-xl shadow-md p-8 border border-gray-100 with quote

### Sections
- **White Section**: bg-white py-16
- **Light Section**: bg-gray-50 py-16

### Badges
- **Trust Badge**: bg-green-100 text-green-800 rounded-full px-3 py-1 text-sm font-medium
- **Category Badge**: bg-blue-100 text-blue-800 rounded-full px-3 py-1 text-sm font-medium
- **Status Badge**: bg-amber-100 text-amber-800 rounded-full px-3 py-1 text-sm font-medium

## Layout Patterns

### Hero Section
- Full-width with gradient background
- Left-aligned text with right-side image/graphic
- Primary CTA (orange) + Secondary CTA (outline/white)
- Trust badges below CTA

### Feature Grid
- 3-column grid on desktop, 2-column on tablet, 1-column on mobile
- Icon + Title + Description pattern
- Consistent card heights

### Testimonials
- 3-column grid with avatar, quote, name, title
- Star ratings where applicable

### Process Steps
- Horizontal timeline on desktop
- Vertical timeline on mobile
- Numbered steps with connecting lines

## Stock Image Usage
- Factory/manufacturing scenes for services
- Quality control/inspection images
- Shipping/logistics imagery
- Product category images (electronics, textiles, machinery, etc.)
- Office/team meeting images for trust sections

## Do's
- Use consistent spacing throughout
- Maintain high contrast for readability
- Keep CTAs prominent and consistent
- Use trust indicators (badges, numbers, testimonials)
- Ensure responsive design at all breakpoints

## Don'ts
- Don't use more than 3 colors per section
- Don't use font sizes below 12px
- Don't use low contrast text (minimum 4.5:1 ratio)
- Don't center-align long paragraphs
- Don't use excessive animation or effects
