# Design Guidelines: SSourcing China

## Visual Style
* Professional, trustworthy, international B2B look.
* Clean layouts with ample whitespace.
* Strong focus on readability and clear calls to action.

## Color Palette
* Primary: #0F172A (Deep Slate/Navy - Trust, Authority)
* Secondary: #2563EB (Blue - Professionalism, Reliability)
* Accent: #F97316 (Orange - Energetic, Action-oriented for CTAs)
* Background: #FFFFFF (White) / #F8FAFC (Off-white for sections)
* Text: #1E293B (Dark Gray for body), #0F172A (Heading Navy)

## Typography
* Primary Font: 'Inter', sans-serif (Clean, modern B2B standard)
* Headings: FontWeight 700 (Bold) for H1/H2, 600 (Semi-bold) for H3
* Body: FontWeight 400 (Regular), 1.5 line height for readability.

## Components Style
* Buttons: Rounded-md (Medium), shadow-sm on hover.
* Cards: Bordered with subtle shadow, white background.
* Inputs: Rounded-md, clear focus states.

## Do's
* Use high-quality realistic industrial/sourcing images (via data-strk-img).
* Maintain consistent spacing (Tailwind spacing scale).
* Ensure high contrast for all text.
* Responsive design - priority on mobile readability while maintaining professional desktop layout.

## Don'ts
* Avoid overly bright or neon colors.
* No cluttered layouts.
* Don't use generic clip-art.
* Don't use low-contrast text (e.g., light gray on white).
