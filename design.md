# SSourcing China - Visual Design Guidelines

## Brand Overview
Professional B2B China sourcing agent website. Clean, trustworthy, international aesthetic. Focus on reliability, expertise, and practical value. No exaggerated claims.

## Color Palette
- Primary: #0F172A (Slate 900) - Deep navy for headers and key text
- Secondary: #1E293B (Slate 800) - Dark slate for secondary elements
- Accent: #0EA5E9 (Sky 500) - Trustworthy blue for CTAs and highlights
- Accent Dark: #0284C8 (Sky 600) - Darker blue for hover states
- Neutral: #F8FAFC (Slate 50) - Light background
- Neutral Alt: #F1F5F9 (Slate 100) - Card backgrounds
- Text Primary: #0F172A - Main body text
- Text Secondary: #475569 (Slate 600) - Supporting text
- Text Muted: #64748B (Slate 500) - Subtle labels
- Success: #059669 (Emerald 600) - For trust indicators
- Border: #E2E8F0 (Slate 200) - Dividers and borders

## Typography
- Font: Inter (system-ui fallback)
- Headings: 600-700 weight, tight tracking
- Body: 400-500 weight, 1.6 line-height for readability
- H1: 48px / 56px (desktop), 32px / 40px (mobile)
- H2: 32px / 40px (desktop), 24px / 32px (mobile)
- H3: 20px / 28px
- Body: 16px / 26px
- Small: 14px / 20px

## Layout & Spacing
- Max content width: 1280px
- Section padding: 80px vertical (desktop), 48px (mobile)
- Container padding: 24px horizontal
- Card padding: 32px
- Consistent 8px grid system
- Generous whitespace between sections

## Visual Style
- Clean, minimal borders (1px solid #E2E8F0)
- Subtle shadows: 0 1px 3px rgba(15, 23, 42, 0.08)
- Rounded corners: 8px for cards, 6px for buttons/inputs
- Professional photography: factories, QC inspections, shipping, meetings
- Icons: Lucide React, 24px stroke, consistent line weight
- No decorative flourishes or gradients

## Components
- Buttons: Solid primary (bg-sky-500), outline secondary, ghost tertiary
- Cards: White bg, subtle border, hover lift on interactive
- Forms: Clean inputs with focus ring, clear labels
- Navigation: Fixed top bar, subtle bottom border
- Footer: Dark slate, organized links

## Tone in Design
- Professional, clear, practical
- Trust signals prominent (certifications, years, clients)
- Data and process oriented
- International B2B feel

## Do's
- Use plenty of white space
- Align elements to grid
- Use real-looking professional imagery
- Keep text concise and scannable
- Show process steps clearly
- Include specific numbers and facts

## Don'ts
- No bright or playful colors
- No stock photo clichés (smiling handshakes)
- No exaggerated claims or hype language
- No cluttered layouts
- No low-contrast text
