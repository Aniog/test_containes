# Velmora Fine Jewelry — Design System

## Visual Identity
- Mood: Quiet luxury, warm, editorial. Premium demi-fine jewelry.
- NOT loud, NOT discount-looking, NOT generic e-commerce.

## Color Palette
| Token | Hex | Usage |
|-------|-----|-------|
| `warm-black` | #1C1917 | Primary dark background, nav solid |
| `warm-charcoal` | #2E2A26 | Card backgrounds on dark, borders |
| `warm-brown` | #3D3530 | Subtle dark surfaces |
| `cream` | #F5F0EB | Light backgrounds, text on dark |
| `warm-white` | #FAF7F2 | Page background (light mode) |
| `gold` | #C9A96E | Primary accent, CTA buttons, highlights |
| `gold-dark` | #A68B4B | Hover states, pressed buttons |
| `gold-light` | #D4B87A | Subtle gold highlights |
| `muted` | #8C8279 | Secondary text, captions |
| `muted-light` | #B5A99A | Placeholder text on light bg |

## Typography
- **Headings / Product names**: Cormorant Garamond (serif), weight 400-600
- **Body / UI**: Inter (sans-serif), weight 400-500
- Product names: UPPERCASE, letter-spacing 0.15em
- Headlines: UPPERCASE or mixed, letter-spacing 0.05em
- Body: normal case, letter-spacing 0

## Spacing & Layout
- Generous whitespace: section padding 80-120px desktop, 48-64px mobile
- Grid gaps: 24-32px
- Hairline dividers: 1px, color warm-charcoal or gold at 30% opacity
- Max content width: 1280px

## Buttons
- Primary: solid gold bg (#C9A96E), cream text, rounded-none or rounded-sm, hover gold-dark
- Secondary: outlined (1px gold border), gold text, transparent bg, hover fills gold
- Size: py-3 px-8 desktop, py-2.5 px-6 mobile
- Font: Inter, uppercase, letter-spacing 0.1em, font-size 0.8rem

## Cards
- Product cards: minimal, no visible border, subtle shadow on hover
- Image aspect: 3x4 or 4x5 for product shots
- Hover: second image fade-in, slight scale (1.02), shadow increase

## Animations
- Subtle, smooth: transition duration 300-500ms, ease-in-out
- Hover: opacity changes, scale 1.02, shadow transitions
- No bouncing, no flashy effects
- Nav: background opacity transition on scroll

## Shadows
- Soft, warm: shadow color uses warm tones not cool gray
- `shadow-sm`: 0 1px 3px rgba(28,25,23,0.08)
- `shadow-md`: 0 4px 12px rgba(28,25,23,0.12)
- `shadow-lg`: 0 8px 24px rgba(28,25,23,0.16)

## Do's
- Use cream/warm-white backgrounds for light sections
- Use warm-black for dramatic hero and footer sections
- Gold accent sparingly — CTAs, highlights, dividers
- Large editorial imagery with warm lighting
- Generous padding and whitespace

## Don'ts
- Never use cool gray or blue tones
- Never use pure white (#FFF) as background — always warm-white or cream
- Never use pure black (#000) — always warm-black
- Never crowd elements — maintain breathing room
- Never use loud/discount visual patterns (badges, red sale tags)
