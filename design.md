# Velmora Fine Jewelry — Design System

## Brand
Velmora Fine Jewelry — DTC demi-fine gold jewelry. Premium-but-accessible ($30–$120).
Target: women 25–45, gifting and self-purchase.
Mood: quiet luxury, warm, editorial.

## Color Palette
- **Background**: `#FAF7F2` (warm ivory/cream) — main page background
- **Surface**: `#FFFFFF` (white) — cards, dropdowns, modals
- **Primary / Text**: `#1A1A1A` (near-black) — headings, body text
- **Secondary Text**: `#6B6258` (warm taupe) — muted labels, secondary copy
- **Accent / Gold**: `#C8A45C` (warm gold) — buttons, highlights, accent elements
- **Accent Hover**: `#B8943E` (darker gold)
- **Border / Divider**: `#E5DFD8` (warm beige) — hairline separators, borders
- **Light Background**: `#F0ECE6` (warm light) — hover states, secondary backgrounds
- **Success**: `#2D6A4F` (deep green)
- **Error**: `#9B2C2C` (deep red)

## Typography
- **Headings**: 'Cormorant Garamond', serif — elegant, refined
- **Body / UI**: 'Inter', sans-serif — clean, readable
- **Product Names**: 'Cormorant Garamond', serif, UPPERCASE, letter-spacing: 0.08em
- **Font Sizes**: 
  - Hero headline: 3.5rem (desktop), 2.25rem (mobile)
  - Section headings: 2rem (desktop), 1.5rem (mobile)
  - Product names: 0.875rem
  - Body: 0.9375rem
  - Small / UI: 0.8125rem

## Spacing
- Section padding: 5rem (desktop), 3rem (mobile)
- Grid gap: 1.5rem
- Card padding: 1.5rem
- Generous whitespace between sections

## Borders & Dividers
- Hairline borders: 1px solid #E5DFD8
- Card borders: none (shadow only)
- Soft shadows: 0 2px 8px rgba(0,0,0,0.04), 0 1px 2px rgba(0,0,0,0.06)

## Buttons
- Primary: solid gold (#C8A45C) background, white text, full-width or inline
- Outline: 1px solid #C8A45C, gold text, transparent background
- Hover: darken gold to #B8943E, subtle transition 0.2s ease
- Border radius: 0 (sharp, premium)
- Padding: 0.875rem 2rem
- Font: Inter, 0.8125rem, uppercase, tracking-wider

## Transitions & Animations
- Hover transitions: 0.2s ease all
- Image hover: scale 1.03, 0.4s ease
- Nav scroll: background change 0.3s ease
- Cart drawer: slide from right, 0.3s ease

## Image Guidelines
- Product images: warm gold jewelry on dark neutral or warm backgrounds
- Hero: full-bleed editorial, model wearing jewelry, warm lighting
- Category tiles: editorial shots, warm tones
- UGC: vertical (9:16) format, mimic Instagram Reels

## Do's
- Use generous whitespace
- Use thin dividers
- Keep UI minimal and refined
- Serif for elegance, sans-serif for utility
- Gold accents throughout

## Don'ts
- No loud colors or flashy gradients
- No heavy shadows or borders
- No discount/coupon-clutter look
- No generic e-commerce patterns
- No emoji in UI text
