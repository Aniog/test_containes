# SSourcing China - Design System

## Brand Identity
- **Company**: SSourcing China
- **Industry**: B2B Sourcing Agent
- **Tone**: Professional, trustworthy, clear, practical
- **Target**: International buyers sourcing from China

## Color Palette

### Primary (Navy/Blue - Trust & Professionalism)
- Primary 800: `#1e3a5f` - Main brand color, headers, CTAs
- Primary 700: `#1d4ed8` - Interactive elements
- Primary 600: `#2563eb` - Links, active states
- Primary 50: `#eff6ff` - Light backgrounds

### Accent (Orange - Action & Attention)
- Accent 500: `#f97316` - Primary CTA buttons
- Accent 600: `#ea580c` - CTA hover states

### Neutrals
- Navy: `#0f172a` - Headlines, primary text
- Slate 700: `#334155` - Body text
- Slate 500: `#64748b` - Secondary text
- Slate 200: `#e2e8f0` - Borders
- Slate 50: `#f8fafc` - Section backgrounds

## Typography

### Font Family
- Primary: Inter (Google Fonts)
- Fallback: system-ui, -apple-system, sans-serif

### Font Sizes
- H1: 3rem / 3.5rem (mobile/desktop), weight 800
- H2: 2rem / 2.5rem, weight 700
- H3: 1.5rem, weight 600
- Body: 1rem / 1.125rem, weight 400
- Small: 0.875rem

### Line Heights
- Headings: 1.2
- Body: 1.6

## Spacing
- Section padding: 4rem / 6rem (mobile/desktop)
- Container max-width: 1280px
- Card padding: 1.5rem / 2rem

## Components

### Buttons
- **Primary (CTA)**: Orange background, white text, rounded-lg, shadow
- **Secondary**: Navy background, white text
- **Outline**: Navy border, navy text, fills on hover

### Cards
- White background, subtle border, rounded-xl
- Hover: shadow-lg elevation
- Padding: 1.5rem

### Badges
- Rounded-full pills
- Light background with colored text

## Layout Guidelines
- Clean white backgrounds for content sections
- Alternating section backgrounds (white / slate-50)
- Consistent container widths
- Mobile-first responsive design
- Breakpoints: sm(640px), md(768px), lg(1024px), xl(1280px)

## Do's
- Use professional, clean layouts
- Maintain consistent spacing
- Use real product/factory imagery via stock system
- Keep text readable with good contrast
- Use Inter font weights appropriately

## Don'ts
- Don't use flashy gradients or animations
- Don't use informal language
- Don't overcrowd sections
- Don't use low-contrast text combinations
- Don't use decorative fonts for body text

## Image Strategy
- Use data-strk-img for factory, QC, shipping visuals
- Ratio preferences: 16x9 for heroes, 4x3 for cards, 3x2 for thumbnails
- Contextual queries referencing section text
