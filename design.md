# SSourcing China - Design Guidelines

## Project Overview
- **Project Name**: SSourcing China Website
- **Type**: B2B Corporate Website
- **Purpose**: Generate qualified sourcing inquiries for China sourcing agent services
- **Target Audience**: Overseas buyers, procurement managers, business owners looking for reliable Chinese suppliers

## Visual Style
- Clean, professional, trustworthy, international B2B aesthetic
- Realistic factory/QC/shipping visuals
- No exaggerated claims - practical and clear messaging

## Typography
- **Primary Font**: Inter (Google Fonts)
- **Headings**: 
  - H1: 48px/56px, font-weight 700
  - H2: 36px/44px, font-weight 600
  - H3: 24px/32px, font-weight 600
  - H4: 20px/28px, font-weight 500
- **Body**: 16px/24px, font-weight 400
- **Small**: 14px/20px, font-weight 400

## Color Palette
- **Primary**: #1E3A5F (Deep Navy Blue - trust, professionalism)
- **Primary Light**: #2D5A8A
- **Secondary**: #F97316 (Orange - CTAs, energy)
- **Secondary Hover**: #EA580C
- **Accent**: #10B981 (Green - success, reliability)
- **Background Primary**: #FFFFFF
- **Background Secondary**: #F8FAFC
- **Background Tertiary**: #F1F5F9
- **Text Primary**: #1E293B
- **Text Secondary**: #64748B
- **Text Muted**: #94A3B8
- **Border**: #E2E8F0
- **Border Dark**: #CBD5E1

## Spacing System
- **Base unit**: 4px
- **Section padding**: 80px vertical (desktop), 48px (mobile)
- **Container max-width**: 1200px
- **Grid gap**: 24px (desktop), 16px (mobile)

## Layout Principles
- Clean white backgrounds with subtle gray sections
- Generous whitespace for readability
- Card-based layouts for services and features
- Clear visual hierarchy
- Responsive design (mobile-first approach)

## Components

### Navigation
- Fixed header with white background
- Logo on left, nav links center, CTA button right
- Mobile: hamburger menu
- Active state: primary color underline

### Buttons
- **Primary**: Orange background (#F97316), white text, rounded-md
- **Secondary**: White background, primary border, primary text
- **Hover**: Darker shade, subtle shadow
- **Padding**: 12px 24px

### Cards
- White background
- Subtle shadow (0 4px 6px rgba(0,0,0,0.05))
- Rounded-lg (8px)
- Hover: elevated shadow

### Icons
- Lucide React icons
- Size: 24px default, 20px for inline
- Color: inherit or primary

## Sections

### 1. Hero Section
- Full-width background with subtle gradient or image overlay
- Headline: "China Sourcing Agent for Global Buyers"
- Subheadline: Value proposition
- CTA: "Get a Free Sourcing Quote"
- Trust badges below CTA

### 2. Services Section
- 3-4 column grid
- Icon + title + description per card
- Services: Supplier Verification, Quality Inspection, Production Follow-up, Shipping Coordination

### 3. Sourcing Process Section
- Step-by-step horizontal timeline
- Numbered steps with icons
- Clear process flow

### 4. Products We Source Section
- Category grid with images
- Categories: Electronics, Furniture, Textiles, Machinery, Packaging, etc.

### 5. Problems We Solve Section
- Problem/Solution format
- Common pain points buyers face
- How SSourcing China solves them

### 6. Trust Points Section
- Statistics, certifications, experience
- Numbers: years in business, suppliers verified, clients served

### 7. Case Studies Section
- 3 featured case studies
- Brief success stories with results

### 8. FAQ Section
- Accordion style
- Common questions about sourcing

### 9. Inquiry Form Section
- Contact form with fields: name, email, company, product details
- Clear call-to-action

### 10. Footer
- Company info, quick links, contact details
- Copyright

## Responsive Breakpoints
- **Mobile**: < 640px
- **Tablet**: 640px - 1024px
- **Desktop**: > 1024px

## Do's and Don'ts
- DO: Use professional imagery, clear typography, consistent spacing
- DO: Include trust signals and social proof
- DON'T: Use exaggerated claims or unrealistic promises
- DON'T: Clutter the design with too many elements
- DON'T: Use bright/clashing colors
- DON'T: Make text hard to read with low contrast
