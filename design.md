# SSourcing China Design System

## Overview
Professional, clean, trustworthy B2B website for a China-based sourcing agent. International audience, practical tone, no exaggerated claims.

## Typography
- Primary font: Inter (Google Fonts)
- Headings: font-semibold to font-bold, tight tracking
- Body: font-normal, relaxed line-height for readability
- Scale: text-sm, text-base, text-lg, text-xl, text-2xl, text-3xl, text-4xl

## Color Palette
- Primary: slate-900 / slate-950 (headings, strong text)
- Secondary: slate-600 / slate-700 (body text, muted content)
- Accent: blue-600 / blue-700 (CTAs, links, active states)
- Background: white, slate-50, slate-100
- Borders: slate-200, slate-300
- Success: emerald-600
- Warning: amber-600
- Error: red-600

## Spacing
- Section padding: py-16 to py-24
- Container max-width: max-w-7xl
- Grid gaps: gap-6 to gap-8
- Card padding: p-6 to p-8

## Components
- Cards: white background, rounded-lg, border border-slate-200, shadow-sm
- Buttons: rounded-md, font-medium, px-6 py-3
- Inputs: rounded-md, border-slate-300, focus:ring-2 focus:ring-blue-500
- Badges: rounded-full, text-xs, font-medium, px-3 py-1

## Imagery
- Use stock images via data-strk-img system for factory, QC, shipping visuals
- Aspect ratios: 16x9 for hero/featured, 4x3 for cards, 3x2 for process steps
- Professional, realistic, no cartoonish or overly generic stock photos

## Layout
- Desktop: multi-column grids, not single-column stacking
- Mobile: single column with proper spacing
- Navigation: sticky top nav, clean horizontal layout on desktop, hamburger on mobile
- Forms: max-w-2xl, clear labels, proper spacing

## Do's
- Use slate/blue palette for trust and professionalism
- Include subtle borders and shadows for depth
- Use icons from lucide-react consistently
- Keep plenty of whitespace
- Use clear section headings and subheadings

## Don'ts
- No bright/neon colors
- No cluttered layouts
- No exaggerated claims or hype language
- No low-contrast text
- No magic values or arbitrary spacing
