# Visual Style Guide - SSourcing China

## Typography
- Primary Font: Inter (Sans-serif)
- Headings: Semi-bold to Bold, slate-900
- Body: Regular, slate-600 to slate-700
- Line-height: 1.6 for readability

## Colors
- Primary: #2563eb (Blue 600) - `bg-primary`, `text-primary`
- Secondary: #64748b (Slate 500)
- Trust: #059669 (Emerald 600) for success points
- Alert/Action: #ef4444 (Red 500) for urgent CTAs if any
- Backgrounds:
  - Neutral-50 (f8fafc) for alternating sections
  - White (ffffff) for main content

## Spacing & Layout
- Container: 1200px max-width, center-aligned
- Section Padding: `py-16 md:py-24`
- Grid Gap: `gap-8` for major components
- Rounding: `rounded-lg` (8px) for cards and buttons

## UI Elements
- Buttons: Professional, crisp borders or solid backgrounds.
- Cards: Subtle shadows (`shadow-sm` or `shadow-md`), white background.
- Icons: Lucide React, stroke-width 1.5-2.0, slate-500/600.

## Imagery
- Realistic factory, QC, and logistics photos.
- Dynamic search queries using `data-strk-img` or `data-strk-bg`.
- Ratios: 16x9 for heroes, 3x2 or 4x3 for service cards.
