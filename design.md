# SSourcing China - Visual Style Guide

## Typography
- **Main Font**: Inter, sans-serif
- **Headings**: Semibold/Bold, slate-900 for high contrast.
- **Body**: Regular, slate-600 for readability.
- **Examples**:
  - H1: `text-4xl md:text-6xl font-bold tracking-tight text-slate-900`
  - H2: `text-3xl md:text-4xl font-semibold text-slate-900`
  - Body: `text-lg text-slate-600 leading-relaxed`

## Colors
- **Primary**: Navy Blue (`#1e293b` - `bg-slate-800`, `text-slate-800`) - Professional, trust.
- **Accent**: Royal Blue (`#2563eb` - `bg-blue-600`, `text-blue-600`) - Actions, importance.
- **Success**: Green (`#16a34a` - `bg-green-600`) - Trust, results.
- **Background**: White (`#ffffff`), Light Gray (`#f8fafc` - `bg-slate-50`).

## Borders and Spacing
- **Rounded Corners**: `rounded-lg` (8px) or `rounded-xl` (12px).
- **Section Padding**: `py-16 md:py-24`.
- **Container**: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`.

## Visual Style
- **International B2B**: Clean, corporate yet modern, high-quality images.
- **Trust Elements**: Badges, testimonials, clear process diagrams.
- **Photography**: Realistic factory floors, QC inspections, port logistics, business meetings.
- **Interactive**: subtle hover states on cards and buttons.

## Do's and Don'ts
- **Do**: Use high-contrast text. Use consistent spacing. Include clear CTAs.
- **Don't**: Use overly bright/neon colors. Use hardcoded pixel values. Overcrowd the mobile view.
