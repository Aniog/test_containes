# SSourcing China - Design System

## Brand Identity
- Professional B2B sourcing agent based in China
- Trustworthy, clean, international feel
- Target: overseas buyers looking for reliable China sourcing

## Colors
- Primary: `brand-navy` (#1e3a5f) - trust, professionalism
- Primary accent: `brand-blue` (#2563eb) - action, links
- Secondary: `brand-orange` (#e97b2c) - CTAs, highlights
- Neutral dark: `brand-dark` (#1a1a2e) - headings, text
- Neutral medium: `brand-gray` (#64748b) - body text
- Neutral light: `brand-light` (#f8fafc) - backgrounds
- White: `brand-white` (#ffffff) - cards, sections
- Success: `brand-green` (#16a34a) - trust indicators

## Typography
- Font: Inter (Google Fonts)
- Headings: font-bold, tracking-tight
  - H1: text-4xl md:text-5xl lg:text-6xl
  - H2: text-3xl md:text-4xl
  - H3: text-xl md:text-2xl
  - H4: text-lg md:text-xl
- Body: text-base, text-brand-gray
- Small: text-sm

## Spacing
- Section padding: py-16 md:py-24
- Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8
- Gap between cards: gap-6 md:gap-8

## Components
- Buttons:
  - Primary: bg-brand-orange text-white hover:bg-orange-600 rounded-lg px-6 py-3 font-semibold
  - Secondary: border-2 border-brand-navy text-brand-navy hover:bg-brand-navy hover:text-white rounded-lg px-6 py-3 font-semibold
- Cards: bg-white rounded-xl shadow-sm border border-gray-100 p-6
- Sections alternate: bg-brand-light / bg-white

## Do's
- Use plenty of whitespace
- Keep text concise and scannable
- Use icons to support text
- Maintain consistent spacing
- Use subtle shadows on cards
- Use brand-orange for primary CTAs only

## Don'ts
- No dark mode (B2B site, keep it light and professional)
- No excessive animations
- No gradient overuse
- No text on busy image backgrounds without overlay
- No more than 2 font weights per element
