# SSourcing China - Design Guidelines

## Brand Identity
A professional B2B website for a China-based sourcing agent. Trustworthy, international, clean, and practical.

## Typography
- Font: Inter (Google Fonts, weights 300, 400, 500, 600, 700, 800)
- Headings: font-semibold or font-bold, tracking-tight
- Body: font-normal, leading-relaxed
- Do NOT use overly large decorative fonts; keep it business-professional

## Colors
- Primary Navy: #0f2b46 (headings, navbar, footer backgrounds)
- Secondary Gold: #c8922b (CTA buttons, highlights, accent elements)
- Accent Blue: #1e5fbb (links, secondary buttons)
- Light BG: #f7f8fa (section backgrounds)
- White: #ffffff (cards, main background)
- Text Dark: #1a202c (body text)
- Text Muted: #64748b (subtle text)
- Border: #e2e8f0 (cards, dividers)

Do NOT use:
- Neon or overly bright colors
- Purple, pink, or flashy gradients
- Dark mode as default

## Spacing
- Section padding: py-16 md:py-24
- Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8

## Cards
- bg-white rounded-xl shadow-sm border border-gray-100
- Subtle hover: hover:shadow-md transition-shadow

## Buttons
- Primary CTA: bg-[#c8922b] hover:bg-[#b07d1f] text-white font-semibold rounded-lg px-6 py-3
- Secondary: border-2 border-[#0f2b46] text-[#0f2b46] hover:bg-[#0f2b46] hover:text-white rounded-lg px-6 py-3
- Link style: text-[#1e5fbb] hover:underline

## Icons
- Use Lucide React icons exclusively
- Icon size: w-5 h-5 for inline, w-8 h-8 for feature cards, w-12 h-12 for hero elements
