# Velmora Fine Jewelry — Design System

## Visual Identity
- Mood: Quiet luxury, warm, editorial. Premium demi-fine gold jewelry.
- NOT loud, NOT discount-looking, NOT generic e-commerce.

## Color Palette
- Base: #FBF9F6 (warm cream white)
- Surface: #F4F0EB (warm ivory)
- Muted: #E8E2D9 (champagne)
- Border: #D6CEC5 (warm stone)
- Dark: #1C1C1C (near black)
- Body: #3D3835 (warm charcoal)
- Subtle: #8B8279 (warm taupe)
- Accent: #C9A96E (champagne gold)
- Accent Deep: #B7934D (burnished gold)
- Accent Light: #F0E2C8 (pale gold)

## Typography
- Headings (serif): Cormorant Garamond — for hero, product names, section titles
- Body (sans): Inter — for UI, descriptions, buttons, navigation
- Product names: UPPERCASE with letter-spacing: 0.15em
- Hero headline: Cormorant Garamond, 400–500 weight, generous size

## Spacing & Layout
- Generous whitespace — section padding: px-6 md:px-12 lg:px-20
- Hairline dividers (border-b border-velmora-border)
- Max content width: max-w-7xl mx-auto

## Buttons
- Primary (accent): bg-velmora-accent text-white, hover:bg-velmora-accent-deep
- Outline: border-velmora-dark text-velmora-dark, hover:bg-velmora-dark hover:text-white
- Smooth transitions, subtle shadows

## Cards
- bg-velmora-base, soft shadow, thin border
- Hover: slight scale + shadow lift

## Accessibility
- All text must have strong contrast against backgrounds
- Light text on light surfaces is forbidden
- Use velmora-body (#3D3835) on velmora-base (#FBF9F6) for body text
- Use velmora-dark (#1C1C1C) for headings
