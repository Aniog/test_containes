# SSourcing China — Design System

## Brand Identity
- Company: SSourcing China
- Tagline: China Sourcing Agent for Global Buyers
- Tone: Professional, clear, practical, trustworthy, international B2B

## Color Palette
- Primary Blue: `#1A3C6E` (deep navy — trust, authority)
- Accent Red: `#C0392B` (China red — identity, energy)
- Accent Gold: `#D4A017` (quality, premium)
- Light Blue: `#EBF2FA` (backgrounds, cards)
- White: `#FFFFFF`
- Gray 50: `#F8FAFC`
- Gray 100: `#F1F5F9`
- Gray 200: `#E2E8F0`
- Gray 400: `#94A3B8`
- Gray 600: `#475569`
- Gray 800: `#1E293B`
- Gray 900: `#0F172A`

## Typography
- Font: Inter (Google Fonts)
- Headings: font-bold, tracking-tight
- Body: font-normal, leading-relaxed
- H1: text-4xl md:text-5xl lg:text-6xl
- H2: text-3xl md:text-4xl
- H3: text-xl md:text-2xl
- Body: text-base (16px)
- Small: text-sm

## Spacing
- Section padding: py-16 md:py-24
- Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8
- Gap between cards: gap-6 md:gap-8

## Components

### Buttons
- Primary: bg-[#1A3C6E] text-white hover:bg-[#15305A] px-6 py-3 rounded-lg font-semibold
- CTA: bg-[#C0392B] text-white hover:bg-[#A93226] px-8 py-4 rounded-lg font-bold text-lg
- Outline: border-2 border-[#1A3C6E] text-[#1A3C6E] hover:bg-[#1A3C6E] hover:text-white

### Cards
- bg-white rounded-xl shadow-sm border border-gray-100 p-6 hover:shadow-md transition-shadow

### Section Headers
- Centered, H2 in gray-900, subtitle in gray-600, optional colored accent line below

### Navbar
- bg-white shadow-sm, logo left, nav links center/right, CTA button right
- Sticky top-0 z-50

### Footer
- bg-[#0F172A] text-white, 4-column grid, copyright bar

## Do's
- Use navy blue for primary actions and headings
- Use China red sparingly for CTAs and accents
- Use plenty of white space
- Use real-looking factory/QC/shipping imagery via stock system
- Keep forms clean and minimal
- Use trust badges and numbers prominently

## Don'ts
- No dark text on dark backgrounds
- No light text on light backgrounds
- No exaggerated claims ("best in the world", "guaranteed")
- No cluttered layouts
- No mobile-unfriendly font sizes
