# SSourcing China — Design System

## Brand Identity
Professional, trustworthy, international B2B sourcing company based in China.

## Color Palette

### Primary — Deep Navy Blue
- Primary: `#1B3A6B` (navy-800) — main brand color, headers, CTAs
- Primary Light: `#2A5298` (navy-600) — hover states
- Primary Dark: `#0F2347` (navy-900) — dark backgrounds

### Accent — Warm Gold
- Accent: `#C8922A` (gold-600) — highlights, badges, icons
- Accent Light: `#E8B84B` (gold-400) — hover, subtle accents

### Neutral
- White: `#FFFFFF`
- Gray 50: `#F8F9FA` — page backgrounds
- Gray 100: `#F1F3F5` — card backgrounds
- Gray 200: `#E9ECEF` — borders
- Gray 400: `#868E96` — placeholder text
- Gray 600: `#495057` — body text
- Gray 800: `#212529` — headings

### Status
- Success: `#2D7D46` — verified, approved
- Warning: `#C8922A` — pending
- Error: `#C0392B` — issues

## Typography

### Font Family
- Headings: `Inter` (700, 800)
- Body: `Inter` (400, 500)
- Accent: `Inter` (600)

### Scale
- Display: `text-5xl font-extrabold` (48px)
- H1: `text-4xl font-bold` (36px)
- H2: `text-3xl font-bold` (30px)
- H3: `text-xl font-semibold` (20px)
- Body Large: `text-lg` (18px)
- Body: `text-base` (16px)
- Small: `text-sm` (14px)
- Caption: `text-xs` (12px)

## Spacing
- Section padding: `py-20 px-4`
- Container max-width: `max-w-7xl mx-auto`
- Card padding: `p-6` or `p-8`
- Gap between cards: `gap-6` or `gap-8`

## Borders & Shadows
- Card border: `border border-gray-200`
- Card radius: `rounded-xl`
- Card shadow: `shadow-sm hover:shadow-md transition-shadow`
- Button radius: `rounded-lg`
- Input radius: `rounded-lg`

## Components

### Primary Button
`bg-navy-800 text-white px-6 py-3 rounded-lg font-semibold hover:bg-navy-600 transition-colors`

### Secondary Button (Outline)
`border-2 border-navy-800 text-navy-800 px-6 py-3 rounded-lg font-semibold hover:bg-navy-800 hover:text-white transition-colors`

### Gold CTA Button
`bg-gold-600 text-white px-8 py-4 rounded-lg font-bold text-lg hover:bg-gold-400 transition-colors`

### Card
`bg-white border border-gray-200 rounded-xl p-6 shadow-sm hover:shadow-md transition-shadow`

### Section Header
- Eyebrow: `text-gold-600 text-sm font-semibold uppercase tracking-widest`
- Title: `text-navy-800 text-3xl font-bold`
- Subtitle: `text-gray-600 text-lg`

## Do's
- Use navy as the dominant brand color
- Use gold sparingly for emphasis and CTAs
- Keep layouts clean with generous whitespace
- Use real-world imagery (factories, QC, shipping)
- Maintain consistent 8px spacing grid

## Don'ts
- Don't use bright/neon colors
- Don't use more than 2 accent colors per section
- Don't use small text on dark backgrounds without sufficient contrast
- Don't use decorative fonts — keep it professional
