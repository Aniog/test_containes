# SSourcing China - Design System

## Brand Overview
Professional B2B sourcing agent based in China serving global buyers. Trust, clarity, and international business professionalism.

## Color Palette
- Primary: `#0f172a` (slate-900) - headers, text, trust
- Accent: `#1d4ed8` (blue-700) - CTAs, links, highlights
- Accent Hover: `#1e40af` (blue-800)
- Surface: `#ffffff` (white) - cards, backgrounds
- Page Background: `#f8fafc` (slate-50)
- Muted Text: `#475569` (slate-600)
- Light Border: `#e2e8f0` (slate-200)
- Success: `#15803d` (green-700)
- Warning: `#b45309` (amber-700)

## Typography
- Headings: Inter, system-ui, sans-serif
- Body: Inter, system-ui, sans-serif
- H1: 3rem / 700
- H2: 2.25rem / 700
- H3: 1.5rem / 600
- Body: 1rem / 1.6
- Small: 0.875rem / 1.5

## Spacing
- Section vertical padding: `py-20 lg:py-28`
- Container max width: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`
- Card padding: `p-6 lg:p-8`
- Grid gaps: `gap-6 lg:gap-8`

## Components
- Primary Button: `bg-blue-700 text-white hover:bg-blue-800 px-6 py-3 rounded-lg font-medium`
- Secondary Button: `bg-white text-slate-900 border border-slate-200 hover:bg-slate-50 px-6 py-3 rounded-lg font-medium`
- Cards: `bg-white rounded-xl shadow-sm border border-slate-200`
- Input: `border-slate-300 focus:border-blue-500 focus:ring-blue-500 rounded-lg`
- Section Label: `text-blue-700 font-semibold uppercase tracking-wide text-sm`

## Imagery
- Realistic factory, QC inspection, shipping container, electronics, industrial, packaging visuals.
- Use stock image tags via data-strk-img / data-strk-bg.
- Prefer 16x9 and 4x3 ratios.

## Do's
- Keep layouts clean and spacious.
- Use plenty of white space.
- Make CTAs prominent and repeated.
- Ensure text is readable on all backgrounds.
- Use responsive grids (1 col mobile, 2-3 col desktop).

## Don'ts
- No exaggerated claims like "#1" or "guaranteed lowest price".
- No cluttered layouts.
- No low-contrast text.
- No emojis in body copy.
