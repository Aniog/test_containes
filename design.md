# Design Guidelines - SSourcing China

## Visual Style
Clean, professional, and trustworthy B2B aesthetic. Focus on global trade, quality control, and logistics.

## Colors
- **Primary**: Deep Blue (#0F4C81) - Represents trust, stability, and professionalism.
- **Secondary**: Light Gray (#F5F5F5) - Used for backgrounds to keep the design clean.
- **Accent**: International Orange (#E67E22) - Used for Call-to-Action buttons and highlighting key points.
- **Text**: Dark Slate (#333333) - For high readability.
- **Muted**: Medium Gray (#666666) - For secondary information.

## Typography
- **Font Family**: Inter, sans-serif (via Google Fonts).
- **Headings**: Semi-bold to Bold, clean sans-serif.
- **Body**: Regular, 16px base size, generous line height (1.6).

## Spacing & Layout
- Generous whitespace to avoid clutter.
- Max-width containers (1280px) for desktop.
- Vertical padding for sections (4rem to 8rem).
- Grid-based layouts (1, 2, or 3 columns).

## UI Components
- **Buttons**: Rounded corners (sm/md), clear contrast.
- **Cards**: Subtle shadows, clean borders, white background.
- **Inputs**: Simple, outlined, focus state using primary color.
- **Icons**: Lucide React for consistent, thin-line iconography.

## Imagery
- Realistic photos of factories, quality inspections, shipping containers, and professional business interactions.
- Avoid overly "stocky" or exaggerated corporate photos.
- Use `data-strk-img` system for all content images.

## Do's and Don'ts
### Do:
- Use clear, actionable headlines.
- Maintain consistent alignment.
- Use responsive Tailwind classes (sm, md, lg).
- Include trust signals (badges, testimonials).

### Don't:
- Use neon colors or overly aggressive gradients.
- Overcrowd sections with too much text.
- Use low-contrast text on bright backgrounds.
- Use generic, unrelated stock photos.
