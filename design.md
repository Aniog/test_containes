# Visual Style Guide - SSourcing China

## Typography
- Primary Font: Inter, sans-serif
- Headings: Bold, slate-900, tight letter-spacing
- Body: slate-600, leading-relaxed for legibility

## Colors
- Primary: blue-600 (#2563eb) - Used for primary buttons and accents
- Secondary: slate-900 (#0f172a) - Used for headings and dark backgrounds
- Background: slate-50 (#f8fafc) - Main background for sections
- Surface: white (#ffffff) - Cards and navigation
- Border: slate-200 (#e2e8f0)

## Spacing
- Section Padding: py-20 (80px) on desktop, py-12 (48px) on mobile
- Container Width: max-w-7xl (1280px)

## Components
- Buttons: rounded-md, px-6, py-3, font-medium, shadow-sm
- Cards: bg-white, rounded-xl, p-8, border border-slate-200, shadow-sm
- Inputs: rounded-md, border-slate-200, focus:ring-blue-500

## Images
- Ratios: 3x2 for factory/product shots, 16x9 for hero/banners
- Style: Realistic, professional, high-quality B2B photography
