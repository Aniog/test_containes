# SSourcing China Visual Design Guide

## Brand positioning
Professional B2B sourcing consultancy for overseas buyers. The interface should feel clean, calm, practical, and internationally trustworthy.

## Color system
- Primary navy: use `brand-navy` for headings, header text, and strong trust cues.
- Deep ink: use `brand-ink` for body copy on light surfaces.
- Supply blue: use `brand-blue` for primary CTAs, links, and focused states.
- Soft blue: use `brand-softBlue` for subtle panels and process backgrounds.
- Accent amber: use `brand-amber` sparingly for highlights, badges, and warm logistics details.
- Slate line: use `brand-line` for borders and dividers.
- Page background: use `brand-bg` for the main page background.

## Typography
- Use Inter as the global font.
- Headings should be concise, confident, and dark navy. Example classes: `text-brand-navy font-semibold tracking-tight`.
- Body text should be practical and readable. Example classes: `text-brand-ink/75 leading-relaxed`.

## Layout and spacing
- Use generous whitespace and a max-width container (`max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`).
- Desktop layouts should use two or three columns where appropriate; mobile should stack cleanly.
- Cards should use white backgrounds, clear borders, and subtle shadows.

## Components
- Primary buttons: `bg-brand-blue text-white hover:bg-brand-navy`.
- Secondary buttons: `border border-brand-line bg-white text-brand-navy hover:border-brand-blue`.
- Cards: `rounded-2xl border border-brand-line bg-white shadow-sm`.
- Badges: clear contrast, usually `bg-brand-softBlue text-brand-navy` or `bg-brand-amber/15 text-brand-navy`.

## Imagery
- Use realistic factory, quality inspection, production follow-up, supplier meeting, product packaging, and shipping visuals.
- Avoid exaggerated luxury, unrealistic claims, or consumer-style imagery.

## Do's and don'ts
- Do keep copy direct and specific to sourcing work.
- Do use trust-building details such as factory checks, QC reports, production timelines, and shipment coordination.
- Don't use vague hype such as “guaranteed best supplier” or “zero risk”.
- Don't use low-contrast text or colored panels without explicit readable foreground classes.
