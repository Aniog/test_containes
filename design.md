# SSourcing China - Design System

## Visual Identity
A professional B2B website for a China-based sourcing agent. Clean, trustworthy, international.

## Typography
- Font: Inter (Google Fonts) - clean, modern, highly readable
- Headings: font-semibold or font-bold, tracking-tight
- Body: font-normal, text-base leading-relaxed
- Section titles: text-3xl md:text-4xl font-bold

## Colors
- Primary: #1e3a5f (Navy Blue) - trust, professionalism
- Primary Light: #2563eb (Blue 600) - accents, links
- Accent: #ea580c (Orange 600) - CTAs, highlights
- Accent Hover: #c2410c (Orange 700)
- Background: #ffffff (White)
- Surface: #f8fafc (Slate 50) - cards, sections
- Muted: #f1f5f9 (Slate 100) - subtle backgrounds
- Text Primary: #0f172a (Slate 900)
- Text Secondary: #475569 (Slate 600)
- Text Muted: #94a3b8 (Slate 400)
- Border: #e2e8f0 (Slate 200)

## Spacing
- Section padding: py-16 md:py-24
- Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8

## Components
- Buttons: rounded-lg, font-semibold, px-6 py-3
- Cards: bg-white rounded-xl shadow-sm border border-slate-200
- Navbar: sticky top-0 bg-white/95 backdrop-blur border-b border-slate-200
- Footer: bg-slate-900 text-white

## Do's
- Use ample white space
- Keep sections focused with clear hierarchy
- Use icons (Lucide) to support content
- Use stock images for factory/QC/shipping visuals
- Keep CTAs prominent in accent color

## Don'ts
- No exaggerated claims or hype language
- No dark backgrounds for main content
- No overly dense text blocks
- No distracting animations
