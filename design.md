# SSourcing China - Design System

## Overview
Professional B2B website for a China-based sourcing agent. Clean, trustworthy, international feel. Minimal, no exaggerated claims.

## Color Palette
- **Primary Navy**: #0F2B3D - Headers, primary buttons, trust elements
- **Primary Teal**: #0A6E74 - CTAs, accents, active states, links
- **Secondary Teal**: #0D8B8F - Hover states for primary teal
- **White**: #FFFFFF - Card backgrounds, clean sections
- **Light Gray**: #F5F7FA - Section backgrounds (alternating)
- **Medium Gray**: #E2E8F0 - Borders, dividers
- **Dark Gray**: #334155 - Body text
- **Heading Gray**: #1E293B - Headlines
- **Muted**: #64748B - Secondary text, captions
- **Success Green**: #059669 - Trust badges, checkmarks
- **Alert Red**: #DC2626 - Required form fields

## Typography
- **Font Family**: Inter (Google Fonts)
- **H1**: 48px, weight 700, line-height 1.2, color #1E293B
- **H2**: 36px, weight 700, line-height 1.25, color #1E293B
- **H3**: 24px, weight 600, line-height 1.3, color #1E293B
- **Body**: 16px, weight 400, line-height 1.6, color #334155
- **Small**: 14px, weight 400, line-height 1.5, color #64748B
- **Nav Links**: 14px, weight 500, color #334155
- **CTA Button**: 16px, weight 600, color white

## Spacing
- **Section Padding**: py-20 (80px top/bottom)
- **Container**: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- **Card Gap**: gap-6 (24px)
- **Element Spacing**: space-y-4 within components

## Layout
- Fixed navbar with white background, subtle shadow
- Full-width hero with background image
- Content sections with max-width container
- Footer with dark navy background

## Do's and Don'ts
- DO use clean, spacious layouts with generous whitespace
- DO use real factory/QC/shipping imagery
- DO keep text practical and factual
- DO use icons from Lucide for services and features
- DON'T use bright neon colors
- DON'T use excessive animations
- DON'T make exaggerated claims or fake testimonials
- DON'T use gradients on backgrounds
