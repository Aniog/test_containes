# SSourcing China - Design System

## Typography
- Font: Inter (Google Fonts)
- Headings: font-bold, tracking-tight
  - h1: text-4xl md:text-5xl lg:text-6xl font-extrabold
  - h2: text-3xl md:text-4xl font-bold
  - h3: text-xl md:text-2xl font-semibold
- Body: text-base text-navy-600 leading-relaxed

## Colors
- Primary: brand-600 (#1d4ed8) - CTAs, links, accents
- Primary hover: brand-700 (#1e40af)
- Primary light: brand-50 (#eff6ff) - backgrounds, badges
- Text dark: navy-900 (#102a43)
- Text body: navy-600 (#486581)
- Text muted: navy-400 (#829ab1)
- White: #ffffff
- Background: white, gray-50 for alternating sections

## Spacing
- Section padding: py-16 md:py-20 lg:py-24
- Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Card padding: p-6 md:p-8

## Components
- Buttons: rounded-lg font-semibold
  - Primary: bg-brand-600 hover:bg-brand-700 text-white px-6 py-3
  - Secondary: bg-white border border-brand-600 text-brand-600 hover:bg-brand-50
- Cards: bg-white rounded-xl shadow-sm border border-gray-100
- Section titles: text-center mb-4, with subtitle in text-navy-500
- Icons: Lucide React, w-6 h-6 or w-8 h-8

## Visual Style
- Clean, professional B2B look
- Generous whitespace
- Blue and navy palette for trust
- No exaggerated animations
- Realistic factory/QC/shipping imagery via stock images
- Subtle shadows for depth
- Border-radius: rounded-xl for cards, rounded-lg for buttons
