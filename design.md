# SSourcing China - Visual Style Guide

## Brand Identity
- **Name**: SSourcing China
- **Tagline**: China Sourcing Agent for Global Buyers
- **Tone**: Professional, clear, practical, trustworthy. No exaggerated claims.

## Typography
- **Primary Font**: Inter (Google Webfont)
- **Headings**: Inter, weight 700-800, sizes 2xl-5xl
- **Body**: Inter, weight 400-500, size base-lg
- **Small/Caption**: Inter, weight 400, size sm-xs

## Colors
- **Primary Blue**: #1e40af (deep navy blue - trust, professionalism)
- **Primary Dark**: #1e3a8a (darker blue for headings)
- **Accent Orange**: #f97316 (warm orange for CTAs, highlights)
- **Navy Dark**: #102a43 (dark navy for hero backgrounds, footer)
- **Navy Light**: #f0f4f8 (light background for sections)
- **White**: #ffffff (clean backgrounds)
- **Gray**: #627d98 (secondary text)
- **Border Gray**: #d9e2ec (subtle borders)

### Tailwind Color Mapping
- `primary-500` = #1e40af (main brand blue)
- `primary-600` = #1e3a8a (heading blue)
- `accent-500` = #f97316 (CTA orange)
- `navy-900` = #102a43 (dark backgrounds)
- `navy-50` = #f0f4f8 (light section backgrounds)
- `navy-500` = #627d98 (secondary text)

## Layout
- **Max content width**: 1280px (max-w-7xl)
- **Section padding**: py-16 md:py-24
- **Card padding**: p-6 md:p-8
- **Grid gaps**: gap-6 md:gap-8

## Visual Elements
- **Buttons**: Rounded (rounded-lg), solid fills, hover transitions
  - Primary CTA: bg-accent-500 text-white hover:bg-accent-600
  - Secondary: bg-primary-500 text-white hover:bg-primary-600
  - Outline: border-2 border-primary-500 text-primary-500
- **Cards**: White bg, subtle shadow (shadow-md), rounded-xl, border border-navy-100
- **Sections**: Alternating white and navy-50 backgrounds
- **Hero**: Dark navy-900 background with overlay, large heading, CTA button

## Spacing Rules
- Between sections: py-16 md:py-24
- Between cards in grid: gap-6 md:gap-8
- Inside cards: p-6 md:p-8
- Between heading and content: mt-4 md:mt-6
- Between list items: space-y-4

## Do's
- Use clean, spacious layouts with generous whitespace
- Use blue for trust elements, orange for action elements
- Use realistic factory/QC/shipping imagery via data-strk-img
- Keep text concise and professional
- Use consistent card styles across all sections
- Ensure all text is clearly readable against backgrounds

## Don'ts
- Don't use exaggerated claims or superlatives
- Don't use dark text on dark backgrounds
- Don't overcrowd sections with too many elements
- Don't use decorative gradients or flashy animations
- Don't use generic placeholder text without context
- Don't mix too many colors - stick to blue, orange, navy, white
