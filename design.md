# SSourcing China - Design Guidelines

## Brand Identity
- **Company**: SSourcing China
- **Industry**: B2B sourcing agent / supply chain services
- **Tone**: Professional, trustworthy, clear, practical — no exaggerated claims

## Typography
- **Primary Font**: Inter (Google Fonts)
- **Headings**: Inter 600-700 weight, tracking tight
- **Body**: Inter 400 weight, line-height 1.6
- **Small/Caption**: Inter 500 weight, text-sm

## Colors
- **Primary Blue**: #1e56a0 (deep navy blue — trust, authority, B2B)
- **Primary Dark**: #0d2f5a (dark navy for hero backgrounds)
- **Accent Orange**: #d4760a (warm amber for CTAs and highlights)
- **Accent Light**: #fb923c (lighter orange for hover states)
- **Neutral Background**: #ffffff (white)
- **Neutral Light**: #f1f5f9 (light slate for section backgrounds)
- **Neutral Mid**: #e2e8f0 (borders, dividers)
- **Text Primary**: #1e293b (dark slate)
- **Text Secondary**: #475569 (medium slate)
- **Text Muted**: #94a3b8 (light slate for captions)

## Tailwind Classes Reference
- Hero background: `bg-primary-800` or `bg-gradient-to-br from-primary-800 to-primary-900`
- CTA buttons: `bg-accent-500 hover:bg-accent-600 text-white`
- Section backgrounds: `bg-white` or `bg-neutral-50`
- Card borders: `border border-neutral-200`
- Headings: `text-neutral-800 font-semibold`
- Body text: `text-neutral-600`
- Muted text: `text-neutral-400`

## Spacing
- Section padding: `py-16 md:py-24`
- Card padding: `p-6 md:p-8`
- Grid gaps: `gap-6 md:gap-8`
- Container max-width: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`

## Layout
- Desktop: multi-column grids (2-3 columns)
- Mobile: single column stacking
- Cards: rounded corners (`rounded-lg`), subtle shadows (`shadow-sm` or `shadow-md`)
- Hero: full-width with background image, centered text

## Visual Style
- Clean, minimal design with generous whitespace
- Professional iconography (Lucide icons)
- Stock images of factories, QC inspections, shipping containers, warehouses
- No decorative flourishes — functional clarity
- Consistent card styles across all sections

## Do's
- Use blue for trust-related elements (certifications, guarantees)
- Use orange/amber only for CTAs and key highlights
- Keep paragraphs short (2-3 lines max in cards)
- Use consistent card layouts for services, products, case studies
- Ensure all text is clearly readable against backgrounds
- Use responsive breakpoints (md:, lg:) for layout changes

## Don'ts
- Don't use light text on light backgrounds
- Don't use more than 2 accent colors
- Don't add decorative gradients or patterns
- Don't use exaggerated language ("best", "#1", "guaranteed")
- Don't clutter sections with too many elements
- Don't use dark backgrounds for body text sections
